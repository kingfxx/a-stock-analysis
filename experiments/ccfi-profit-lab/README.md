## 模型及来源

- CCFI：用户附件月度图中整数标签，提前一个月：Q2 用 3—5 月，Q3 用 6—8 月。2026Q2 为 1210 点，Q3 为 1752.3333 点，涨幅约 44.82%。原始备注、缺失和单元格位置可在网页展开；不将图中周次伪造为实际日期。
- 财务只读 `financial_reports`，截止 2026-06-30，优先新浪 gjzb，逐项回退 lrb。营业成本只取 lrb.BIZCOST，避免 gjzb 的 BIZTOTCOST 同名标题误用。累计值转同年单季，Q1 不减上年年报。
- 正式2025年报、2026中报及已有来源样本复用；补齐2023Q1—2026Q2共14份正式报告，证据保留于 `data/verification/samples/ccfi-profit-lab/`，包括来源、哈希及解析页。新增请求复用公共RequestCollector和原库已有公共采集元数据；未修改财务事实或正式财报登记。
- Q2 国际收入 =（H1 全部航线收入 − H1 国内航线收入）−（Q1 全部航线收入 − Q1 国内航线收入）；箱量同理。其余合并收入 = Q2 合并营收 − 国际收入 − 国内收入。
- 中性收入水平模型为 `f(CCFI)=2639.2567+4.743080×CCFI` 元/TEU；Q3单箱收入 = Q2实际 + f(Q3CCFI) − f(Q2CCFI)，然后作可选收入汇率情景修正。可选择二次、1500点分段或幂函数作探索；所有模型使用同样的Q2锚定。
- 手动弹性模式：单箱收入增幅 =（1 + 传导弹性 × CCFI 环比）×（1 + 收入汇率情景修正）− 1；手动覆盖时不再使用模型、弹性/汇率。编辑弹性会切回手动模式。
- Q3 国际收入 = Q2 国际收入 ×（1 + 单箱收入增幅）×（1 + 箱量增幅）。国内及其他收入按同一箱量增幅缩放，是简化假设。
- Q3 成本 = Q2 合并营业成本 ×（1 + 箱量增幅）×（1 + 单位成本增幅）。没有将燃油与其他成本拆出，公司未披露燃油占总成本的精确比例。
- Q3 归母 =（收入 − 成本 + 毛利以下税前净额）× 税前转归母比例 + 额外归母损益。额外损益已是税后归母口径，避免再次乘税率。
- 公式是研究情景模型，不替代合并报表；统一成本弹性、固定税前转归母比例在极端或亏损情景下可能不适用。

## 历史与雪球对照

提前 0/1/2 月用相同 13 个季度（2023Q2—2026Q2）；2023Q1 缺 2022 年末 CCFI，三组共同排除。至少 6 季训练，7 季滚动预测。运价桥 = 最近一季实际归母 + 训练期回归斜率 × 有效 CCFI 变化。

滚动 MAE 分别为 26.67 / 19.87 / 39.59 亿元；沿用上一季度利润为 42.88 亿元。提前 1 月的当前运价桥参照为 153.74 亿元。回测不验证主观业务情景，且历史财务采用当前修订版本，未还原当时可得快照。

参考用户提供 ljm94 的雪球 PDF《中远海控2026年三季度利润怎么估：从CCFI到归母净利润的拆解》，原链接见网页。文章是图像版，视觉核读第1—9页。其Q2基础业务数据已用正式报告核对；文章更长的单箱收入回归训练集、汇率和燃油月均值未独立复核。按文章展示参数复算为166.7312亿元，页面提供载入按钮。

## 收入弹性与非线性验证

本次共同样本为2023Q2—2026Q2共13季。14份业务表收入与箱量先分别差分再相除，未拿年度/半年度均价冒充季度均价；Q3另用直接单季列核验；随后年度的航线总额/国内数据比较数未发现修订差异。

12次季度涨幅的过原点回归弹性为0.6987；收入水平线性回归折算本次Q2→Q3弹性为0.6712，单箱收入增幅30.08%。百分比弹性即使在线性水平模型下也随基数变化，不能与每点CCFI的绝对边际混为一谈。

二次单箱收入模型的HC3近似p值0.772，归母利润二次项0.334。高于1500点仅两个季度；删除2024Q3后单箱收入曲率反转。7季滚动收入MAE线性299.1、二次277.9元/TEU；将预测开始提前至2024Q3高点，8季误差分别为322.6、727.9元/TEU。分段模型早期没有高区间训练样本，参数不可识别，不强制评分。因此保留线性默认，非线性仅探索。

完整结论、逐季明细、模型系数、来源及检验在 `data/verification/reports/ccfi-profit-lab/ELASTICITY_RESEARCH.md` 和 `calibration.json`；独立页面新增“财报弹性检验”，并支持将所选模型应用到当前情景。

## 周度提前两周检验

新增 `weekly.py`、页面“周度提前两周”、`data/verification/reports/ccfi-profit-lab/weekly.json` 与 `WEEKLY_RESEARCH.md`。复用已提取14季业务财务，不重新下载财报；原Excel、原月度/周度值不改动。

日期为按官方2023—2026发布日历及图中节假日空档辅助推定，保留原图周次与推定日期两个字段，未将推定日期冒充原始来源。2026图中第1周从1月9日起，而不是套ISO周号；节假日提前发布按公告日期调整。日历依据保存在 `data/verification/samples/ccfi-profit-lab/weekly-calendar-evidence.json`，原图提取样本为 `weekly-source-chart.png`。

“提前两周”将季度起止整体减14天。比较0—6周，按发布值等权与按日暴露两个口径，所有候选（含原月度、从周值重建月度）使用相同13季、7次滚动预测。应发布却缺值则整段留空；正式节假日无发布不计缺失。按日暴露允许指数从发布日起保持至下次发布，但不跨缺失的应发布值填充。

发布均值口径：提前2周收入MAE238.66元/TEU、利润水平MAE14.77亿元、利润桥MAE18.84亿元；原月度分别299.14、15.38、19.87。利润桥提前3周为18.17亿元，略好。按日暴露提前2周业务情景归母173.59亿元，发布均值为173.11亿元。原月度中性171.9亿元默认保留。

日期整体±7天、扩大为8次检验、极保守去除矛盾备注均会改变最佳窗口，不能确认精确两周最优。另发现2024年1月原月值1441与周值均值1191.75不一致，原备注已标待核对；新增重建月度敏感性，未覆盖源值。财务样本仍13季，不是数百周。八项Python测试及JS选择器/日期/样本/前后数据验证通过；浏览器视觉验收限制仍在。

## 刷新与验证

使用含 numpy、openpyxl 的 Python；读取 Excel，不改动附件。

```powershell
python experiments/ccfi-profit-lab/build.py --workbook '<附件绝对路径.xlsx>' --reference-pdf '<雪球PDF绝对路径.pdf>'
python experiments/ccfi-profit-lab/capture_reports.py
python experiments/ccfi-profit-lab/calibrate.py
python experiments/ccfi-profit-lab/weekly.py
python experiments/ccfi-profit-lab/build.py --workbook '<附件绝对路径.xlsx>' --reference-pdf '<雪球PDF绝对路径.pdf>'
python experiments/ccfi-profit-lab/test_model.py
node experiments/ccfi-profit-lab/verify.mjs
```

已有初版snapshot可跳过首次build。capture需要requests、pypdf；calibrate/build需要numpy，build另需openpyxl。capture已归档文件不重复请求；未有文件时显式采集经公共限速/冷却保护，不能在网页读取时自动运行。

`build.py` 生成单文件 `index.html` 和 `data/verification/reports/ccfi-profit-lab/snapshot.json`，内嵌最新calibration和完整拟合系数。HTML无外部依赖，参数只在会话内保存，支持JSON导出，导出包含收入模型系数。

验证覆盖时间窗口、缺失/零/负数、隔离数据库单季转换、未来报告排除、成本字段、年度报告季度核对、无冲击与 Q2 对账、文章复算、情景/重置动作及页面渲染函数。内置浏览器安全策略拒绝 `file:`，未完成真实浏览器视觉和点击验收；未使用另开服务等方式绕过该限制。
