# A 股季度分析页面

一个运行在本机的季度财务柱线图。输入沪深 A 股六位代码，可分别为柱形（左轴）和黄色线（右轴）选择营业收入、归母净利润、披露日估算市值或披露日前复权股价，自由对照，并查看单季度、年度和滚动四季度（TTM）。默认标的是 601919 中远海控，默认组合为左轴归母净利润与右轴前复权股价。单季度视图的柱形按 Q1–Q4 固定着色，每年重复同一组颜色，便于跨年比较。

页面下方还有估值图，可切换 PE(TTM)、PB、市销率 PS(TTM)、近 12 个月已实施现金分红股息率及最近 10/5/3 年。走势按月采样，参考线分别是所选区间有效月份的 80%、50%、20% 分位；摘要显示当前值高于多少有效月份。PE/PB/PS 还与当前同行业平均值比较，股息率因行业数据缺少同口径值而单独标明不可比。

## 指标口径

- 营收和归母净利润来自季度利润表的当年累计值；单季度按相邻累计期差分，TTM 汇总连续四个单季度。缺季度时留空。
- 股价取财报披露日或此前最近交易日的腾讯日 K 收盘价；相隔超过 15 天不计入披露日价格。若披露日处在有前后交易记录的长间隔内，且距前一交易日 16–180 天，图上以空心圆点显示最近收盘参考值，悬停标明实际交易日和相隔天数。与参考点相连的趋势段使用虚线，正常价格点之间使用实线。缓存仅保留每份报告对应的正式快照与参考点，不保存完整日线。
- 新浪历史记录的 `publish_date` 存在向后错一年的情况。页面按上一年同报告期记录校正，并保留原字段 `source_publish_date` 供核对；无法得到可信日期的早期报告留空。300750 的 2021 年年报已与深交所 2022-04-22 公告核对。
- 股本取同一报告期资产负债表的“实收资本（或股本）”；披露日估算市值＝对应交易日未复权收盘价×报告期末股本。长间隔参考市值也按最近收盘价×报告期末股本计算，仅是参考值。股本并非披露日实时股本，因此不是精确历史市值。
- 前复权股价取同一披露日对应的腾讯前复权日 K，仅用于走势，不用于市值。该序列的历史值可能为负，页面保留数据源原值，不把负数当作缺失。
- 横轴是报告期；悬停同时列出财报实际披露日与价格采样日。图表是事后对照，不能当作当时已经公开的估值。

估值图的 PE(TTM)、PB 和总市值历史来自百度股市通，每月保留最后一条可用记录。PS(TTM) 为当月总市值 ÷ 截至该月已披露财报的 TTM 营收；市值按亿元转换为元后再相除。股息率＝截至当月最后交易日前 365 天内实际除权实施的税前每股现金分红之和 ÷ 当月最后交易日未复权收盘价 × 100%；现金分红事件来自东方财富，`PRETAX_BONUS_RMB` 为每 10 股金额，计算时除以 10；未复权收盘价来自腾讯日 K。无已实施派息时股息率为 0%。PE 为负或指标无效时不参与分位计算。同行业算术平均来自东方财富同行估值接口，只有当前 PE/PB/PS 横向快照，不能与历史月份直接对照。财报历史值可能包含后续修订，估值图并非严格的历史实时回测。估值数据另存于 `data/cache/valuation/`，正常打开优先读当日缓存，点击“刷新数据”重新获取。

目前不保存完整逐日行情和历史成交额。精确历史股本与财报修订的点时版本计算仍在后续阶段；此前的阶段 0 资料保留在 `docs/data-sources/`。范围变更记录见[季度页面方案](docs/plans/2026-09-27-quarterly-dashboard.md)。
