# 公司价值投资研究框架

> 本文提供研究问题及分析深度。展示结构以 [固定模板契约](reference-layout.md) 为准；本文的建议表头、可选评分及小节调整不能覆盖用户指定模板。来源仅按大章节集中展示，逐项关联保留在独立事实账本。

目录：研究主线；报告框架（开篇与八模块）；资料组织；完整性验收。

## 研究主线

**生意怎样赚钱 → 谁控制和分配资本 → 超额回报靠什么维持 → 哪些情形会推翻判断 → 价格隐含什么预期 → 是否存在逆向机会 → 数据能否支撑 → 形成有条件的决策。**

展示顺序沿用参考报告；实际研究应先准备数据和资料，再完成商业判断与估值，最后写摘要及评分。不能从先定星级、先定目标价开始寻找支持理由。

每个关键论点使用同一写法：**判断 → 证据 → 经济机制 → 替代解释或反证 → 判断成立的条件／后续验证。** 不要求每段机械列五项，但完整论点必须覆盖它们。

## 报告框架

### 0. 开篇：让读者快速理解研究对象和主要分歧

**需要回答：** 研究哪家公司、截至何时、资料是否足以判断、投资者最终承担什么经营风险、回报主要从哪里来？

输出内容：

- 公司及研究时间；财报报告期、披露截止、行情交易日分别说明。
- 一句话投资本质：为哪种客户价值付费，依靠何种优势赚取现金，价值兑现依赖什么。
- 核心判断、最强支持证据、最大反证、尚未解决的关键缺口。
- 六维摘要表：商业模式、治理与文化、竞争优势、资本回报、安全边际、逆向机会。每项一至两句，由正文推导。

信息充分程度与公司质量分别判断；证据不足不能自动等于公司差，也不能给确定高分。星级可以作为可选摘要，须有清晰规则，不用无权重依据的平均星级制造总分。正文不要重复展开数据核对。

### 1. 商业模式：理解收入、利润和现金的形成过程

#### 1.1 生意本质与客户价值

- 卖什么、卖给谁、谁使用、谁付钱？需求是必选还是可选？
- 客户为何购买：价格、效率、可靠性、便利性、风险降低，还是身份及体验？
- 采购频率、替换周期、合同期限与付费方式是什么？
- 产品差异化是否能兑现为溢价或复购？竞争是否主要靠降价？

#### 1.2 产业链、经营链条与议价

- 公司处于何环节，上下游各自提供什么，利润池在哪里？
- 对供应商和客户分别有多大议价力？账期、预付款和风险由谁承担？
- 销售、交付、服务、融资、渠道如何影响单位经济性？
- 是否存在规模、数据、服务密度、口碑或复购的正反馈？其代价和边界是什么？

#### 1.3 收入结构、资本需求与集中风险

- 产品、地区、客户、渠道、经常性／一次性收入分别占多少？
- 利润主要由规模、价格、结构、成本还是周期推动？
- 需要多少固定资产、研发、营销和营运资本才能维持收入与增长？
- 收入何时变成现金？是否需要融资支持客户？增长是否反而吞噬现金？
- 客户看似分散，是否共同依赖财政、同一终端行业、平台或原材料价格？

**建议输出：** 业务结构表；经营链条／价值链表；必要时单位经济性表。章节结论说明生意清晰度、需求持续性、资本负担和增长约束，不能仅以“龙头”“轻资产”收尾。

### 2. 治理、企业文化与资本配置：判断现金会被怎样使用

#### 2.1 管理层诚信与监督

- 实际控制链、董事会、管理层分工及监督机制如何运作？
- 历史披露、审计、承诺兑现、重大关联交易是否支持诚信判断？
- 信息是否足以评价资金占用、担保、并购溢价及关联方受益？

#### 2.2 激励与组织能力

- 管理层的直接与间接经济权益、薪酬、考核和退出安排是否与长期股东回报一致？
- 考核是否诱导短期利润、激进销售或不合理扩张？
- 关键人员离开后能否运行？依靠个人、团队还是可复制的制度？
- 用户导向、人才建设和长期投入是否体现为真实行为，而非文化口号？

#### 2.3 资本配置与关键决策复盘

- 研发、扩产、并购、海外拓展、金融投资分别取得何种结果？
- 分红、回购、留存与融资安排是否匹配经营缓冲和再投资回报？
- 历史大决策当时有什么选项？管理层是否识别错误并调整？

**建议输出：** 五维治理表（管理层、资本配置、股东一致性、组织能力、长期发展）；历史决策表（时间、决策、当时依据、结果、归因与评价）。不将未检索到负面记录写成不存在问题；不将费用化直接等同于研发有效。

### 3. 竞争优势：识别超额回报的来源、寿命与变化

逐项检验五类机制：品牌与定价权、转换成本、网络效应、成本优势、技术及制度壁垒。行业存在许可、资源、渠道或生态壁垒时增加相应项，无关项注明不适用。

每项回答：验证方法是什么；具不具备；证据是什么；对价格、成本、留存或资本回报有什么作用；在扩大、稳定还是收窄？

继续追问：

- 竞争者获得足够资金后，能否复制？还缺时间、认证、客户信任、资源、组织或生态什么条件？
- 龙头优势来自真实差异还是周期顺风、补贴和产品结构？
- 行业份额、同口径利润及客户行为能否相互支持？
- 谁最有可能颠覆优势，靠什么机制？这一变化是否已发生？

**建议输出：** 护城河验证矩阵；复制难度判断；优势趋势与主要颠覆机制。技术投入、专利数、规模及高毛利是线索，不能单独作为持久壁垒的证明。

### 4. 风险、竞争与反方论证：主动寻找会错在哪里

#### 4.1 风险矩阵

按需求、竞争、技术、政策、地域、财务、治理与资本配置识别重大风险。每项说明发生状态、发生可能性、影响程度、传导路径、缓释措施与剩余风险；证据不足时不编造概率百分比。

#### 4.2 竞争格局

选择真正争夺相同客户的对手，比较市场范围、产品定位、份额及趋势、渠道、成本、盈利和战略。集团整体与业务分部、不同区域及产品范围分别列示，避免混用分母。

#### 4.3 专项风险检查

- 行业技术变化与经济／行业周期。
- 应收、存货、商誉、金融资产及减值的真实质量。
- 现金与负债是否存在限制、期限错配或融资成本矛盾。
- 控制权、质押、担保、关联交易及少数股东风险。
- 业务特有风险：质保、履约、客户融资、监管资本等。

#### 4.4 空方论点与历史类比

- 写出最强的反方解释，而不是容易反驳的弱论点。
- 比较公司历史低谷或相似企业：当时因什么失败，本次有哪些相同与不同？
- 区分周期恢复、结构增长与不可逆衰退，说明证据能支持到哪一步。

**建议输出：** 风险矩阵、竞争者表、专项风险表、空方论点与验证条件、历史类比。章节结论明确哪些风险能定价、哪些使估值失去可靠基础。

### 5. 安全边际：把经营认识转化为价格条件

#### 5.1 当前价格与估值背景

列示适用的PE、PB、现金流收益率、股息率、历史区间和同业比较，明确利润、净资产、现金流及交易日期口径。价格处于历史低位只是背景，不能证明便宜。

#### 5.2 正常化盈利及现金流

剔除或单列一次性损益，分析营运资本释放、维持性与增长性投入；用跨周期历史和业务驱动说明正常化基数为何合理。需要净现金调整时，完成可用资产、债务、租赁及其他权益桥接。

#### 5.3 正向估值

选择适用模型，列参数、理由、结果及敏感性。采用DCF时区分FCFF／FCFE、匹配折现率和权益调整，并展示终值依赖；无法完成口径桥接则保留缺口，条件演算不能升级为确定内在价值。

#### 5.4 反向估值

在明示的参数体系中求当前价格隐含的增长、利润率或回报条件，与经营证据比较。同时说明哪些其他参数也能解释当前价格，不把单一模型的解称为市场唯一预期。

#### 5.5 情景与交叉检验

- 悲观、中性、乐观情景须改变具体业务驱动，写明成立条件。
- 区分终点股价、分红、今天的折现值与持有期总回报，避免重复计算现金与股息。
- 按业务选择利润倍数、股息、资产价值或分部估值作独立检查；不要求每家公司全部模型齐全。
- 解释模型差异的原因，再给有条件的价值范围，不能把几个模型简单平均。

**建议输出：** 估值快照、参数表、情景表、敏感性表、反向估值条件、交叉检验与综合价值判断。安全边际同时评估估值折价、经营韧性、资产质量和判断可信度。

### 6. 逆向机会扫描：区分暂时被嫌弃与永久受损

保留参考报告的六问，但通用化名称和回答：

1. 是否遭遇短期利空，市场悲观是否有价格或估值证据？
2. 长期经营逻辑是否完整，现金创造是否仍可持续？
3. 分红／回购是否持续，是否由现金能力支持？
4. 品牌、客户关系和竞争优势是否受损？
5. 盈利是否增长或能正常化恢复，低价格是否仍可解释为低估？
6. 控股股东或管理层是否增加经济敞口，行为能否支持其信心？

**建议输出：** 问题、是／否／部分／未知／不适用、证据、限制。不要只数“是”得出买入结论；成长型、低分红企业可以不符合这一筛选，也不因此成为坏公司。

### 7. 核心数据：用紧凑表格承载判断的共同底座

#### 7.1 跨年经营与盈利

通常覆盖五年、周期低谷与最新可比期间：收入、归母与扣非利润、增速、EPS。必要时延长到完整周期，不用半年度直接与全年比较。

#### 7.2 回报、现金与财务健康

按适用性列毛利率、净利率、ROE／ROIC、周转、CFO、资本开支、自由现金流口径、债务、流动性、研发、股东分配，以及关键资产与负债风险。

#### 7.3 行业经营指标

制造业看销量、产能、单位收入及产品结构；消费看门店、同店、复购及渠道；软件看订阅、留存、获客与经常性收入；金融公司改用资产质量、资本充足与相应估值体系。只选解释经营机制的指标，不机械填满清单。

**建议输出：** 近年财务表、回报及健康表、行业经营表。核心数据汇总事实，前文负责解释，不在此重复整篇分析。完整逐项核对单独保存，不作为报告末尾长附录。

### 8. 决策与跟踪：把结论写成可被新证据改变的判断

- 综合经营质量、管理层、竞争优势、资本回报和价格，明确支持及保留意见。
- 区分价格吸引力、持有逻辑、估值兑现与逻辑破坏。
- 给出改变判断的经营证据、估值条件及下一次观察事件。
- 风险条件、观察指标和机械买卖指令分开；指标异常先判断机制是否改变。
- 若要给个人仓位或操作安排，需要投资者期限、组合、资金需求与承受能力；缺少这些信息时保持公司研究层面的条件结论。

**建议输出：** 决策条件表（状态、成立依据、失效条件、跟踪项）；最强多空论点；一句话概括可能回报来源和主要代价。明确资料缺口是否足以改变决策。

## 资料组织与展示

资料优先级沿用已讨论约定：本地已验证SQLite财务原值 → 本地正式财报及parse、附注 → 公司及监管公告 → 可定位的行业原始统计和同行正式报告 → 机构研报 → 其他二手材料。该顺序不表示数据库能替代所有资料：附注、制度、客户价值和竞争机制需要相应原文。

机构研报用于提出假说、比较预测与发现资料线索；实际数据、机构预测、公司计划、本报告假设分别标注。财报parse用于定位，错位或粘连表格返回PDF原页确认。

每章应有简洁来源指向；末尾按文件或数据集合并列参考资料。完整原始值、单位、报告期、来源、计算输入和核对结果保留为独立附件。正文只说明改变结论的重大口径差异和矛盾，遵循用户不逐条展示核对的偏好。

## 完整性验收

| 检查 | 完成标准 |
|---|---|
| 商业模式 | 解释客户价值、盈利机制与资金需求，指出至少一个增长约束 |
| 治理与文化 | 有真实制度、行为或决策证据，不以口号代替评价 |
| 竞争优势 | 说明机制、验证证据、变化及潜在颠覆，不只列优势名词 |
| 风险 | 包含最强反方解释及历史或周期检验，不只列通用风险 |
| 资本回报 | 解释历史与新增资本回报、留存及再投资关系，不只报ROE |
| 估值 | 正常化基数、业务情景、敏感性与失效条件可解释；不适用模型可以省略 |
| 逆向机会 | 区分暂时压力与永久损害，未知项明确留空 |
| 数据 | 时点、单位、口径及关键勾稽一致；详细核对不占正文 |
| 决策 | 支持、反证和后续修改条件能对应前文，没有无来源的新判断 |

框架允许有充分说明的资料缺口；不通过堆字数、表格数或星级弥补缺失证据。参考报告的结构可以复用，具体阈值、参数、结论和操作比例不能跨公司套用。
