# 宇通客车案例与验收

项目内样例目录（可能未随 Git 分发）：`data/research_reports/sh600066/2026-10-05/`。需要样例时读取，不把案例结论或日期套给其他公司。

`report.html` 是交付版，`report.md` 是事实宏模板，`report-readable.md` 是数字展开版；`facts.json` 保存全部事实、来源与公式，`case-evidence.json` 保存人工核对的PDF页和补充网络资料，`valuation-config.json` 与 `valuation.json` 分开保存假设和计算。原财报留在正式目录。

已观察到的易错点：
- 年报PDF第13页客车产品收入3,622,876.43万元，成本2,712,654.55万元，毛利率25.12%；parse把两列金额粘连。单位转换与收入成本毛利勾稽必须同时通过。
- 地区表与产品表合计不同，暂缺口径桥接，不能强行归一化；地区毛利不能写成归母利润。
- 新浪关键指标的BIZTOTCOST虽可能显示为营业成本，实际是营业总成本；只读BIZCOST计算毛利。
- 2026H1合并CFO/归母利润约318.55%，不是203%，也不是严格归母现金流。
- 年度归属DPS与最近365天除息DPS不同；分红方案与已实施事件分开。
- 机构报告的原文日期、索引日期、首页价格和附表价格可能不同；其预测表或历史列不能自动覆盖正式实绩。

重跑测试：`python -m unittest discover -s scripts -p test_research.py`。16项测试包括单位错位拦截、毛利勾稽、有效零保留、缺值留空、同报告期gjzb优先、BIZTOTCOST排除、后发数据过滤、读库写操作拒绝、路径越界拒绝、源引用与估值口径校验。测试只使用临时SQLite。

首版保留原目录；扩充版位于 `v2-expanded/`，补读公司行动方案、评估、8月调研及金龙与中通年报，正文179个引用事实、18张表。自动检查不证明研究观点正确；机构预测是作者观点，利润/PE及DCF均明确标为条件假设。已有同年度同行财务比较，独立行业明细、净现金与正常化FCFF仍有缺口，参考DCF复算不能称为已核验目标价。

按新框架重写的版本位于 `v3-framework/`：开篇六维摘要与八模块齐备，26张表、203个不同事实引用。新增十年周期对照、经营驱动的五年股权总回报情景、EPS与非经常金融项目分析、欧洲服务中心实施证据，以及完整治理、护城河、风险和决策条件。重新只读采集本地数据，与复用财务原值比较无差异。独立复算股息／末期售价折现和IRR；桌面与窄屏检查正常，内部来源锚无失效。

按用户偏好，默认不逐项展示数据核对；正文仅解释重要差异，末尾按原始文件合并来源。完整事实与核对保留在 `facts.json`、`validation.json`。后续报告遵循相同展示方式。
