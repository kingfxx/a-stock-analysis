# 指标与估值边界

`valuation.py` 支持 `mode=pe_scenarios`：输入股数、行情基准价、每个情景的归母利润与PE、假设说明，输出股权价值及每股值。利润PE估值不再加净现金；情景标注为自身假设，不能包装为实绩或确定目标价。

金额以元保存，来源原值/字段码/单位保留；百分数以数值百分点保存，例如 38.03 表示 38.03%。`OPNCFTONP` 等来源原比值不是百分数，不按显示格式统一换算。

利润、收入、CFO、CapEx 是累计流量；余额为期末。年度/中报的同比必须同长度，TTM 可用“上年度全年＋本年累计－上年同期累计”，仅对三期同口径流量。ROE、EPS、周转率不相加相减。非正同比基期不生成看似常规的增长百分比。

本工具毛利率 = `(营业收入−营业成本)/营业收入`；营业总成本包括费用，不作毛利成本。合并净利率 = 合并净利润/收入；归母利润率另命名。现金转化 = 合并 CFO/归母利润，必须标明跨主体分母，其比例不是严格归母现金流。

简化 FCF = CFO−购建长期资产现金支出，不自动等于 FCFF 或 FCFE。未扣并购、未区分维持与扩张投入；正常化需要考虑营运资本、周期、资本开支及一次性项。估值不得仅按最近三年平均宣称“正常化已验证”。

DCF 资料核对先检查本地 gjzb 的 FCFFPS（每股企业自由现金流量）和 FCFEPS（每股股东自由现金流量），保存原字段、单位、期间和来源。适配器以 source_fcff_per_share / source_fcfe_per_share 抽取，不自动认定是已核验的估值基数：需要确认来源公式、股数分母、租赁和合并／归母边界，不能直接乘当前股数放大成历史总额。再逐项核对 lrb 的利息、所得税、少数股东损益，fzb 的现金、债务和权益，llb 的借款流入、还债、少数股东分红及投资付款；附注补分项现金利息、租赁和受限现金等。区分“数据库缺字段”“本地已有尚未抽取”“口径未桥接”和“未来估值假设未论证”，不把未完成分析笼统写成缺财务数据。没有维持性／扩张性分拆也不必然禁止模型：全额资本开支法或显式情景可用于注明边界的演算，不能称作已验证正常化基数。

借款字段缺失不推断为零；一年内到期非流动负债可能含租赁/其他项目。债务附注不完整时不自动算完整净现金。货币资金还可能受限，交易性金融资产未必都是可加回现金；净现金的估值参数需要单独证据。

分红按归属年度和实际除息日分别记录；同来源/跨来源事件去重并检查金额冲突。金额估算必须使用该次分红基准股数或正式总额，不能用当前股数补所有历史分红。按支付日计算过去12个月每股现金分红；用同年度实施分红/同期归母利润估算年度派息率。送转股导致每股历史值不可直接比较时停止简单累计，提示调整。未来拟分红不作为已实现收益。

## 分红与股息率的三年持续性分析

这是用户要求的默认分析窗口。以研究截至日所在年份 Y 为准，展示 Y−3、Y−2、Y−1 三个完整日历年度。例如研究截至日为 2026 年，展示 2023、2024、2025 年；2026 年中报已经在截至日前正式披露时，再展示 2026 中报。尚未披露当年中报时只展示前三年，不按月份猜测披露状态，不使用截至日之后的公告。某年度年报或分红方案尚未披露时保留该年并写待补，不换成更早年度冒充窗口齐全。

在第五章“股息率锚定交叉校验”中加入 **近三年分红与股息率持续性** 表，表头为：**期间｜每股现金分红｜派息率｜期末市值口径股息率｜分红构成及状态｜持续性判断**。原快照的 TTM 和最近完整年度股息率两行继续保留，完整历史表不在其他章重复。第七章“分红”行引用三年趋势及当年中报，第二区资本配置评价、第六章逆向扫描、第八章决策用同一份历史证据。

- 每股现金分红按利润归属年度汇总中期、年度及特别分红；记录各部分已实施、已宣告待实施或仅拟议，并在表中拆分金额。年度完整方案合计与其中已实施部分分别注明，不能把只抓到的已实施事件当作完整年度方案。特别分红单列，避免误认作经常性派息。
- 派息率用归属同期现金分红总额／同期归母净利润，不用当前股数反推历史总额。当前中报只用归属当年上半年的分红／同期归母净利润；同期可比需要补充上一年中报或可比中期分红，不拿全年派息率作直接同比。分母为零或负值时解释，不机械展示常规派息率。
- 用户指定历史年度股息率采用“归属当年现金分红总额／当年末市值×100%”，不用当前价格或当前市值回算历史年度。分母优先从本地 sw_cap_facts 取对应年末最后交易日的 total_cap，记录实际交易日、元／亿元、import_id 和来源引用；解析 sw_cap_provenance，而非将行内兼容占位 {} 视为无来源。同一日期有版本时核对修订与冲突；核验原始响应哈希及指标定义。只有对应历史日缺有效值或口径不符时，联网搜索可核对的历史市值来源；不得用其他季度或当前值填补。
- 当年中报采用“归属上半年现金分红方案总额／六月末最后交易日市值×100%”，注明“半年方案、未年化”，不使用尚未发生的本年年末市值。待实施／拟议方案不计入已实现 TTM 收益。年末股息率是事后按利润归属期比较，不意味着年末已支付后来宣告或实施的股息，不能称为当时已知的 TTM 收益率。
- 分红总额和市值必须核对公司／股类／币种边界。A股报价乘全部股数的“总市值”须明确是同价等价市值，不能写成 A＋H 两市场实际总市值；只取A股市值时不能拿全体A＋H分红作分子。用各次真实分红股本估算总额时注明估算及回购股扣除边界，不能用年末股数或当前股数重算历史分配。缺适用历史市值留空并标待补。
- 核对三年及当年中期的现金分红总额、归母利润、经营现金流、资本开支、债务及一次性收益，分析派息的现金支持。区分“连续派息”“金额稳定／增长”和“高股息率持续”三个判断；价格下跌也会抬高收益率，不能仅凭收益率上升认定分红改善。
- 结论明确哪些年度有分红、每股金额及派息率怎样变化、是否依赖特殊收益／特别派息、当年中报是否延续以及哪些条件会打断。三年连续分红仅是持续性的证据，不证明未来必然维持。不能默认“逐年上升”或“不是一次性事件”；结论由数据决定。

先从本地 `dividend_events` 核对各年度及当年中期记录，完整可用时直接复用，不先联网。本地取数器只自动提取已实施事件，不自动提供完整年度方案、特别分红分类或待实施中期分红；需要先检查本地表内其他状态与正式财报，再对实际缺口联网补对应年报、中报、利润分配及实施公告，通过 add-evidence 登记。详细来源优先级见 local-sources.md 的分红规则。数值、公式及来源仍保存在事实账本，正文来源集中到第五章末尾。未分红须有资料支持才能填零；事件记录缺失写待补。

## 估值工具

`valuation.py` 接受显式参数JSON：`mode` 为 `fcff` 或 `fcfe`；`cash_flow_basis`、`base_cash_flow`（元）、`discount_rate`（小数）、`discount_rate_basis`（fcff必须WACC，fcfe必须cost_of_equity）、`terminal_growth`、`years`、`shares`（股）、`equity_adjustment`（元）、`scenarios`（预测期增速列表）、可选 `market_price`、`assumptions`（每个关键参数的依据）。

预测期第一年开始增长；终值 = 第N年现金流×(1+永续增速)/(折现率−永续增速)，折回期初。FCFF 得到经营企业价值后加适用净非经营资产、减债务及其他权益；FCFE 已是股权现金流，不再按债务重复调整。FCFE 的 `equity_adjustment` 固定为0；非经营资产需要先说明是否在基准FCFE中排除，再另行研究，第一版工具不自动处理。

折现率必须高于永续增长；股数、基准现金流和年数需有效正值。输出情景每股价值、终值占比、折现率敏感性及给定模型的反向增速。根求解不能括住市场价时返回缺失原因，不硬填结果。声明假设并不证明参数正确。

CFO−CapEx 简化指标可用于明确标注的敏感性演示；要形成正式FCFF估值，需重建利息、税、现金收益、少数股东、债务和净现金边界。工具能复现参考报告的算术，但不能证明它的45亿FCF和95亿净现金合理。

现金流折现估值中不再额外加同一时期分红；采用“期末售价＋中间股息”方法则逐笔折现。股息率锚只是一种条件价格，不能说明未来分红必然延续。强周期及多业务公司选择适用的正常化盈利/分部方法，金融公司不要套简化DCF。

### DCF交付执行检查

非金融企业已有全年CFO与完整CapEx时，先把能够核定的现金税、利息列报、租赁本金、少数权益及再投资逐项列成桥接表；未核定项给出来源、近似方法和影响敏感性。按实际列报区分经营与筹资现金利息，不能对CFO机械加回税后利息或重复扣税。使用条件FCFE时注明少数现金归属及债务续接假设，股权调整为零；条件FCFF则明确WACC与债务／非经营资产桥接。不得将财务费用直接称为实际现金利息。

除真实缺少基期输入、基期现金流不适用或企业类型不适用外，完成至少一组正向DCF、现价反向条件解、折现率／增长率敏感性以及至少一项营运资金或再投资基数敏感性；并把结果与PE／股息结论交叉核对。未做完分析不能登记为数据库缺数据。保存桥接明细、参数、输出与复算入口；若DCF显著低于原参考价，更新结论，不能只新增表格而保留原有安全边际表述。
