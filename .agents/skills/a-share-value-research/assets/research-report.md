# 宇通客车参考模板：固定报告契约

本契约来自用户提供的 `data/research_reports/宇通客车_价值分析_模版.png` 及局部截图。图片只用于结构与排版，不是事实来源。后续补图用于修订本契约。适用于本技能默认报告，优先于旧框架的“建议输出”、可选评分和可自由调整小节的约定。

## 固定规则

- 标题、章节顺序、小标题、表头、通用左列问题及行项目保持下列结构，不自行改名、合并、删除或换成另一种研究框架。
- 公司名称、日期、报告期、年度、事实、历史决策、对手、风险、论点、评分和结论按研究对象填写。宇通特有业务及案例不跨公司照搬。
- 缺数据保留对应项目，写“待补：所需资料；影响的判断”。口径不适用写“不适用：原因”。不得删除整块，不得用零、旧期或模板数字填空。
- 评分栏保留。有证据才填五级星标及简洁理由；不足时写“暂不评分”。不平均星级制造综合结论。资本回报阈值必须解释适用性，不能直接移植客车标准。
- 正文研究深度沿用原框架：判断、证据、机制、反证、验证条件嵌入原有段落、答案或说明栏。不要为这些内容改造表头或增加另一套正文目录。
- 事实引用宏、来源编号、计算冻结、原文核验及只读数据库规则全部保留；来源账本独立交付。正文每章保留简短“数据来源”，只展示重大口径差异。

## 开篇

1. `价值投资研究报告 - 公司名称（证券代码）`
2. 研究日期、生成方式、市场；明确行情日和最新财报期间。
3. 三个紧凑标签：信息丰富度评级、AI 可研究性、交叉验证状态。标签必须对应实际资料覆盖与校验，不能沿用样例结果。
4. `数据交叉验证提示`：只写重要差异及口径解释，不铺开核对账本。
5. `一句话本质`：一段概括生意和投资本质。
6. `Checklist 评分`，表头 **检查项｜评分｜理由**；固定六行：1. 商业模式、2. 企业文化、3. 竞争优势、4. 资本回报、5. 安全边际、6. 特色中巴。

## 一、商业模式分析

按顺序写八个加粗引导段落，保持段落式而非重做表格：

1. 生意本质
2. 是否是同质化竞争、常打价格战？
3. 为客户创造的独特价值
4. 产业价值链位置
5. 飞轮效应
6. 收入结构与现金流质量
7. 盈利能力与负债
8. 客户与供应商集中度

章末数据来源。

## 二、企业文化分析

先写三个加粗引导段落：**管理层与诚信**、**CEO 离开后能否照常运转？**、**最大的文化瑕疵**。

### 企业文化多维分析

表头 **维度｜问题｜答案｜评分**；固定前两列：

| 维度 | 问题 |
| --- | --- |
| 管理层 | 是否频繁变更、乱投资、高溢价关联交易并购掏空公司？ |
| 资本配置能力 | 研发回报率高？并购成功率高？股价低迷回购？持续分红派息？ |
| 股东利益一致性 | 管理层持股稳定？薪酬结构合理？减持与增发记录较少？ |
| 组织能力 | 团队稳定？关键人才流失风险？是否依赖某些关键人物？ |
| 长期发展 | 有无负面企业文化特征？是不是用户导向？能不能长期健康发展？ |

### 关键决策复盘

表头 **时间｜决策｜结果｜评分**。按实际历史选取代表性成功、失败及调整事件。结果栏解释当时信息、资本投入、外部因素和教训，不移植样例时间或案例。章末数据来源。

## 三、竞争优势分析

表头 **类型｜验证方法｜是否具备｜具体证据｜变宽/变窄**；固定前两列：

| 类型 | 验证方法 |
| --- | --- |
| 品牌 / 定价权 | 能否在不损失销量的情况下提价？ |
| 转换成本 | 客户迁移到竞品的成本有多高？ |
| 网络效应 | 用户越多产品越好吗？ |
| 成本优势 | 资源禀赋或规模效应带来的成本优势有多大？ |
| 技术壁垒 | 技术领先几年？能否被复制？ |

**关键追问：**固定四问，逐问写回答：

1. 给竞争对手相当于当前市值的钱，能否复制这门生意？
2. 护城河在被侵蚀吗？
3. 能被什么颠覆？这件事正在发生吗？
4. 近年份额在减少吗？

章末数据来源。

## 四、风险分析

风险主表表头 **风险｜概率｜影响｜说明**。风险行按公司实际确定，保留传导机制、状态、缓冲及剩余风险；不得虚构概率数字。

### 竞争格局与主要对手

表头 **对手｜市场份额｜竞争策略**。包含研究公司和实际主要对手；市场范围、期间、分母及不可比之处写入单元格。

### 特定风险分析

表头 **类型｜问题｜答案**；固定前两列：

| 类型 | 问题 |
| --- | --- |
| 竞争态势 | 行业技术趋势和竞争动态是否有风险因素？ |
| 周期影响 | 是否受经济周期、行业周期影响？ |
| 虚假资产 | 资产是否包含过多商誉、存货、应收账款？ |
| 财务矛盾 | 是否既有很多存款，也有很多贷款和财务费用？ |
| 股权结构 | 实控人是否稳定，有无质押爆仓、控制权变更风险？ |

答案栏可以附有依据的星标，证据不足注明暂不评分。

### 空方核心论点

用项目符号写公司最强空方解释：加粗论点后给证据与传导逻辑，不改成多空对照表。

### 历史类比

用段落写最相关历史案例、相同与不同之处及可检验结论。章末数据来源。

## 五、安全边际分析

快照表表头 **指标｜当前值｜解读**；固定行：股价、总市值、PE（TTM）、PB（LF）、股息率（TTM 口径）、股息率（最近完整年度口径）、FCF Yield、52 周价格区间、年初至今 / 近一年。年度随截至日期变化；不适用、未分红、缺资料分别说明。

### DCF 内在价值测算（正向）

参数表表头 **参数｜取值｜说明**；固定行：基准自由现金流 FCF、预测年期、折现率 r、永续增长率、净现金、总股本。说明栏明确 FCFF/FCFE、正常化、净现金桥接、终值及假设依据；不得重复加净现金。

**测算结果：**表头 **情景（FCF 复合增速 g）｜每股内在价值｜现价折溢价｜判断**。增长情景由公司证据决定，不固定沿用样例 0%/3%/5%/7%。

### 反向 DCF（当前股价隐含增速）

表头 **参数｜取值｜说明**；固定行：企业价值 EV、当前 FCF、折现率 r / 永续增长、隐含复合增速 g。下面用段落解释隐含预期及最强替代解释。

DCF 不适用或输入不足时仍保留以上小节及表格，明确不测算原因；在本节内说明适用估值法，不填伪造结果。

### 情景估值区间

依次用项目符号写 **悲观、中性、乐观**：业务驱动、利润与资本假设、倍数、持有期、分红、折现后价值及触发条件。随后两个加粗引导段落：**股息率锚定交叉校验**、**合理估值区间**。交叉方法不适用时保留标签并说明。章末数据来源。

用户追加的分红要求：在“股息率锚定交叉校验”下加入 **近三年分红与股息率持续性**，保留原快照表及大章节顺序。表头 **期间｜每股现金分红｜派息率｜期末市值口径股息率｜分红构成及状态｜持续性判断**；截至年份前三个完整年度各一行，当年中报已披露再追加一行。例如 2026 年研究为 2023、2024、2025，已披露时再加 2026 中报。历史年度以当年现金分红总额／年末最后交易日市值计算，优先本地 sw_cap_facts，缺失或口径不符再联网补来源；当前中报用六月末市值，半年不年化；完整方案、已实施及拟分红分开，特别分红单列。表后分析持续派息、现金支持及中断条件，不仅陈列数字。具体取数与比较边界见 metrics-and-valuation.md 的三年持续性规则。

## 六、特色中巴（逆向机会扫描）

表头 **#｜问题｜是 / 否**；固定六问：

1. 行业 / 公司遭遇短期利空、市场集体抛弃、股价大幅杀估值
2. 企业长期经营逻辑没有崩塌、现金流仍然正常、行业不会永久衰退
3. 企业的股息或回购并未停止，近年股息率逐年上升
4. 公司的品牌并未受损，竞争优势仍然较高
5. 公司的 EPS 仍然有正增长，但股价接近 52 周价格区间下限
6. 大股东、高管最近半年有大量增持，基本无减持

第三列直接写是、否、部分、未知或不适用并附理由与证据。随后写 **结论：**及有依据的评分；不机械数“是”得出买入结论。

## 七、核心数据

### 财务指标（近 5 年）

表头 **年度｜营收｜净利润（归母）｜增速｜EPS**。年度逐行展开，另列最新中期或季度累计；增速明确归母同比，营收同比在营收单元格注明。期间必须同口径。

### 盈利能力与财务健康

表头 **指标｜数值｜说明**；固定通用行：ROE（加权 / 摊薄）、ROA、毛利率、净利率、经营现金流、资本开支强度、有息负债 / 有息负债率、资产负债率、流动比率 / 速动比率、研发投入、分红、上市以来累计派现、应收账款。最后保留行业经营指标行，客车填销量，其他公司用适用指标。期间在行名注明。可在说明栏补充 ROIC、增量回报和现金质量，不另重做表结构。章末数据来源。

## 八、投资决策

表头 **状态｜建议**；固定行：空仓者、持仓者、卖出信号、加仓信号。建议为有条件的公司研究结论；没有用户组合约束，不填模板的仓位比例和机械交易指令，仍保留四种状态。

结尾提示框按顺序：**最终结论（综合评分或暂不评分）**、主要保留意见、**一句话**。多空分歧、回报来源、失效条件与正文一致。

页脚含研究性质说明、免责声明、数据截止及生成日期；实际参考来源简洁归并，详细事实账本另附。

## HTML 外观与验收

白底长文、黑色正文、中文无衬线字体；内容居中，桌面正文宽约 1120px，内侧留白约 40px。大章标题粗黑并加底部分隔线；小标题较小粗体。表格浅灰表头、细灰网格、极淡隔行底色，左对齐、顶部对齐；按参考列宽突出答案和说明。星标金色；结论框浅灰底配红色左边线，来源说明小号灰色斜体。摘要标签紧凑排列。截图红色圈选是批注，不作为报告装饰。

窄屏保证可读，宽表可横向滚动。HTML 不得擅自改成卡片仪表板或另一个视觉主题。现有渲染器输出后需检查并调整样式；保持事实与来源链接。框架一致不等于承诺每个像素或每段长度相同。

交付前逐项对照本契约：九个主块（Checklist＋八章）、全部小标题、表头、固定行及问题、每章来源、估值块及结尾提示框。标题齐全但内容缺失不能通过；缺口必须原位说明。资料不足应标为不完整报告，而非删掉小节宣称完成。
