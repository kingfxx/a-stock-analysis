# DCF 估值开发计划

日期：2026-10-14。协作模式：主代理规划/审查，执行代理开发；各代理仅更新本目录状态。用户指定本目录及小写文件名，优先于通用计划目录约定。

## 需求与实现边界

在个股「估值与分位」股息率旁添加 DCF 估值按钮，展开同风格模块。10年年末现金流折现、永续终值、悲观/中性/乐观、敏感性矩阵、年度明细；四参数默认为最近3完整年度FCF平均、3%、9%、2%，支持1/5年和手动基准。推荐值单独呈现，用户主动应用，所有参数浏览器内重算，不重新采集。

先提供明确标识的简化DCF。经营净现金流-CapEx没有可靠税后利息/非经营现金流桥接，不能认作FCFF或FCFE。总折现值、每股参考折现值、相对股价参考差额可展示，不能标为合理股权市值/合理股价/可投资安全边际。专业FCFF入口以数据缺口说明呈现，不使用货币资金或不完整有息债务作自动股权调整。

支持独立WACC估算器：人工输入并注明来源日期的国债收益率、Beta、ERP、债务成本、税率、债务权重；公式 Ke=Rf+Beta*ERP，WACC=Ke*(1-wd)+Kd*(1-T)*wd。系统没有这些可靠实时来源时明确缺失，9%是可覆盖的假设而非自动估算的WACC。

## 架构与数据映射

- Python 标准库 HTTP 服务 `quarterly_dashboard/server.py`，静态 `web/index.html` 和独立 JS/CSS。新增只读 `/api/dcf?code=...` 返回数据依据；仅调用现有 read 方法，不 ensure、不建表、不采集、不用模型。
- `FundamentalService.read` 读取现有 `financial_reports`/人工覆盖；`core.build_period_rows` 和 `view_rows(...,'year')` 复用 `free_cash_flow_ytd`。只用12-31完整年度，年度缺值不跳过凑齐窗口，基准不足留空。
- 现金流元、股本股、未复权价元/股。最近 `market_trade_snapshot` 的实际日期、来源、版本提供股本；报表实收资本未经验证不作为股数回退，缺可靠股数留空。现价比较已有交易快照和 `PriceService.read(...,'raw',lease=False)` 的有效日期，日期和回退均明示；过期和日期不一致警告。
- 历史增长：最近最多10年，逐年可比正基数增长中位数，同时展示收入/归母利润/FCF样本数、负值、波动；不足5年不称充分推荐，异常波动使用谨慎区间，不直接异常端点CAGR。
- 金融企业复用财务页面识别依据并提示不适用；周期行业和高终值占比提示限制。

## 公式

FCF_t=FCF_0*(1+g)^t；PV_t=FCF_t/(1+r)^t，t=1..10。
TV_10=FCF_10*(1+gt)/(r-gt)；PV_TV=TV_10/(1+r)^10。
V=sum(PV_t)+PV_TV；终值占比=PV_TV/V；参考每股折现值=V/总股本；参考价格差额=1-当前价/参考每股值（仅正值可算，不称专业安全边际）。
专业模式的必要桥接：FCFF=CFO+已在CFO扣除的税后利息-非经营现金流-CapEx（需核对利息归类和税盾），股权=EV-有息债务+经核实超额现金+未在现金流计入的非经营资产-少数股东权益及其他优先索取权；缺失绝不能默认0，租赁不重复。
