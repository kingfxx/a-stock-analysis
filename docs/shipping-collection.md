# 航运采集

统一入口为「后台维护 → 采集管理 → 航运采集」；月度（含图片）、周度和既有资料导入按数据类型切换，人工图片补正在月度下折叠展示。各任务保留独立operation、进度、范围和定时配置，定时默认关闭，导入仅手动。预测页面、模型计算及版本保存见[航运预测](shipping-forecast.md)；用户后续明确本次一并提交。

## 来源与范围

上海航运交易所／航运研究所共用真实提供方sse，交通运输部为mot。CCFI周度解析免费可见的综合及全部航线、上期／本期真实日期和公布涨跌幅；SCFI免费页仅综合有值，变动为点数。两种指数和不同统计区间保持独立。

交通运输部目录按标题年月识别中国出口集装箱月度指数及市场分析，不把URL年月当指标年月。默认发现范围从2022-12开始，可选起止日；按月选取，日部分不作为月内截断。月表分别保存上年均值、YTD均值、当月值和公布环比；西非／东西非保留原名。已校验分段普通增量／回填跳过，修订核对重新请求；失败归档可原范围离线重解析，校验通过后发布新分段，不改旧失败历史或原取得时间。

行业吞吐量保留指标期、报告月、披露日、单位、公布同比和原文范围；monthly、ytd、annual分别保存，不把累计量当当月值，全国／沿海／内河不强行平账。纯定性正文标记无披露，未知结构保留失败而非补造。

## 图片与本地资料

图片先通过公共来源归档，再进行本地OCR与多结果校验。运行依赖见requirements-shipping-ocr.txt及stock_analysis/domains/research/sectors/shipping/resources/shipping_ocr.ps1；不安装时不能将未知图片静默判定完成。低置信、冲突或未知布局保留待核验，可显式导入核验JSON：image_source_id、html_source_id、month、published_on、verified、rows。verified须为true，每行route、annual、ytd、monthly、change；保留图片／正文配对和核验文件证据，事实引用真实图片来源。相同核验文件重放不新增事实，不扩大声明覆盖。

既有研究资料导入为特定已核验Excel及研究快照的迁入器，需要data/verification/reports/ccfi-profit-lab及对应samples的本地研究文件。先校验Excel、14份PDF及逐页解析哈希，再复用正式company_reports存储；不是任意Excel导入器。原始Excel、日历推定和备注归档，转录／推定日期不冒充官方。原来源文件不随Git提交，资料迁移应包含公共归档及正式PDF。

## 公共调度与存储

默认航运策略同源单并发、请求后等待2—5秒、60秒最多30次、每20次额外休息10秒。管理页可显式保存限速模板／手调，来源锁、共享预算、拒绝即停、至少一小时和更长Retry-After冷却、恢复探测及重试等待保持公共机制；参数生效和范围见[采集管理](collection-management.md)。

v41迁移是已上线不可修改的共享存储前置，包含四张research_shipping_*表及引用约束；本次保留其完整校验历史，预测版本表用于保存显式生成的预测快照。采集使用shipping_forecast.py中的publish_rates和current_rates事实存取函数。数据修订引用公共source／batch，不逐行复制响应；执行成功不等于全历史覆盖。结构及维护时间依据见[SQLite存储](sqlite-storage.md)。

相关验证：来源样本解析、幂等修订、完整分段校验、来源外键、拒绝停止、取消、图片不确定性、原归档恢复、吞吐量期次／范围、共享预算与配置、管理页及窄屏菜单。全部自动测试使用隔离库／模拟请求。
