# 统一采集管理

## 个股模块（2026-10-27）

新增一个“个股采集”模块，内部选择股票/分组及八类数据，不按提供方拆卡片。手动可增量、全量或继续失败部分；页面的单股手动/全量也进入同一运行历史。分组各自保存日周月规则和所选数据项，同组可多条规则，不同主题和时间分别保存；已保存列表提供编辑、删除，也可用规则下拉选择编辑或新增。新规则默认关闭，保存不立即运行，定时只增量。删除只停止后续调度，已运行任务和历史保留；只显示当前频率适用的星期或月检查日，个股不提供发布窗口。

运行记录通过公共进度模板展示股票数据项成功、失败、待执行、停止和复用，并引用原公共来源证据及已记录入库数；缺计数不推算。详情包含固定成员与数据项、各项状态及sync run引用。整次任务可请求停止，批次执行成功不代表覆盖完整。个股模块的批量限速只作用分组、多股、定时，单股页面速度例外不变；任何个股operation运行时也禁止保存限速。

个股已取消打开页面的到期采集。首次初始化、显式手动及分组定时为三类触发；已有股票只读缓存，定时失败不由访问补采。详细范围、初始化兼容和存储边界见[个股采集说明](stock-collection.md#当前触发与统一管理2026-10-27)。本节覆盖下方历史记录中“个股尚未决定/不注册自动任务/不套用管理覆盖值”的旧描述。既有其他任务日程和授权不变。

后台维护默认打开「采集管理」，随后是「数据库预览」「未关注股票管理」，已有「投资笔记设置」继续保留。刷新只作用当前面板。数据库预览首次进入才请求 storage；清理完成在隐藏页只标脏，下次进入预览再刷新。任务轮询只在面板可见且存在运行任务时进行，不读取 storage、事实全表 COUNT 或物理页。

## 已实现任务与操作

任务目录见 [TASK_CATALOG](plans/20261025_统一采集管理/TASK_CATALOG.md)。全市场财务、季度快照、指数、拥挤度及已有国债增量均复用原采集器。手动默认增量；历史初始化、回填及范围操作显示参数并要求确认。行业任务暂不开放用户取消，失败后按相同范围续跑；指数／拥挤度／国债提供请求停止。批量采集入口统一在本页；原行业、指数、拥挤度页面仅保留只读进度和前往采集管理的导航。执行继续复用真实领域operation及数据库短事务互斥。

财务／快照自动检查只运行保存的单个目标报告期／季度，需主动更新目标；不自动扩大历史范围。个股到期检查、收费数据工具、正式财报和模型不注册自动任务。航运统一显示为一个「航运采集」模块，内选月度（含图片）、周度或既有资料导入；月度图片自动解析，人工补正在月度下折叠展示。内部保留周度、月度和两个手动资料导入适配任务的原身份与记录，详见[航运采集](shipping-collection.md)。

## API与证据

- `GET /api/maintenance/collections`：九个显式注册适配任务（页面合并为六个模块）、白名单模式、最近20次领域历史、最近运行至多100个公共分段、来源冷却、最近10个定时槽位。
- `GET /api/maintenance/collections/operation?task_key=…&operation_ref=…`：显式点击时读取该任务的完整领域运行结果；列表SQL仅投影计数／进度摘要，剔除来源清单、逐字段计数和工作项明细。
- `GET /api/maintenance/collections/evidence?batch_id=…`：该分段最近200条来源元数据，包括状态、时间、归档路径及双哈希；不下载文件。
- `POST /api/maintenance/collections/run`：`task_key,params`。
- `POST /api/maintenance/collections/cancel`：`task_key`，仅支持真实取消的任务。
- `POST /api/maintenance/collections/schedule`：`task_key,schedule`，只保存配置。schedule包含布尔enabled、local_time、rule及白名单params。

不接受任意URL、函数、shell或cron。写接口沿用本地Origin／JSON校验和RequestGate。最近检查取最近运行关联source.obtained_at；最近成功取最近20次运行中的领域finished_at。没有记录显示未记录，不以数据日期替代。分段的执行状态和coverage_status分开，全历史／逐字段覆盖仍可能未知；成功不自动变成完整覆盖。历史详情保留原采集器进度及请求／行数，不混算为任务数。

## 日程与恢复

服务器仅启动一个 `collection_management.Scheduler`，每30秒检查，在原8765生命周期内运行。未注册来源不会执行。旧 `market_congestion.DailyScheduler` 类保留兼容，但服务器不再启动它。

拥挤度原collection_schedules记录不重写。默认每日规则继续调用原scheduled_tick，保留初始化门槛、到期时段内成功HTML检查复用、冷却和metadata_only；已有开关、北京时间不改变。其他任务没有配置记录时默认关闭。用户保存启用即授权该任务所填范围。保存不执行采集；新增规则从保存后下一个未来槽位开始，停机重启不修改配置时间，错过的槽位合并到最近一个，不逐日重放。

规则均按Asia/Shanghai计算：daily；weekly+weekday（0周一—6周日）；monthly+day（1—31，短月按月末）。财务／快照可设monthly+window=[起日,止日]，窗口内逐日检查明确目标。只有原任务无失败且目标相关公共分段明确coverage_status=complete才停止重复检查；unknown不当成完整，窗口外只合并最后一个必要检查。航运周/月任务可独立保存日周月规则，默认关闭；两个资料导入任务仅手动。正式财报单份准备仍需预测页明确操作，不纳入航运批量定时。

新定时槽位唯一键(task_key,slot_key)。数据库短事务同时领取槽位与创建领域operation，提交后才联网；多个进程／页面不能重复领取或绕过领域互斥。公共batch通过operation_ref关联记录真实scheduled触发和槽位，不复制响应及整份运行结果。来源锁、预算、拒绝停止及冷却原样复用。来源冷却期间不消费新槽位，解除后由公共层执行恢复探测。

启动先执行原领域恢复，再将未完成定时槽位标pending；同一槽位最多自动恢复一次，仍失败保留failed，后续新周期可再次做增量检查。跨多期恢复合并到最新槽位。关闭自动开关不取消已执行任务；安全停机内部只对本调度器的领域任务发送取消，并等待退出。财务／快照为停机新增内部cancel_requested及公共collector回调，不因此宣称支持用户取消。数据库恢复／压缩门禁覆盖整次定时执行，未排空时不能替换数据库。

## 进度与提供方交互、统一漏跑规则

进度不再额外放置无时间戳摘要；记录按启动时间倒序，默认展开最新一条，无论完成或运行中。用户手动折叠/展开的状态在轮询中保留，新运行出现时展开新记录。最近运行的公共分段默认折叠，用户展开后刷新保留状态。手动及自动检查来源均使用有界高度的下拉多选，表单仍提交provider白名单数组；支持键盘打开、Esc关闭、点击外部关闭，轮询保留所选来源。

用户确认将拥挤度漏跑规则统一为指数规则。所有每日任务使用相同北京时间最近到期日期计算：已提前启用18:00检查，当天22:00启动服务补当天槽位，次日09:00启动补前一天槽位，多天停机合并到最近一次，不逐日重放。同槽位已处理不重复；首次/重新保存启用从下一个未来时间开始。关闭网页不会停止运行中的8765后台。

拥挤度继续使用既有operation日期唯一键与原HTML采集器；到期时段中已经成功的手动/依赖HTML检查可跨午夜复用，不触发重复来源请求。失败/冷却策略、初始化及metadata_only不变。检查槽位表示计划检查时间，不强迫来源生成对应日期的数据；实际更新仍按本地水位与来源已发布数据，缺失不补造。

## 折叠限速设置

每个网络任务在进度区域后提供默认折叠的「限速设置」，按真实提供方分别显示当前参数、配置时间和支持的并发上限。模板选择只填表，点击「保存限速设置」后才生效；页面刷新保留未保存编辑。未保存自定义配置时，当前参数来自原采集器，不自动换成保守模板。默认模板为10秒+0—5秒、5次/60秒、每20次休息60—120秒、单并发；较快模板使用该任务既有提速起点，拥挤度／国债为2—5秒、30次/60秒、每20次休息10秒、单并发。

可调间隔（1—3600秒）、随机等待上限（0—600秒）、60秒请求上限（1—60次）、每次休息对应请求数（1—1000次）、休息最短／最长（0—3600秒）及能力内并发。中证、申万与全市场财务支持1—2，其余支持1；参数是HTTP在途上限，不能增加工作项或改动页序。默认、较快之后仍可手调。拒绝立即停止、至少一小时和更长Retry-After冷却、重试次数和60／120秒等待固定。拥挤度仍只尝试一次。

保存仅写collection_rate_limits；任何指数／拥挤度／国债／航运或行业operation运行时均禁止保存，避免中途更换策略。下一次手动和定时任务共用保存值，仍读写同一collection_provider_state，预算和冷却不清零。公共批次在第一次请求时记录实际自定义策略快照，不复制到事实行。个股与未注册历史CLI不套用管理页覆盖值。辅助分类／日历等非该任务已登记提供方保持原策略。本地导入说明无需网络限速。

接口：列表GET /api/maintenance/collections包含rate_limits；POST /api/maintenance/collections/rate-limit只接受task_key、provider、settings，沿用同源及维护门禁。存储为v42迁移。2026-10-25用户明确本轮完成后不要重启后台，故本次只做隔离库验收，原8765及正在运行的采集保持不动；正式库迁移与真实页面验收待后续允许重启。


后续历史航运解析修复中，用户明确允许重启原8765并恢复。2026-10-25已完成该次重启，正式库v42迁移随启动应用，前述“待后续允许重启”状态至此解除；航运原范围归档恢复成功，既有配置保留且航运自动检查仍关闭。记录见docs/plans/20261024_ccfi海控利润预测/ACCEPTANCE.md。

## 公共入库数量模板

采集管理的全部已注册任务、最近20次历史和当前进度共用 `collection_progress.py` 适配层及 `collection-progress.js` 展示模板。按提供方与数据项显示已记录写入、新增、修订、补全（有记录时）、未变化、返回／解析条数，以及复用／跳过分段数。正在运行时显示已记录的发布结果，不能代表最终覆盖完整性；没有计数的旧记录显示“未记录”，不推算为0。

| 任务 | 统计依据／口径 |
|---|---|
| 指数估值与行情 | 公共发布分段的inserted/revised/unchanged及price_counts，估值和行情分开；不混入后续派生补算 |
| 全市场财务四表 | 按四个接口分别显示new/revised/enriched/unchanged；实际写入=new+revised+enriched，published_count含未变化，不当成新写入 |
| 季度交易快照 | 公共快照分段的inserted/revised/unchanged；跳过的旧快照本轮写入0，不能复制上轮计数 |
| 拥挤度 | 按API／页面渠道显示发布计数，返回／解析条数取rows |
| 国债收益率 | 按年度事实发布分段统计，返回条数取total；初始化发现请求和manifest不计为另一份事实写入 |
| 航运周度／月度／资料导入 | 既有published是实际写入总数；旧记录不能区分新增、修订、未变化时对应项显示未记录。周度返回／解析条数取visible_points；复用分段本轮写入0 |
| 航运图片核验导入 | 发布仍引用原图batch，本次运行从自身channels.published读取计数，避免拿旧batch总数冒充本次写入 |

公共分段在SQLite中仅投影轻量计数字段后按运行、提供方和数据项汇总，覆盖运行的全部分段，不受公共分段展示100条上限影响；不扫描事实表、不读原始文件或改写旧记录。存在部分分段未记录写入数量时明确提示，已记录数量不冒充完整统计。新采集器使用公共batch的inserted/revised/unchanged（或明确的published写入总数）、returned计数即可接入模板；特殊字段／口径在适配层登记，前端不新增任务专属渲染。

明确记录返回／解析0条时，摘要和黄色提示注明分段数及日期范围；失败的空响应也提示并保留失败状态。新增0、published=0、空覆盖状态、缺计数和复用旧分段都不能单独证明来源为空。未变化表示重复值，不是新写入。页面读取和统计不会触发来源采集，来源预算、定时和证据策略保持原规则。
