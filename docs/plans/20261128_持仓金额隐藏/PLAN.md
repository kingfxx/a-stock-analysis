# 持仓金额隐藏

- 持仓页在公共侧栏卡片下方提供独立按钮，统一切换四个标签页的显示状态，浏览器保存开关。页面脚本直接渲染固定占位符 `****`，计算和接口使用原始值。
- `portfolio.js` 管理开关、快照和流水重绘。持仓快照保留现价及百分比，隐藏数量、成本、金额和对账数值。历史成交和转账隐藏金额相关字段及筛选输入，隐藏期间收起导入和手工录入入口。
- `performance.js` 重绘金额卡片与日历，隐藏资产轨迹并清除金额图，趋势与日历自动切换收益率。保留比率、基准和日期。权限、数据写入和后端无需修改。
- 验收四个标签、图表悬浮与日历明细、展开对账及分户、筛选、刷新和恢复，使用宿主 8765 原库，只读。
