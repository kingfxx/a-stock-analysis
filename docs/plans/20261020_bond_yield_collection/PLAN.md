# 国债收益率历史采集与指数估值入口整合方案

## 目标

接入 AKShare `bond_zh_us_rate` 所使用的东方财富中美国债收益率数据，采集其全部返回字段并保存在本地。第一次采集从 2002-01-04 到最近可用日；初始化中断优先恢复未完成分段，完成后按自身水位补尾并刷新有界近期窗口。将操作整合进指数页「更新近期估值」按钮，与现有指数增量采集共同显示进度和结果。

本计划只覆盖采集、存储、来源追溯、增量调度及按钮整合，不在本次实现股债利差派生指标或估值信号。页面仍只读本地数据；仅用户点击现有按钮时发起请求。

## 已核实依据

- 宿主机安装 AKShare 1.18.30，`bond_zh_us_rate(start_date='19901219')` 实测返回 9,370 行，日期范围 1990-12-19 至 2026-10-20。
- `中国国债收益率10年` 最早非空日为 2002-01-04，至 2026-10-20 共 6,192 条非空日度记录。
- 接口原始数据按分页返回。AKShare 源码当前使用 `datacenter.eastmoney.com/api/data/get`，单页 `ps=500`；SDK `start_date` 是客户端停止/过滤条件。2026-10-20宿主机公共RequestCollector实测另行确认服务端 `filter="(SOLAR_DATE>='2026-10-01')(SOLAR_DATE<='2026-10-10')"` 生效：从无筛选9370行/19页缩至8行/1页，首末日10-10/10-01。原文证据在日常库 `collection_sources`，probe dataset为 `macro.sovereign_yield.probe`，source4155为首页、4156为筛选样本。正式采集采用服务端固定日期闭区间，并继续客户端校验边界；所有分页经公共 `RequestCollector`，不直接调用SDK的内部网络请求。
- `bond_zh_us_rate` 标准化返回的 13 列：`日期`；中国国债收益率2年、5年、10年、30年及10年-2年；中国GDP年增率；美国国债收益率2年、5年、10年、30年及10年-2年；美国GDP年增率。数值单位为百分数原值（如 1.65 表示 1.65%），不转成小数。
- 当前指数页面 `web/indices.html` 的「更新近期估值」按钮触发 `mode='incremental'`，共用 `index_collection_operations`、进度接口和公共采集组件；各指数来源用各自水位，只补最后完整批次之后的交易日，最新时跳过来源请求。指数已有特定提速授权只适用于已列明的中证、乐咕、申万来源；东方财富国债接口不继承该提速策略。

## 范围与非目标

- 点击时先查同定义的未完成初始化清单并恢复；没有清单且没有事实才创建2002-01-04起初始化。只有已完成初始化清单才能进入普通增量；不得因倒序首段产生了最新日期事实而误判初始化完成。无需另设独立历史采集按钮。
- 采集接口提供的所有字段，不只10年期收益率。接口没提供的国家、期限、实际债券券种或其它宏观指标不补采。
- 不迁移、不回填既有指数估值或原始采集表，不重新请求旧指数历史。
- 不增加定时任务、不由页面读取触发请求。
- 暂不把股债利差写入数据库；未来计算应作为可追溯派生值，按指数、PE来源/定义及债券序列口径保持身份。

## 数据设计

新增独立日度事实表（建议 `sovereign_yield_observations`），每个来源定义版本、观察日一条逻辑最新事实，日期是市场观测日而不是写入时间。保存全部12个可空数值字段：

1. `china_2y`, `china_5y`, `china_10y`, `china_30y`, `china_10y_2y_spread`, `china_gdp_yoy`
2. `us_2y`, `us_5y`, `us_10y`, `us_30y`, `us_10y_2y_spread`, `us_gdp_yoy`

来源字段 `日期` 映射为 `observation_date`。百分数列不乘除100；差值、零、负值按来源原值保留。空字段为 NULL，不使用前值、插值或另一个数据源填补。字段含义、源字段、单位、频率及缺值行为同步写入 `docs/sqlite-storage.md` 及本任务设计说明。

表记录dataset/序列定义版本、`batch_id`、`source_id`、修订版本、内容哈希和真实写入时间；来源取得时间通过source引用读取。按日期和修订保存历史版本，以最大修订读取最新事实；相同数值不新增版本也不改原出处。数值使用可无损还原来源十进制值的格式，不能经浮点舍入损失精度。尽量复用公共来源/批次记录，不逐行复制提供方、请求JSON或响应。采集来源身份固定为 `eastmoney`（同域请求共享状态），dataset 标识国债收益率历史。新表在 `quarterly_dashboard/maintenance.py` 的 `DESCRIPTIONS` 登记为「宏观数据」；维护更新时间明确组合事实写入时间与关联 `collection_sources.obtained_at`，不得用观察日期替代。

如核实已有通用宏观事实表可无损容纳该数据，应优先复用而不重复建表；需先确认其字段定义、来源外键、修订、分类及时间规则全部满足本方案，再在 DECISIONS 记录替代决定。

## 采集与发布

### 统一采集基础设施

- 新任务复用 `quarterly_dashboard/collection.py` 的 `RequestCollector`、公共批次、来源原文归档、双SHA256、共享 `collection_provider_state`、锁、冷却、拒绝停止和取消能力。
- 提供方按真实请求域登记为 `eastmoney`；不得因按钮或接口名称另建预算。按公共保守策略执行：并发1、请求间隔至少10秒加0—5秒随机等待，滚动60秒最多5次，每20次额外休息60—120秒。网络重试与403/429拒绝规则沿用 `docs/agent-rules/collection.md`。
- 使用实际原始分页响应逐次登记 source；归档解码后原文与压缩文件哈希。所有分页、总页数稳定性和字段解析校验完成后再发布该批事实。等待、请求和归档不持有SQLite写事务；按已验证的日期段短事务提交，取消/失败保留已完成分段和证据。

### 首次初始化和分页恢复

- 第一次请求前创建公共 `collection_batches` 初始化清单（scope标明 `kind=initialization_manifest`），持久化固定起点2002-01-04、定义/解析版本、启动时点及年度范围清单。第一页有效后固定 `target_end` 为其最新观察日；此后取消、重启、下一次点击均沿用该目标，不随 `max(observation_date)` 变化。无有效第一页时清单保持待恢复，不能标完整。不另外新增一套operation或控制表。
- 按年度倒序发布（首年从2002-01-04起，尾年到固定target_end）；年度batch在scope中引用初始化清单id，记录实际范围、分页证据及执行/覆盖状态。完整清单只有所有目标年度都完成分页验证和发布后才能结束；逐字段未知覆盖仍保持unknown。恢复优先读取未完成清单和已完成年度，跳过相同目标/定义的完成段；清单结束后再计划目标之后的尾部增量。
- 每个年度batch使用已实测的 `SOLAR_DATE>=start` 与 `SOLAR_DATE<=end` 服务端闭区间，固定倒序排序和ps=500，避免全史新增行推动历史页码。仍遍历该区间全部页面，检查总记录数/页数稳定、页长、重复日期、日期方向、13字段/单位、客户端范围和起点；HTTP200空页、截断、总数变化或返回区间外行不能按完整发布。历史年度通常一页，但不得据此省略多页支持或校验。
- 实际HTTP来源直接归属对应年度batch，日期筛选使正常请求不跨年；无需额外实现跨年分配。确有可重放来源需用于另一批次时沿用公共 `reusable_source(db, target_batch, source_id)`，事实引用目标batch内别名，原文不复制、obtained_at不改、真实请求数不增加；适配器先校验同dataset/定义、日期范围和缓存时效，不能直接跨batch引用source。
- 保存年度固定filter、排序/页容量/总数/首尾日期及source引用。跨日恢复对未完成年度从其固定区间第一页重新获取，禁止拼接不同检查时点的未完成多页；已经完整提交年度保持原结果。年内历史修订仍可能改变页数/边界，检测到漂移就停止该未完成段，标可恢复，下一次点击从该年度第一页重试；不无限重试。无需实现无筛选全史页码的跨日定位系统。
- 日期范围事实按返回观测日入库；周末/节假日不预期必须有行。逐字段记录首末非空日期和空值数，特别核对中国10年期从2002-01-04起的实测覆盖。缺行与字段空值分别登记，没有可靠国家日历或字段发布依据时不宣称全覆盖。

### 增量更新与按钮

- `mode='incremental'` 中增加独立国债收益率工作单元；「更新近期估值」一次操作同时推进已选指数来源及国债收益率，进度按来源/日期段分别展示。新数据部分失败时保留其它来源已验证完成的结果，整体结果标为 partial/failed，并能恢复。
- 初始化完成后，普通增量取 `min(自身水位之后的补尾起点, 当前观察日之前14个日历日)` 起至当前可见最新日；长期停用按年度补尾。近14日重读用来捕获中美字段迟到和近期修订，不重放全史；页面文案说明「补新并核对近期14日」。本版不提供国债旧历史audit入口；更旧已完成历史保留证据，后续另行明确扩展审计能力，不借本按钮扩大核查范围。
- 新鲜度独立于指数日历与15点：分别记录中国（Asia/Shanghai）和美国（America/New_York）的最近有效检查时间、各字段最后非空日及待发布/未知状态，使用本地时区计算检查目标，不共用A股交易日。来源真实发布时间尚未核实时，采用保守可配置检查策略：有效响应6小时内可跳过重复请求；目标观察日暂以各自本地昨日作为检查参考，额外24小时作为迟到宽限，仅用于提示/再查，不能视为来源发布承诺。字段仍滞后或响应空时1小时后可再次检查；请求失败不推进有效检查时间。空响应记录执行结果，保留unknown覆盖，不能因已有max日期而跳过整天。一个接口响应可同时更新两国检查记录；缺一国字段不能把该国标为最新。GDP独立记录实际首末日期，不套日度收益率的完整性预期。实测发现可靠发布依据后才收紧分国策略，并记录依据。
- 来源复核数值改变时建立修订；NULL变有效值允许补入。任何已有字段由非空变空，整条候选版本暂不替代现有事实，记录日期/字段/候选source为待核实，批次标partial/unknown；其他无争议日期可发布。未解决候选保存在公共batch结果，每次点击先于新鲜度跳过及普通增量按候选日期闭区间重检，即使已超近期14日也不丢失；仍为空或没返回该日保持待核实，有效响应与已发布事实一致后记录resolved及解决batch/source，原候选证据保留。不得把旧字段拼进新source冒充完整新响应。没有可验证撤回证据时不得静默清空。相同内容不生成修订。旧历史审计留待后续独立扩展，不借近期刷新扩展用户范围。
- 当前控制器仅接受 `csindex/legu/sws`，最小扩展为可选 `datasets` 参数（例如 `['bond_zh_us_rate']`），旧请求省略时保持原行为；指数页「更新近期估值」按钮显式传入附加dataset。本版国债只接受incremental且不接受start/end，其他模式或显式日期应返回参数错误，不能静默忽略；旧providers和full/review/audit请求及页面按钮含义不变。国债可在自身模块独立计划日期，不复用指数算出的end。复用index operation互斥、取消和结果，dataset进度及异常独立登记；指数日历/来源失败不阻断可独立执行的国债工作项，反之亦然。
- UI 仍使用「更新近期估值」操作入口，并更新按钮说明：将同时更新指数估值与国债收益率；首次国债初始化会采集2002年至今，可能耗时较长，显示共享进度；之后补增量并核对近期14日。指数已有来源的提速提示保持准确，另行说明 `eastmoney` 仍使用公共保守限速。状态应明确初始化、恢复未完成年度、补增量、近期核对、无新增、部分失败、冷却等待、可恢复/取消。

## 覆盖、恢复与验收

- 分段幂等键包括 provider、dataset、数据范围、字段定义版本、解析版本及触发模式；只有相同范围/定义且验证完成的batch可恢复跳过。
- 拒绝后立即停止全部本轮 Eastmoney 请求并共享冷却；不可用代理/IP轮换或更换域名绕过限制。
- 隔离库中模拟分页、接口字段顺序变化、分页截断、空页、跨页重复、总页数变化、日期缺口、缺值/有效负值、同日修订、来源拒绝、暂停/取消和失败恢复；验证Eastmoney预算与指数并发任务跨进程共享。必须覆盖「已发布最近年度、旧年度未完成、重启再次点击」仍初始化恢复；来源同batch外键/真实取得时间；年度固定filter不受区间外新增行影响、跨日未完成年度从第一页重取、多页漂移停止；普通增量捕获同日迟到美国字段；有值变空保留旧值并报待核实；两国跨午夜/美国夏令时/周末、空响应后到期重查。来源复用仅验证实际采用路径，不强制构造无必要的跨年发布机制。
- 已完成两次公共RequestCollector真实样本，证据source4155/4156如上；root保留原文与验收报告，Luna使用隔离模拟响应实现。只有新的未解决接口问题才追加少量真实请求，禁止大规模试封禁阈值；SDK start_date的客户端语义与已实测服务端filter能力分别记录，避免混淆。完整历史采集由本任务授权范围和运行入口执行，不借样本验收绕过预算。
- 首次历史回填后输出 `data/verification/reports/` 覆盖报告：请求分页总数与行数对照、来源双哈希、每字段行数/有效数/空值数/首末有效日、起点覆盖、重复日期、日期断档、外键/完整性、事实与source双向核对、维护接口分类/大小/时间依据。报告只能描述实测覆盖，不默认每个交易日所有宏观字段均有值。
- 新表同步更新 SQLite 存储说明及 `maintenance.DESCRIPTIONS`、真实时间路径；隔离库迁移后核对维护统计接口/页面的发现、用途、分类、记录数、含索引大小和更新时间（含空表、来源时间缺值显示未记录）。用代表性多年全字段及修订样本记录每行/总表含索引字节、分段写入耗时和常用最新日期/范围/溯源查询耗时，核对数值精度；结果写入验收报告。验收通过后按项目规则自动重启宿主机8765并核对日志和页面。

## 验收标准

1. 首次点按现有入口会自动初始化2002-01-04至最新可用日，不需要单独后台命令；源端拒绝、失败或未覆盖的区间不会误标完成。
2. 每条返回事实都能关联有效公共batch/source及原始证据，13列完整映射；不丢字段、不改百分数单位、不填造空值。
3. 初始化中断后优先恢复固定清单的未完成年度；完成后补尾并核对近期14日，有效检查仍在TTL内时跳过请求，空响应/迟到字段可到期重检；已提交不变事实不产生新版本，有值变空不静默覆盖。
4. 页面进度、取消、状态、错误和冷却信息与现有指数采集一致；默认页面读取不产生网络请求。
5. 一份完整覆盖报告验证观测日与逐字段覆盖；不能只以operation complete判定数据全量可用。
