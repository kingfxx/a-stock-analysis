1. 将 `stock_analysis/http/server.py` 中现有全部路由按功能归属提取；Handler 保留协议适配、统一请求门禁和分发，不继续承载领域分支和业务数据组装。

## 目标边界与依赖

以下是职责约定，文件名在逐项映射后确定；只创建有实际代码的模块。

| 职责 | 目标归属 | 约束 |
|---|---|---|
| Handler、请求门禁、协议响应和统一分发 | `http/server.py` 与必要的 HTTP 公共模块 | 保留 Host/Origin/会话校验、请求体限制、状态码、异常边界和连接中断处理 |
| 个股/财务/估值、行业、指数/市场、笔记、研究/AI/财报、维护/采集路由 | `http/routes/` 中按实际领域分组 | 使用显式方法/路径匹配，保留匹配优先级和错误路径行为；不搭建通用插件式路由框架 |
| HTML 模板、资源版本替换和页面渲染 | `http/rendering.py` 或同目录具体模块 | 复用 assets 映射与白名单；领域层不读取 HTML 或拼接响应 |
| 个股加载、刷新、旧缓存兼容及跨领域协调 | `domains/stocks/` 的具体应用服务 | 不接收 Handler；用明确参数和依赖返回数据，保留锁、失败复用和刷新语义 |
| 财务/估值等领域数据组装 | 对应 `domains/financials/`、`domains/valuation/` 等 | 先盘点调用者；跨领域协调不强塞进纯计算模块 |
| 服务缓存、配置、实例创建及恢复清理 | 应用组装模块，按需由 runtime 调用 | 明确唯一所有者，依赖显式传递；不复制缓存/锁，不用 globals/sys.modules 或反向导入 server 获取服务 |
| 新浪财报、腾讯名称/行情解析及纯校验 | `domains/stocks/` 下具体解析模块，按实际凝聚程度分组 | 输入 payload/文本及必要参数，返回现有结构；不请求、不写库、不读取隐含业务状态 |
| 请求参数、Session 调用、分页、跨响应校验及恢复回调 | `domains/stocks/sources.py` 或具体来源适配模块 | 调用纯解析器；保留调用顺序、超时、分页窗口及异常传播 |

依赖方向：HTTP → 领域应用服务 → 来源适配 → 纯解析；应用组装负责注入服务及运行配置。领域及解析模块不得反向依赖 HTTP。兼容导出只用于已查明的现有调用者，生产调用逐步指向真实归属；不得只搬代码再让新模块回调 server 完成业务。

## 验收标准

### 结构

- 路由清单覆盖现有全部入口，每项有唯一处理归属；server 仅剩协议、分发和必要启动兼容，不再直接组装领域业务数据。
- 新领域模块不导入 `http/server.py`，不通过传入 server 模块或全局函数表继续依赖旧单体；实例、缓存及锁保持唯一。
- sources 清单中的全部解析已独立，纯解析器在禁止网络/SQLite 连接下导入与执行，不加载 requests 或 server；请求层只保留适配和必要编排。
- 以职责清单是否完成验收，不设机械行数目标，不用空模块或大量委托制造拆分完成的表象。

### 行为与测试

- HTTP 契约覆盖正常/无效参数、未授权请求、未知路径/方法、Content-Type/请求体限制、响应头、文件访问安全和恢复门禁；业务结果按固定输入前后比较。
- 重点复用 `test_server`、`test_p4_server_integration`、`test_async_loading`、`test_database_restore`、`test_dcf_server`、`test_shipping_http`、公告、笔记、研究及采集管理等现有测试，按实际路由清单补必要缺口。
- 数据组装验证缓存版本、共享价格、局部失败、并发冷启动、服务复用和恢复后清理，不只验证导入或页面 200。
- 来源复用 `test_sources`、`test_p4_source_contracts`、`test_storage_source_contracts`、`test_stock_collection` 及相关价格/财务测试；覆盖截断分页、重复日期、无效字段、缺失/零/负值、复权异常、重叠不足、未推进、恢复回调以及请求顺序/次数不变。
- 自动测试用隔离临时数据库，禁止真实外网和模型调用；测试补丁更新指向真实调用点，断言不能为通过而削弱。
- 涉及生命周期和全路由的重构完成后运行完整回归；最终无新增失败，不能将跳过、超时或未执行项记为通过。

### 数据与运行不变量

- 原库路径、schema、来源及历史修订、正式财报/PDF、凭据、笔记目录保持；无新增 SQL 迁移。
- 公共同源状态、锁、限速配置、拒绝停止/至少一小时及 Retry-After 冷却、个股速度例外和 metadata_only 策略保持；不得新增定时或扩大刷新授权。
- 8765 部署前后只读核对关键配置和运行状态；页面验收不得额外启动采集/模型，保留既有已授权到期机制。

回退仅撤销本任务对应源码/文档，保留其他任务改动和全部日常数据；禁止 reset --hard、用测试库替换原库或清空来源状态。文档计划阶段无需重启后台。
