# 复用自动 WACC 结果到参数面板

## 目标

从折现率参考卡片或展开的 WACC 面板触发自动估算后，六项估算参数都显示在下方输入框中，并可继续手动调整。

## 实施

1. 抽取共享的 WACC 自动估算与表单填充逻辑。
2. 两个入口使用同一逻辑，保留来源证据、自动值恢复和显式应用折现率操作。
3. 更新 DCF 说明并增加卡片入口的 DOM 回归断言。

## 验收

- 从折现率参考卡片估算后，Rf、Beta、ERP、Kd、税率和债务权重均写入输入框。
- WACC 结果可用时参考卡片仍显示估算值；参数可编辑，恢复按钮可用。
- 运行 DCF DOM 测试、JavaScript 语法检查及 `git diff --check`。
