# 决策记录

- D01（2026-11-03）：范围严格为“机构预测去 pandas”和“拼音检索预生成持久化”；初轮产出计划，用户后续已明确授权实施。单代理，不启用协作开发。
- D02：预测纯解析独立到 valuation 领域，用标准库 HTMLParser；来源适配保留原公共采集、冷却、metadata_only 和接口契约。不用延迟导入 pandas 替代真正移除。
- D03：按用户 2026-11-03 的要求，拼音结果复用 instruments，仅新增 search_pinyin、search_initials 两个可空 TEXT 字段，不新增表、名称快照、逐行版本、时间或拼音数据库索引。前端仍使用原 search 字段；名称与拼音同事务维护。
- D04：维持当前 pypinyin 版本和转换方式，辅助进程按需批量生成后退出，主后台不加载词典。不使用禁用短语库、更换多音字规则或动态卸载模块等捷径。
- D05：股票身份/名称集中写入口仍为 Database.ensure_instrument；生成在写锁外，名称及检索字段同事务提交。新增、更名才生成，同名/只传代码复用，避免在频繁服务调用中启动进程。
- D06：初始化准备覆盖新库、旧库迁移、当前库缺失索引、维护暂存恢复库以及恢复后重载；legacy 名称导入继续走集中写入口。页面读取不修复索引、不生成拼音。
- D07：新增 stock_search 领域 helper 和独立 worker，SQL/事务归存储，转换/进程协议归检索领域；不得反向导入 application/HTTP，不建立常驻进程、调度器或通用依赖注册框架。实施前再次复核实际依赖归属。
- D08：优先按当前受影响路径验证，不跑无依据的全量。采用离线合成机构预测样本，不为验收新增真实请求或保存真实机构预期值/HTML。
- D09：页面速度为硬约束，分别核对冷/热路径；判定观察线和测量次数见 PLAN。迁移和新增/改名的写入成本单列，不能拿常用页面均值掩盖首次延迟。
- D10：行业缓存、OpenBLAS 和 Plotly 均不在本次范围；numpy 继续承担现有航运拟合。节省量以同环境前后实测为准，不累加独立依赖测量值作承诺。

- D11（2026-11-03）：NULL 表示未生成，空串表示已生成但无拼音；初始化仅补缺失。算法/词典变化通过迁移作失效和重建，不每行保存版本。直接 SQL 改名必须同步置空并准备或走集中写入口；不以只读页面修复替代写入一致性。

- D12（实施）：初始化先完成schema事务并关闭连接，再执行批量补缺；SQL集中在Database.pending_search_keys/publish_search_keys，领域helper不导入Database。原P4回归补齐公告mock以隔离来源，保留全部断言。
- D13（验收）：保留冷态/并行探针原始慢样本，受影响行业热态与浏览器时间在探针结束后单独复测；行业输出比较固定哈希种子排除浮点累计顺序差异。没有扩展到行业缓存优化。

- D14：用户追加授权一小时空闲回收，覆盖行业/指数/维护的可重建内存缓存，扩展D10范围；从实际数据访问算空闲，状态轮询不续期；复用原Scheduler，无全局服务注册表、不改采集授权。
- D15：仅释放过期对象引用；不强制压OS工作集，避免下次访问额外换页。内存实际下降和缓存释放分开报告，临时对象分配器高水位不伪装为可过期缓存。

- D16（2026-11-04）：实际反馈表明仅缓存TTL覆盖不足。D15仍禁止压OS工作集；新增只针对未使用堆页的HeapOptimizeResources及每小时空闲GC，遵守前台请求/采集/模型/恢复门禁，分别报告有限收益与常驻原生库限制。
- D17：同时补齐指数默认collector自建主Session的确定性关闭；注入所有权不变，不调整来源策略。
