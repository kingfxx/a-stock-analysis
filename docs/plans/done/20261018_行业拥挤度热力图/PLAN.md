# 行业拥挤度热力图

在指数分析页“大盘拥挤度”图表下加入申万一级／二级行业热力表。默认展示最近30个自然日内的日频样本，最新拥挤度降序，前五名置顶；用户可切换层级和日期范围，点击日期列按该日拥挤度降序重排。色彩连续映射行业换手率在各自完整历史中的分位，悬浮提示两项数值。点击行业跳到“估值与分位”的拥挤度视图并传入行业。

复用现有指数行情表与指数选择控件，不采集新数据、不改数据库结构。仅使用申万 `analysis.points` 日频序列，拥挤度值取 `amount_ratio`，换手率分位取同一序列 `turnover_rate`。缺值保持空白。
