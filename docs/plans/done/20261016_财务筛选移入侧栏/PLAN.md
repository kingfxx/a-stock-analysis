# 计划：财务分析筛选移入侧栏

## 目标
将财务分析的报告期、利润与现金流口径、比较对象、金额单位和资产负债图筛选移至左侧栏；每行两个筛选，财务分析激活时显示且默认展开。报告期支持季度／年度步长切换。行业对比筛选组进入行业对比时默认展开。

## 范围
- `web/index.html`：添加财务筛选侧栏容器。
- `web/financial-statements.js`：把动态筛选控件移入侧栏，并随研究标签切换显隐；加入季度／年度报告期导航步长。
- `web/financial-statements.css`、`web/industry.css`：侧栏筛选样式及足够的布局宽度。
- 不改变筛选口径和服务端数据请求规则；报告期导航只在已有报告期选项中跳转。

## 验收
- 财务分析控件不再显示在内容面板顶部，财务分析标签激活时在左侧显示且默认展开。
- 财务筛选按两列排布；报告期导航具有季度／年度步长切换，并只选择本地可用报告期。
- 行业对比筛选在行业对比标签激活时在左侧显示且默认展开。
- 切换其他研究标签时隐藏相应筛选；窄屏下控件可用且不会挤压内容。
- 检查静态差异与语法，不运行测试，除非用户另行要求。
