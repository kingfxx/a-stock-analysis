# 决策

- 采用用户确认的宽版横向柱形图，不采用简称竖柱方案。
- 占比以来源披露的本活动流入／流出小计分别为分母；缺失或非正分母不计算，不用已展示条目拼凑分母。
- 流出金额在图中取反表达现金影响；原始金额和来源仍保留。来源负值不取绝对值，避免隐藏反向现金影响。
- 默认收起，点击柱形或有标签的按钮展开；切换报告期、口径、单位时刷新当前明细，切换报表时隐藏。
- 不修改数据库结构，不启动来源采集或模型。
- 明细图只有一个条目系列，使用 `closest` 单柱原生悬浮；不透明深色背景、浅色固定字号、完整名称换行，关闭尖峰线。原金额、现金影响及占比的口径与精度不变。
- 本任务后续调整、缺陷修复和验收反馈共用此目录，不再另建修复计划。
