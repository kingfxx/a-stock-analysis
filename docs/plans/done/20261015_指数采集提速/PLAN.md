# 指数采集提速计划

## 目标与范围
用户于2026-10-15明确授权协作开发：跨来源并行；指数同源最多2个在途请求；每次完成后等待2—5秒；滚动60秒30次；同源累计20次完成后额外休息10秒。仅指数估值采集采用此授权策略，其他公共采集、个股及cninfo策略保持现有行为。

## 分工
Sol负责计划与最终代码审查；Luna负责实现、隔离测试、更新本目录PROGRESS.md。仅使用本计划目录，不引用其他开发计划状态。

## 实现要求
1. 复用collection.py公共归档、预算、冷却机制，不创建独立指数预算表或重置预算。
2. 跨提供方任务并行；同源请求最多2个跨线程/跨进程在途；来源锁改动必须保持其他默认单并发调用与新指数调用相容。
3. 每个工作单元独立Session和可变计数，统一取消、按来源进度、结果汇总；单源拒绝立即阻止新的同源发送，已在途响应仍归档，其他来源继续。
4. 保留普通失败最多3次、60/120秒重试、至少一小时拒绝冷却、单次恢复探测、增量跳过、完整分页校验和幂等发布。
5. 优先在指数代码循环级调度可独立批次；申万分页校验语义不得削弱。统一日历准备后开始并行。
6. 修改docs/index-valuation-collection.md与collection规则的用户授权例外说明；若存储结构变化同步维护和存储文档，优先不迁移schema。原文档已合并至[统一指数采集说明](../../index-data-collection.md)。
