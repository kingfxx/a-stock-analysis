# 拥挤度展示优化

2026-10-17，按用户图片说明实施。

- 指数下拉、图例和悬浮只显示指数名称，不显示稳定代码。
- 将历史/覆盖及点位来源信息移入默认折叠的“说明与近期数据”；最新观测只显示日期。
- 图表将两个来源投影到按日期的单条拥挤度曲线，统一蓝色和“大盘拥挤度”图例；相同日期优先网页有效值，NULL不覆盖已有有效值。数据库仍独立保存通道与证据，冲突在说明中保留。
- 新增月/周/日频率；5年默认日、10年/全部默认周，切换范围重设默认，切换指数保留频率。
- 周/月按每周期最后一个已记录实际日期取同日指标/点位，没有该日值留空，不拿周期前日的值冒充。按UTC计算周一分组，跨年正确，原始日频记录不变。
- 悬浮日期由共享标题唯一显示YYYY-MM-DD，各数值行移除日期和来源，指数仅名称。
- 仅修改静态展示，不改变采集、数据库及日程，不新增来源请求。
