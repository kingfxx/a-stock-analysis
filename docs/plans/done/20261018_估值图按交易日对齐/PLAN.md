# 估值图按交易日对齐

## 目标

周／月频估值图启用前复权股价叠加时，让同周期估值点与股价点共用该周期最后一个实际交易日作为横轴日期，并在悬浮提示中只显示一次这个日期。

## 实现范围

- 只调整个股“估值与分位”前端图表的月频横轴日期及 tooltip。
- 估值数值继续取当月最后一条有效观察；股价继续取当月最后交易日收盘价。
- 其他频率、指标计算、分位统计和数据来源不变。
- 同步指标文档，说明月频点位按交易日对齐，估值观察值仍可能早于该日期。

## 验收标准

- 周／月频且打开股价叠加时，两条序列共用周期实际交易日期，tooltip 不重复列出日期。
- 没有可用交易日期时退回原展示日期。
- 关闭股价叠加及日／周频行为不变。
- `git diff --check` 通过。
