# 决策

- 仅压缩 financial_reports，不引入科目字典或原文文件。
- SQLite 现有 raw_json TEXT 亲和性允许 BLOB；保留列和索引，避免重建外键/触发器。BLOB 自描述版本为 ASTKFR 1，包含原始长度和 SHA256，压缩为 zlib level 6。
- 编解码集中在 financial_storage，应用的 financial_reports 仓储及直接读取入口显式调用；不改变全库行工厂，避免给无关大表增加读取开销。文本兼容读取，业务快照继续保存原文本。
- 独立研报技能保持标准库实现，不导入应用；实现同一协议并由交叉兼容测试核对。
- 解码限制原文 64 MiB，核对长度、完整压缩流及 SHA256；迁移拒绝与既有 content_hash 不符的历史记录，事务回滚。
- 仅开发本身不启动采集或模型。用户授权已涵盖历史迁移、备份及必要的重启/空间整理。
