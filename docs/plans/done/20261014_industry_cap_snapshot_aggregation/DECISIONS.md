# 决策记录

- 不新增控制表或业务表；汇总审计版本写入 `sw_imports`，季度当前版本映射写入现有 `sw_update_runs.result_json`。
- 只用 `market_trade_snapshot` 中目标季末日可用的沪深公司总市值，按东财原始、核验停牌参考价、历史合成的顺序择优。
- 三级行业保存汇总；上级行业由当前版本的三级汇总行向上计算。
- 部分覆盖只显示已知金额，完整总额保持空值；公司市值不回退旧公司市值来源。
- 已有历史汇总保留；某季度还没有新来源汇总时，页面继续使用该季度现有的最新有效旧汇总。
- 同输入签名复用版本，名单或有效公司市值变化时追加审计版本；当前行业名单指针保持不变。
- 行业同比继续按当前期和去年同期的共同公司计算，不以两期行业总额代替。
- 公司快照完成发布后独立提交汇总，避免将网络采集放入汇总写事务。
- 不对既有历史季度执行批量回填；只为此后采集或修订任务实际处理的季度生成新来源汇总。
