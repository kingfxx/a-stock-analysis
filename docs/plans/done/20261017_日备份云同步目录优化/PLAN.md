# 日备份云同步目录优化

## 目标

每天系统首次生成的日备份放在 `backups/stock_cloud_bkp`，该目录只保留当天版本；新日期备份生成后，旧日备份归档到 `backups`。结构迁移等专项备份继续直接写入 `backups`。维护页恢复列表同时读取两个位置。

## 范围

- 调整 `Database.daily_backup()` 默认目录和旧日备份归档。
- 扩展维护恢复列表及备份源路径解析。
- 将维护统计和相关说明纳入新目录。
- 显式传入日备份目录时维持原有保留数量语义。

## 验收标准

- 默认日备份只在 `stock_cloud_bkp` 保留最新一个有效日期文件。
- 旧日文件移动至 `backups`，冲突时不覆盖已有备份。
- 专项备份调用路径不变。
- 维护页能选择并预览两个目录下的备份，拒绝越界路径。
- 更新架构和维护说明；按当前会话规则不运行测试。
