# 估值分位统一日样本

## 目标

在相同时间范围内，估值分位和参考线统一使用该范围内全部有效日观察，不再按 3／5／10 年切换日、周、月样本。

## 范围

- PE、PB、PS 使用现有逐日估值观察。
- 股息率在本地日行情和分红事件可用时按每日收盘价计算日样本；图表展示频率与行数据保持现有行为。
- 仅调整样本选择、样本频率标签和对应说明；不插值、不填补缺日、不改分位公式或图表展示频率。

## 验收

- 3／5／10 年分位、80／50／20 参考线及标准差参考线共用各自区间的有效日样本。
- 展示文字显示日样本数，切换图表展示频率不改变结果。
- 无日级来源时如实沿用本地可用的观察粒度。
- 同步指标文档并通过 `git diff --check`。
