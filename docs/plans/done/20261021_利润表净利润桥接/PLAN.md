# 利润表净利润桥接

## 目标

在利润表瀑布图中，从合并净利润继续展示少数股东损益归属、归母净利润、非经常性损益净影响和扣非归母净利润，帮助用户核对利润口径如何转换。

## 实施范围

- 复用现有 `net_profit`、`parent_profit`、`minority_profit` 和 `deducted_profit` 字段。
- 仅在桥接两端均有有效值时绘制差额和目标总额，不将缺失值当零。
- 悬浮提示解释差额公式及少数股东损益披露值；页面注释说明差额不代表现金，也不拆分非经常性项目明细。
- 只调整利润表页面与对应后端瀑布数据，不改变采集或数据库结构。

## 验收

- 已有合并净利润、归母净利润、扣非归母净利润时，图表能依次落到三个对应总额。
- 任何桥接端点缺失时，不绘制该段差额、不补零，页面说明缺失限制。
- 悬浮提示显示差额口径与单位。
- `git diff --check` 通过。
