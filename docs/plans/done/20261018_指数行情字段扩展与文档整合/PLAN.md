## 3. 字段方案

新增以下可空列；现有OHLC、身份、来源、修订及时间列保留。列名不含展示单位，定义文件明确标准单位和转换。

| 新列 | 标准单位/语义 | 中证历史原字段 | 申万日报原字段 |
|---|---|---|---|
| `volume` | 股，允许有效零；REAL兼容来源精度 | `tradingVol`，原单位须确认 | `bargainamount`，亿股×1e8 |
| `amount` | 元，允许有效零 | `tradingValue`，原单位须确认 | 无直接字段，NULL |
| `change_points` | 指数涨跌点数，允许零和负数 | `change` | 无直接字段，NULL |
| `change_pct` | 百分数，2.5表示2.5% | `changePct` | `markup` |
| `turnover_rate` | 百分数，允许有效零，不设置100%上限 | 无，NULL | `turnoverrate` |
| `amount_ratio` | 成交额占比百分数，不是0—1比例 | 无，NULL | `bargainsumrate` |
| `constituent_count` | 非负整数，非整数来源值拒绝 | `consNumber` | 无，NULL |
| `mean_price` | 元，来源均价，不能当指数点位 | 无，NULL | `meanprice` |
| `float_market_cap` | 元，流通市值 | 无，NULL | `negotiablessharesum1`，亿元×1e8 |
| `mean_float_market_cap` | 元，平均流通市值 | 无，NULL | `negotiablessharesum2`，亿元×1e8 |

申万单位依据：AKShare官方 `docs/data/index/index.md` 的 `index_analysis_daily_sw` 输出说明，https://github.com/akfamily/akshare/blob/main/docs/data/index/index.md 。实现前核对版本和原站口径；换手率、均价、市值不得自行命名为等权/自由流通等未经证实口径。

中证量额单位是前置核实项：优先现有官方材料及缓存元数据，必要时仅做宿主机有限验证，通过公共RequestCollector并遵守共享状态；禁止凭数值量级直接决定转换。拿不到足够依据时保留缓存及明确阻碍，不用猜测值完成验收。

用户提出用拥挤度表每日 `total_amount_yi` 推导中证指数成交额占比、申万行业成交额。用户进一步确认仅用于定性分析，接受北交所等分母范围差异及比例舍入引入的近似误差，按“基于Legu全A成交额的估算”实施；分母严格一致不再作为前置阻碍，金额单位及同日匹配仍须正确。本窗口仅已做离线样本验证，不写业务事实。

设同日大盘总成交额 `T = total_amount_yi × 1e8` 元：

- 中证指数派生成交额占比（百分数）=`中证当日amount / T × 100`。
- 申万行业派生成交额（元）=`申万当日amount_ratio / 100 × T`。

执行要求：

1. 记录已知分母市场范围及交易统计口径差异，包括沪深/北交所、证券范围、大宗交易；核实指数amount含义和单位。Legu已知不含大宗交易，不能声称中证/申万必然相同，但用户接受此差异下的定性估算，不继续以无法证明分母完全相同阻碍实施。
2. 优先离线核查多个重叠日期，能获得申万自身总成交额或行业直接成交额时做独立比对；行业占比加总约100%只能验证占比内部关系，不能证明与Legu分母一致。不能用同一公式正反推导作为独立验证。
3. 申万公开占比通常仅两位小数，反推金额必然有舍入误差；若四舍五入到0.01个百分点，比例本身导致的金额误差约为 `±T×0.00005`，还未包含来源口径差异。结果明确是派生/估算，不宣称来源精确金额。
4. 严格同一实际交易日匹配；分母缺值/零、单位未明、来源异常时不计算，不前填/插值。若拥挤度总成交额来自BigQuant补值，其来源和定义须独立标识，不当作Legu原值。
