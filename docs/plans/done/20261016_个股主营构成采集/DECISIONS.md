# 设计决策

日期：2026-10-16。用户确认范围：个股主营构成；保存结构化业务版本而非原始 JSON；全量历史十年，增量类似现有个股财报。

1. 只接入个股采集，不采全市场，不建调度任务。read 只读；更新沿用个股明确操作／到期检查。
2. 采用 RPT_F10_FN_MAINOP。PageAjax 两样本均仅 200 条且截断报告期，不用于完整历史。
3. 十年按上海今天减十个日历年计算，报告期上下限含当天，不取“最近十个有数据年份”；不自动删除滚出窗口的旧版本。
4. 复用现有财务模式：24小时检查、180天全量审计、失败600秒抑制、最近两个实际报告期重叠。主营构成独立同步状态，不以新浪财报最新期替代东财水位。
5. 增量上限到今天，允许来源迟到、新增季度及重叠期补字段；没有季度明细不强求每季齐全。近期窗口之外的修订由审计／full发现。
6. 两张表使用 business_segment_versions、business_segment_items；不增加独立任务表，不存原始 JSON、响应片段或原文哈希。
7. 复用 metadata_only 与 stock_fast，共享真实 provider=eastmoney；新明细增加公共来源页精确引用，与旧个股事实关联方式的差异明确记录。
8. 版本按公司×来源×报告期整体保存，重复业务内容不重写，真实变化保留旧版，A→B→A允许；排序变化不单独制造业务修订。
9. 业务字段十进制 TEXT＋Decimal；保留零、负数和 null，不臆造未确认币种或字段定义。
10. 不自动合并跨期同名／同码业务；不把分部毛利当净利润，不跨维度加总，不静默填补缺值或撤回旧事实。
11. 2026-10-16用户已授权按计划实施，采用协作模式。主代理规划／审查，执行代理开发测试，仅读写当前计划目录的状态，不混用其他计划。
12. 本次实现采集／结构化存储／本地读取／个股财务操作接入；图表、招股书补充及人工跨期分类映射不在本轮范围。源数据保留原名，足以供后续展示消费。
