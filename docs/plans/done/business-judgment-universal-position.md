# 跨行业行业地位表审阅方案

目前运行版本仍为prompt_v10，仅中远海控有直接数据适配。本轮只整理候选规则和伊利独立样稿，不应用到8765后台，不改写历史。

入口：quarterly_dashboard/prompts/business_judgment_universal.draft.txt；追加规则为business_judgment_industry_position.draft.txt。

统一表格结构，先识别核心业务，再定义竞争市场、地区、渠道、统计主体、时期和份额分母。公司排名/份额分别处理，同行和集中度缺值明确保留；数字只能依据可读来源，不要求靠提示词保证所有市场都有数据库。

来源策略：有直接行业适配时用确定性事实；无适配时模型检索正式报告、协会及研究机构资料，按同一格式输出并保存证据。候选JSON追加industry_position.markets，生产协议及前端尚未改造。

伊利样稿需区分液态类乳品、婴配奶粉、成人奶粉和冰淇淋；公司引用机构统计与独立机构报告分开说明。同业份额不够就不计算CR3/CR5。

## 伊利样稿

已生成 data/research_reports/sh600887/2026-10-10/business-preview-469d492c/report.html。模型仅调用一次，156秒，public-only输入，不读取本地财务或财报传给模型，不写日常AI任务表。样稿含四张分析表与统一行业地位表。

首轮缺口：中文PDF链接混合编码、冷饮遗漏、关键资源行沿用航运标题、婴配奶粉仍用2025数字而同份已检索2026报告有18.6%。审阅后按同一公开2026半年报PDF第10–12页人工校正行业事实：液体乳披露第一但无份额；婴配奶粉第一18.6%；成人奶粉第一26.8%；冷饮公司披露第一但排名指标/份额缺失。同行可比排行仍不足，不计算CR。原始response、实际调用rules及每项修正manifest保留，不伪称纯自动结果；其他四表未逐项独立审计。

相应规则补充核心财报分部覆盖、第三表行业适配、同一最新材料全品类取数及行业地位引用协议。当前候选规则与实际首轮生成rules的哈希分别保存。
