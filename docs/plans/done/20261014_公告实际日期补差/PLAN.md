# 公告实际日期补差

按用户要求取消固定90日回看。增量查询使用数据库已验证公告的实际最新发布日期作为含当天的起点；保留十年边界、首次/全量/扩类完整查询、公共限速及元数据证据策略。无公告记录时使用成功查询终点，未成功初始化时使用完整范围。实际水位只取当前分类集合适用的已采记录。

验证尾部长期无新公告、同日补漏、无记录、全量及扩类不退化；相关隔离测试通过后重启8765。历史内部缺口仍通过显式全量或定向start检查，不把尾部补差宣称为历史完整覆盖。

2026-10-21 后续修正：普通增量不因财务列表新增更早报告期扩大联网窗口；日期判断只重算新增/变化公告关联的报告期及既有覆盖中的新报告期。其余历史判断保留，显式 full/start 或分类/规则身份变化才按指定范围核验。十年范围外的旧 pending/missing 不触发汇总警告，范围内提示列明报告期；不迁移或删除旧判断，不新增外部请求。
