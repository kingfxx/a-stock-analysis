# 指数拥挤度频率与说明布局

## 目标

- 大盘拥挤度提供“自动”展示频率：5年自动按日，10年和全部历史自动按周。
- 指数估值与分位中的拥挤度自动频率：3年和5年按日，10年按周。
- 指数估值与分位的覆盖、定义和方法说明默认收起在“说明”控件中。
- 保持大盘拥挤度的每日检查状态、设置和说明区布局符合用户截图。

## 实施

- 在拥挤度频率选择中增加自动项，默认自动，并在范围变化时重新解析自动频率。
- 指数拥挤度按所选范围解析自动频率；其他估值指标保持现有自动规则。
- 使用原生 details/summary 收纳指数估值区说明。
- 将大盘拥挤度说明标题简化为“说明”，每日检查状态和设置仍在说明区外可见。

## 验收

- 检查改动仅影响所述控件、自动频率选择和说明区布局。
- 检查页面脚本语法，并运行相关现有测试（如用户要求）。
