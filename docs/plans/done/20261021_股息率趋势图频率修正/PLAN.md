# 股息率趋势图频率修正

## 目标

让个股股息率趋势图的日／周／月频率选择切换到对应的实际观察序列，修复目前三种频率都返回同一组月度数据的问题。

## 验收

- 有本地未复权日行情时，以真实交易日收盘价和已实施分红计算日频股息率；日频不插值、不补日期。
- 周／月展示各自周期内最后一条有效股息率观察。
- 股息率悬浮提示显示该观察日过去365天税前每股现金分红合计和不复权股价，单位元／股，均保留两位小数。
- 所有频率只显示时间范围内的日期，范围外观察不能扩展图表横轴。
- 无本地日行情时保留已保存的月度股息率观察，不伪造日频数据。
- 分位、当前值和股息率公式不因展示频率变化。
- 更新指标说明并重启 8765 原数据库后台供人工验收。
