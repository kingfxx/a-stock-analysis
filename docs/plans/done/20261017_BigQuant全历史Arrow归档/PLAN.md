1. 宿主机使用现有 SDK、公共预算/锁和真实 bigquant 提供方，查询逐日独立计数，确认可访问日期范围。
2. 按年度串行下载，必要时按数据量缩小到季度。保留公共 source/batch 及原始 Arrow 归档，使用清单引用，不复制正文。
3. 每段核验 schema、逐日计数/证券去重/amount和volume非空数、重复键、日期范围与归档双哈希；通过后记录可恢复分段。
4. 汇总执行状态和覆盖限制；不计算拥挤度、不写业务事实、不修改日程或后台。
