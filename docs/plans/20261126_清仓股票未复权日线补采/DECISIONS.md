# 设计决策

| 事项 | 决定 |
| --- | --- |
| 独立交付 | 单独维护本目录。原持仓分析计划负责历史年度展示和盈亏核算口径。 |
| 补采窗口 | 招商已清仓的 27 只沪深 A 股，每只一个连续窗，最早需要估价日至最后一笔卖出日，上市日为最早可用行情边界。 |
| 来源 | 联网使用现有腾讯未复权日线，先验证有限样本，沿用公共预算和原响应归档。 |
| 存储 | 持久业务表 `portfolio_historical_closes` 保存价格和证据引用，无个股建档依赖。 |
| 启动与恢复 | 采集管理登记独立手动任务；既有公共 operation、batch、source 承接任务控制、发布和续跑。 |
| 读取 | 主表同口径当天收盘优先，专用表逐日回退；一次落库，按区间批量读。 |
| 疑似缺口 | 按交易日历、上市和停牌证据核对。缺少证据或来源返回缺行时保持待核，价格留空。 |
