# 设计决策

| 事项 | 已确认或计划采用的口径 |
| --- | --- |
| 界面和范围 | 在采集管理新增 ETF 卡片。仿照个股的操作布局，直接填写 ETF 代码，可选择行情和分红。分组、ETF 业务展示和持仓计算不属于本次交付。 |
| 日程 | 计划沿用公共日、周、月规则，按代码和数据项保存，默认关闭。自动检查仅更新已手动初始化的数据项。 |
| 行情 | 新浪初始回填，腾讯接续日常增量。东财行情源的历史记录和定向核对保留。未复权价格、成交量、成交额保留各自真实来源与已确认口径。腾讯未提供的成交额、振幅、涨跌幅、涨跌额和换手率存 `NULL`。 |
| 来源接续 | 每只 ETF 用重叠区间单独核对，存储按来源保留证据及版本；消费端按已验收区间取用。成交额、扩展字段缺少证据时保持缺失。 |
| 分红 | 用户已确认 F10 逐笔明细为主、正式公告核准差异、券商流水记录实际入账。全量分红复核对照新浪累计序列，单只公告核对在同一卡片提供正式公告 PDF 链接。 |
| 存储和运行 | ETF 领域拥有业务事实与发布，表名定为 `etf_daily_prices` 和 `etf_cash_dividend_events`。统一使用公共运行、分段、原始响应及调度状态。默认沿用公共来源限速，卡片可按来源手调，保存后的下一次任务生效。 |
| 独立计划 | ETF 采集独立于「个人持仓与复盘」和「清仓股票未复权日线补采」。前者拥有持仓展示与收益口径，后者处理固定范围的清仓 A 股价格。 |
