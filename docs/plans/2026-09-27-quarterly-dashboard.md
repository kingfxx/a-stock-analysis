# 季度分析页面：缩小后的首版方案

日期：2026-09-27。依据用户提供的柱状图＋折线图示例及“无需完整日线，季度财务足够”的新要求，取代原计划中首版必须入库多年日线与成交额的前置条件。

页面按股票代码加载季度报告。营收、归母净利润取新浪财报三表的累计值，转换为单季度、年度及滚动四季度；期末股本取同一报告期资产负债表。初版计划用月末 K 线对齐季度，但这会使实际披露日期和股价错位；现改为分段查询腾讯日 K，只缓存每份报告披露日或此前最近交易日的收盘价快照（超过 15 天留空）。披露日估算市值＝对应未复权收盘价×报告期末股本；前复权价格仅用于走势图。缺少价格或股本时该图显示缺口，营收＋利润仍可独立使用。

横轴为**报告期**，不是投资者实际看到财报的日期。悬停同时显示报告期、实际披露日、价格采样交易日和来源。财务数据在当季结束后才披露，因此市值／营收等图用于事后对照，不能称为“当时可交易估值”。原计划的历史 PE/PB、分红收益率及点时版本修订保留到后续阶段，不阻断本页面。

实现为 Python 标准库本地 HTTP 服务、Plotly 本地脚本、按股票的 JSON 缓存。页面只监听 `127.0.0.1`，提供股票代码输入、四种图形切换、单季度/年度/TTM 切换、刷新数据及缺失提示。默认以用户示例中的 300750 宁德时代展示；界面采用深色图面、青色柱与黄色线，轴单位分开。首版不使用自动交易和全市场批量请求。

验收：300750 在本机能获取真实季度财务并生成页面；四组图和三种周期均可切换；营收/利润累计差分与 TTM 测试通过；无价格时财务图可用，价格类图标明缺口；缓存后再次打开不需要重新访问数据源。
