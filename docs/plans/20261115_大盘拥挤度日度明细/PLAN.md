# 大盘拥挤度日度明细

- `indices.html` 在成交额图下提供表格容器，`indices.css` 提供与融资明细一致的横向布局，`congestion.js` 负责状态、同日对齐、日度筛选与渲染。
- 表格随「成交额」按钮及成交额子图显示。默认 30 个自然日，支持 60／90 日。日期从新到旧，显示所选指数点位、拥挤度以及全 A 成交额和同格增减额。
- 成交额和增减额以亿元为单位四舍五入显示为整数。增减额先用原始数值计算，再取整显示。
- 拥挤度概览卡片在当前观察日期后用两个空格接同日全 A 成交额，金额显示无千分位的整数，单位为「亿」。
- 复用 `/api/indices/congestion` 的本地数据及图表来源优先级。按已记录的市场交易日计算日差，上一日缺值时留空，区间首日可引用窗口外的上一交易日。月频指数点位按真实日期展示。
