# 常规采集与历史归档解耦

## 目标与范围

以仅恢复 SQLite、未同步旧响应文件的新电脑为验收场景。已有且适用的已发布结果继续使用；本次运行所需而未取得的输入，通过原有采集入口补齐。历史归档仍用于溯源、审计、导出和离线回放。新响应继续先保存证据再发布事实。

本轮处理指数、航运月度、季度交易快照、申万行业与沪深名单日检四条链路。全市场四表、财务补缺和大盘拥挤度保留已有缓存失效后的联网回退，按受影响范围验证。专项历史回填、人工图表复核、独立归档与云备份机制维持现有契约。

## 实施顺序

1. **指数交易日历，优先修复。** 在 `domains/indices/index_collection.py::load_calendar` 中将旧日历当作可选缓存。缺旧散文件或 ZIP 时走现有新浪请求、取消、预算、解析和入档流程。有效且满足覆盖要求的日历仍可复用。核对指数增量／修订核对和 `market_trade_snapshot.target_date` 共用的调用链，后者已有经核实的交易日映射时继续优先使用该映射。网络取回的日历须满足使用方覆盖校验，缺目标交易日时明确失败。
2. **全市场季度交易快照。** 在 `domains/market/market_trade_snapshot.py::collect_day` 中保留同范围、同日且已验证的失败分段分页复用。缓存页缺失时，通过原东财入口重取必要页。沿用页长、总数、日期、跨页重复及原子发布检查；分页一致性无法确保时，只重新抓取该未发布分段，或明确失败。已完成快照仍按原幂等规则处理。
3. **申万行业及沪深名单日检。** 在 `domains/industries/industry_memberships.py` 中把本次新取得的名单证据和沿用的上市日期来源分开。对已保存且仍适用的上市日期，通过真实旧批次／来源引用保留来源，复核 `industry_service.import_bundle` 已有的 retained 清单路径和数据校验约束。若新响应没有上市日期或公司暂缺，保留旧事实及出处。新上市日期、真实修订及新名单仍走本次证据校验。缺历史原文可以提示，缺来源数据库记录、引用冲突或新证据落盘失败分别处理。
4. **航运官方月度。** 在 `domains/research/sectors/shipping/shipping_collection.py` 中，已完成月份按匹配的 URL、数据集、月份、口径及已校验发布状态识别，保留覆盖判断和人工复核引用，常规运行不逐一打开旧正文和图片。核对合法空结果及旧批次只有完成标记但缺发布依据的情形。待采分段和历史回填目录需要正文时，缓存缺失走原 URL 取数。人工复核和资料导入入口继续校验其所需原件；显式修订核对沿用现有发布保护。

## 职责与证据

领域模块决定是否需要重新取数及如何验证业务覆盖。公共 `collection/collection.py` 继续负责请求预算、状态、批次和新证据落盘。`collection/source_archive_read.py` 继续严格按源路径、映射与哈希读取；只有多个领域确实需要同一异常分类时，才在公共读取层提取最小能力。复用原计划、运行、批次和来源表，预计无需新增表、迁移、缓存文件、进程或接口。实施前复核实际调用链及已有校验，若有变化先更新本计划。

## 验收

- 用隔离 SQLite 和临时目录构造已发布数据与旧归档引用。分别移除旧散文件和 ZIP，使用模拟来源请求，验证四条链路通过正常入口执行，历史事实、修订、来源 ID、哈希和取得时间仍可核对。
- 验证有效缓存避免额外网络请求；缺失旧输入仅补必要内容。覆盖上游无可用响应、拒绝／冷却、取消、新响应落盘失败及分页不一致的情况，确认运行终态真实且未校验数据不会发布。
- 验证航运人工复核和已完成月无额外请求、没有重复发布；名单沿用旧日期及来源，新日期按真实来源发布；严格审计／回放仍报告缺失或损坏。
- 定向运行指数、季度快照、行业名单、航运及归档读取的相关测试，必要时验收采集管理的手动和定时入口。模拟迁机场景覆盖成功后，实施交付按项目规则检查宿主机 8765，安全重启并验证日志及页面；重启验收不额外触发正式采集。

## 实施前复核

- 只将 `FileNotFoundError` 用作日常缓存缺失回退，保留损坏、哈希及路径错误的诊断。快照重新取得缺页后须通过现有全段校验，冲突直接失败并保留事实。
- 名单继续使用现有 `reusable_source` 建立元数据引用链，由它验证来源状态和归属。沿用近期新证据的回读校验，避免改动既有发布契约。
- 航运从已完成批次的结果判断月份及合法空结果，并维持主来源和复核记录的数据库引用。旧批次没有足够发布结果时，按待处理月份走正常取数流程；绕开物理文件读取仅适用于已完成分段复用。
