# 设计决策

| 主题 | 本轮建议 |
|---|---|
| 实施顺序 | 第一阶段交付招商 XLS 持仓快照和已提供的 2026 年历史成交；按用户确认补齐华泰快照和同日合并。手动交易和资金流水后续复用同一事实结构 |
| 首批表 | `portfolio_accounts`、`portfolio_snapshots`、`portfolio_snapshot_positions`、`portfolio_ledger_entries`。快照头保存账户时点及汇总，明细按快照关联，交易事件独立保存 |
| 仓位展示 | 现金每份快照仅保存一次。优先按确认总资产计算仓位，现金未知时以证券市值为分母并标出口径 |
| 第一阶段确认 | 上载 XLS 先预览再提交；快照重传保留修订，历史记录以来源与行号保留，跨文件相同候选要求显式选择。来源原件按哈希存于活动数据库同级私有目录 |
| 建账方式 | 招商可先保存快照，确认收盘日及现金口径后设为期初。华泰已确认基准日和录入现金，合并区间从两户数据均足够之日算起 |
| 招商日期 | 文件及表名为 `20271125`，文件修改日期为 `2026-11-25`，表内无日期。导入时确认交易日和盘中／收盘状态 |
| 招商资金与成本 | 余额、可用、可取和券商资产分别保留。用户确认 2026-11-25 收盘现金为 12,773.42 元。成本采用原表成本金额，成本价与券商持仓盈亏供核对 |
| 招商历史成交 | 保存买卖及其他业务事件。期初前事件可回看，待资金流水到手后匹配实收实付及费用。成交编号和委托编号均不能单独用于去重 |
| 手动单笔交易 | 账户建账后可直接录入 A 股和 ETF 买卖，与导入走同一账本。后续导入匹配同笔成交时补齐证据及费用 |
| 华泰首份持仓 | 使用截图人工转录草稿，用户已确认 2026-11-25 收盘并采用总资产减证券市值作为期初现金。精确成本金额与交易随券商记录补录 |
| 双户合并 | 分户账本独立，同日按市场、类型、代码合并并展开分户。报价、日期和成本口径须可比，缺口显式显示。合并的内部划转抵消，跨日配对进入在途资金 |
| 首版收益 | 先做可对账的资产、盈亏金额和证券贡献。有完整估价及现金流后再做连续净值与绩效 |
| A 股和 ETF | 都进入账本。个股复用本地未复权行情和估值，ETF 缺价时允许带日期的用户输入或券商市值快照，跟踪指数只作为参考 |
| 历史盈亏临时估值 | 一天只涉及一只证券缺收盘时，使用该证券此前最近的本地未复权收盘价，记录实际报价日。缺少此前价格或涉及多只证券时保留缺口。原始行情和流水保持原值。 |
| 港股 | 暂时排除，范围内外资金移动按边界资金流处理 |
| 投资笔记 | 个股沿用已有 Markdown，组合复盘使用独立笔记身份和显式保存的数据快照 |
| 产品入口 | 独立「持仓分析」页，持仓快照默认为合并视图，历史成交以独立 Tab 展示 |
| 运行边界 | 组合属于独立领域，复用现有本机鉴权、恢复门禁和 SQLite 生命周期。读路径只调用已初始化的只读能力，组合不持有额外常驻状态 |
| 估值与来源 | 共享日期投影归估值域，组合与笔记分别调用。后续 ETF 批量行情走现有采集管理、来源预算及调度 |

招商快照的适配依据已齐。实际建账时确认日期和资金口径。华泰格式、两家历史流水能导出的长度、期初成本定义和划转配对依据随文件到手核实。

## 2026-11-26 持仓分析视觉一致性

以企业经营趋势的外观为参照。研究导航与当前对象摘要由公共模板和布局样式统一，持仓当前对象仍显示账户与快照日期。移动端导航统一采用主研究页的每行三项布局。

## 2026-11-26 盈亏日历选月

月份按钮打开暗色选择窗口，内含年份切换和按顺序排列的 12 个月份。每次打开定位到当前月份所在年份，超出原有可选范围的月份禁用。

## 2026-11-26 日历视图和显示控件

「视图」和「显示」采用经营趋势页的分段按钮样式。年度视图在年份下拉两侧加箭头，兼顾逐年翻看和直接跳转。

## 2026-11-26 历史成交券商范围

历史成交默认展示全部已建档券商的有效账本记录，增加券商列，日期筛选和分页在合并结果上执行。

## 2026-11-26 盈亏账户覆盖

成交与转账按全部账户读取。盈亏页按账户展示资料覆盖，保留招商的估算。华泰完整对账资料到齐并核验前，估算留空；跨券商合并盈亏还需要可核对的共同时段。

## 2026-11-26 合并盈亏口径

按用户要求使用目前入库资料复算。合并区间取所有账户覆盖的交集，使用各账户日盈亏及收益基数的总和。已导入银证转账按方向汇总作参考，证券盈亏与收益率计算沿用原有口径。

## 2026-11-26 更新合并区间

取最早账户的复算起点至最新账户的收盘日期，逐日纳入已开始覆盖的账户。后开户账户在起点之前无需提供记录；已有账户在区间内缺数据仍标明。时间范围统一使用「开户至今」。

## 2026-11-26 手动持仓重估

按当前选中的快照做只读重估，独立展示原快照日期与行情日期。重估沿用快照仓位、以最新本地交易日为目标，采用证券自身未复权收盘价，缺当日价格的证券留空。快照后的实际仓位变化以较新券商快照为准。本轮采用手动入口。

## 2026-11-26 保存估算结果

当天完整的收盘重估通过点击一次计算并保存。原券商快照继续保留，日期菜单用「本地估算」区分；非当日或缺价只供预览。修订保留每次采用的结果和原快照引用。

## 2026-11-26 手动添加按钮与表单

「历史成交」和「银证转账」分别提供手动添加按钮。弹窗填表后直接保存到既有账本。两类记录用同一来源归档与事务规则。券商和业务可下拉或输入，交易表单的证券也可搜索或手填。优先复用已有账户和证券资料，用户明确选「新增券商」时与账本同事务建档。买卖及转账的持仓和现金滚动计算仍按已有对账计划分步交付。

## 2026-11-26 手录业务范围

按本地历史业务补充股息入账、股息红利税补缴、红股入账和申购配号。业务决定必填字段以及现金、数量的处理。交收修正、取消和新股、配股全流程待原流水关联及对账规则明确后开放手录。

## 2026-11-26 流水查看控件

历史成交和银证转账采用同一查询交互。保留默认开户至今、成交或转账时间倒序，列筛选和排序作用于全量符合范围的记录，日期按北京时间。

## 2026-11-26 资产轨迹现金口径

资产曲线展示证券收盘市值与账户人民币现金的合计估算。历史现金从最新券商确认值按已识别的人民币资金流倒推，港股、未确认交收修正及未入账的公告分红不用于推算现金。两张图统一使用高对比悬浮提示。

## 2026-11-26 修正迪茨法及 XIRR

按用户选择，单利使用修正迪茨区间收益率，复利使用 XIRR 年化收益率。账户收益率用全账户资产及外部流水，费用、现金估算和分红说明集中在折叠区。

## 2026-11-26 日历收益率口径

盈亏日历使用未年化的修正迪茨区间收益率。顶部和账户收益率曲线继续支持修正迪茨与 XIRR 年化切换。

## 2026-11-26 盈亏与资产摘要

净投入为所选账户在所选日期范围内已入库转入减转出。资产三项取当前账户、证券范围及期间最后一个交易日，缺项显示为空值。盈利／亏损天数和日线覆盖纳入盈亏说明。

## 2026-11-26 日历证券盈亏归属

分证券使用与日历相同的收盘估值、成交、费用及分红口径，仅累计账户范围内整体可复算的交易日。同市场及代码跨账户汇总，零盈亏不进入两栏。逐日分证券取分后的尾差归入当日金额最大的证券，使合计与日历逐日金额一致。

## 2026-11-26 收盘版本展示修订

- 保存和回看统一使用原有持仓主表及日期菜单。生成失败由页面提示。已保存的市值和盈亏从 JSON 回读，成本和现金从保存时引用的原券商版本读取；同日券商收盘优先自动展示。

## 2026-11-26 盈亏分析采用已保存本地收盘日

- 本地收盘版本用于确定分析可延伸到哪一天。计算仍以券商正式快照为确认锚点，之后的仓位与资金按已录流水推进。持仓页的今日盈亏按该版本仓位的价格变动估算。

## 2026-11-27 港股持仓与盈亏补充

- 用户确认 2022-02-15 招商 01919 的一条「港股订单买申报」实际买入 1,000 股。仅确认该记录的业务分类，保留原始业务标志和文件证据。人民币成交金额用于估算，净交收和费用字段保留缺失。
- 01919 的 10 笔股息按用户确认的人民币金额和原入账日，已与每股人民币派息扣税后数字逐笔对齐。港股范围显示证券盈亏和市值，不以账户银证转账推算港股账户收益率。

## 2026-11-27 全证券盈亏口径

- 日历取两种证券范围的已复算日期并集，截止双方均已覆盖的日期。某一市场开始复算前只展示已有市场的已覆盖盈亏。一方在覆盖区间内没有当日记录时，当日只计已复算侧的盈亏和股息，市值沿用上一估值。已有记录明确存在缺口时保留缺口。
- 合并及招商账户默认选择「A 股、ETF 及港股」，港股按最新券商快照固定汇率折算。全证券的账户现金和收益率待港股交收与资金核对后另行处理。

## 证券范围交互

- A 股、ETF 和港股支持任意组合。清空时提示选择证券类型。筛选同步更新盈亏、股息、市值、图表和日历，账户收益率继续使用当前账户原有口径。
- 组合按日加总各类型已独立复算到分的盈亏。已知缺失的当日金额留空，不按零相加。跨市场日期差异继续沿用前述对齐口径。

## 含港股账户收益率口径

- 用户同意沿用估算口径。选中港股时，账户收益率的总资产包含港股，现金仅计一次。买入和净股息进入账户内部现金，不计作银证净流入。组合证券盈亏仍按原有各类型日盈亏相加。
- 收益率控件使用原标签，固定汇率和估算说明置于折叠说明。缺失可用现金、估值或资金流水继续留空。

## 2026-11-27 重估行情日及删除范围

- 优先使用当天已收盘且完整的行情，其次使用上一交易日的同日行情。菜单日期为实际报价日期；旧券商快照编号与已保存的估算版本编号保留。
- 用户可以确认删除一份本地估算快照；保留同日其他版本，盈亏分析依据剩余版本重新确定可复算截止日。
