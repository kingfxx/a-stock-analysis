# 航运研究双 Tab 与运价趋势图计划

日期：2026-10-25。状态：已按用户实施要求完成；验收详见 [TREND_TABS_ACCEPTANCE.md](TREND_TABS_ACCEPTANCE.md)。

## 目标与页面结构

在截图所示独立页面内增加二级 Tab，保持现有企业经营趋势入口和返回路径，不增加左侧一级导航：

- 「利润预测」：承接现有预测页面全部功能，包括参数、版本、校准、历史验证和来源。
- 「CCFI / SCFI 趋势」：展示完整趋势、跨年趋势对比，以及可选的海控实际归母净利润子图。

页面公共标题建议改为「中远海控 · 航运研究」，利润预测 Tab 内保留原标题。现有 `tab=shipping-forecast` 链接默认进入利润预测；通过额外子视图参数保存选中 Tab，支持刷新和浏览器前进后退。趋势 Tab 首次打开再读取本地趋势数据。

## 已核实的存储与覆盖边界

仅从 `research_shipping_rate_points` 读取运价事实，不采集、不重算预测、不保存模型版本。使用未被后续修订替代的记录，来源通过公共证据引用追溯，无需新增表或迁移。

本轮只读查询的当前快照（覆盖首末期不等于逐期完整）：

| 指标与频率 | 本地资料 | 当前边界 |
|---|---|---|
| CCFI 官方月度 | 2,073 条 monthly_mean，含各航线 | 2014-01—2026-09 |
| CCFI 官方周度 | 26 条，综合及航线 | 2026-10-16、2026-10-23 |
| CCFI 补充周度 | 188 条，含日历推定与标记数据 | 2023-01—2026-10，需逐点质量提示 |
| CCFI 补充月度 | 45 条转录资料 | 2023-01—2026-09，与官方重叠 |
| SCFI 官方周度 | 2 条综合 | 2026-10-16、2026-10-23 |
| SCFI 月度 | 暂无 | 首版不以周均冒充官方月均 |

月表还存有 `annual_mean`、`ytd_mean`，不能混入月度走势图。周度只取 `release`，月度只取 `monthly_mean`。SCFI 若未来出现美元/TEU、美元/FEU 航线值，按实际单位展示，不能一律标成指数点。

## 筛选与默认状态

共享筛选区供两张趋势图使用：

- 指标：CCFI / SCFI，首版单选，默认 CCFI。
- 口径：月度 / 周度，默认月度；无该频率时显示明确空态和可用频率提示，不静默改成另一种统计口径。
- 航线：综合或该指标、该频率下真实存在的航线，默认综合。切换后原航线不可用时回到综合并显示提示。
- 时间范围：全部、十年、五年、三年、一年，默认全部；以所选序列最新有效所属期为截止点，页面显示实际首末日期。近 N 年采用滚动日历区间。
- 来源质量：默认「仅官方」，可选「官方优先＋补充资料」。后者仅在相同语义、相同所属期无官方值时使用补充，保留转录/推定日期标识，不覆盖官方值。两种模式均不插值。
- 利润：不显示 / 单季度归母 / 年初累计归母，建议默认不显示，按需打开。

运价数据的 `channel`、`quality`、来源 ID 和修订 ID 随 API 返回。默认选择同口径最新修订；不同来源同一期出现冲突时执行明示的官方优先规则，并保留冲突诊断。多个官方来源无法判定优先关系时不得按行 ID 随意取值。

周度航线原名含「航线」及括号残留，月度多为短名称。实现前建立经核对的有限别名映射，保留原名与实际来源；只规范确认等价的名字，西非、东西非等范围不同的航线维持独立，不以模糊字符串合并。

## 完整趋势图

- 横轴为真实日期：月度按月末锚定，说明其值为整月均值；周度采用来源发布日期，推定日期明确标识。
- 运价折线保留原值、单位和精度，明显缺期断线；月度缺月明确留空，周度停发与漏周不能凭日差直接判定，无法核实时显示间隔说明，不编造预期发布日。
- 标题、单位、图例、颜色、网格、时间范围与筛选外观复用项目现有 Plotly 图表风格。
- 若启用利润，在运价图下增加独立纵轴的利润柱状子图，共享日期横轴及缩放范围；利润只在真实报告期末出现，不扩散成每周/每月数值。
- 两张图附近展示所选数据的覆盖、点数、最新所属期、真实采集时间和来源质量；覆盖不足照常展示已有点，不把首末期称为连续完整历史。

## 多年趋势对比图

- 年份多选，候选来自共享筛选范围内有数据的年份；默认最近四个可用年份（如具备覆盖时为 2023、2024、2025、2026）。时间范围变化后保留仍有效选择，并提示被移除年份；单年也可查看，不虚造对比。
- 月度横轴固定 1—12 月，各年一条线；当前年未发生月份留空，不补齐、不延长到年底。
- 周度建议按 ISO 周序比较，使用 ISO 周年归属，周 53 单独保留；年界发布日期和归属年需解释，不将第 53 周压入第 52 周。同一 ISO 周如有多条有效发布，保留明示的周期内最后有效发布规则与真实日期，不能静默覆盖。
- 月度年份使用日历年，周度年份使用 ISO 周年，切换频率后重建年份选项并说明。周序对齐不代表各年发布日期相同，也不代表春节等节假日对齐。
- 若启用利润，在下方显示同组年份的 Q1—Q4 分组柱状子图，各年颜色与运价线一致。月度/周度筛选只改变运价，利润仍为财务季度，清楚标明两个子图横轴粒度；不将季度利润转换成周利润。
- 共享范围只提供可比较数据窗口；滚动范围造成首年不完整时保留真实截断并提示，不偷偷扩展到全年。

## 利润口径与解释

利润使用本地 `financial_reports` 的 601919 中国准则归母净利润，遵循 gjzb 优先、lrb 逐项回退，沿用 `PARENETP` 及亿元换算。复用现有财务读取逻辑并补足累计返回：

- 单季度：Q1 直接取累计，Q2—Q4 用本期累计减同年上期累计；任一必要值缺失则留空，不能跨年差分。
- 年初累计：直接读 Q1、H1、前三季度、全年原始累计值，不能把残缺季度求和冒充完整累计。
- 保留有效零值及负值；趋势中只画已披露实际，不把预测值混入历史。
- 报告期末是经营所属期，非披露日；该图用于观察同期关系，不能据此证明当时已知或因果关系。

首版不加运价滞后或相关系数，避免与预测页已有提前一月/两周窗口混淆。可在后续增加季度运价均值与单季利润散点、可选滞后和共同样本数，但需独立定义及验证，作为候选扩展。

## 悬浮提示与交互

遵循 `docs/chart-tooltip-style.md`：统一横轴提示，标题只出现一次日期或周期，序列行仅显示「名称：数值 单位」，隐藏额外 trace 名称框。

- 完整趋势：日期轴标题 YYYY-MM-DD；月度均值、周度发布值的日期含义在图旁说明。
- 跨年月度：标题为月份；序列名称带年份，数值行不重复日期。
- 跨年周度：标题为 ISO 周序；各年真实发布日期通过邻近可展开的「数据明细」表查看，提示框不重复堆叠日期，图旁明确周序并非同日。
- 季度利润：提示标题为 YYYYQn 或跨年图的 Qn，各序列行注明单季度/年初累计归母与亿元。
- 补充资料与推定日期采用可辨识标记，并在数据明细保留来源、所属区间、发布日期、质量、修订信息，避免仅靠颜色识别。
- 窄屏筛选自动换行；多年份图例可换行，图表 resize 在切换 Tab 后执行，隐藏 Tab 不出现零宽图。
