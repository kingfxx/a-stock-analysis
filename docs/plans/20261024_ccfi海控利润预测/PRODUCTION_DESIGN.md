# 601919 专用利润预测页正式接入建议

状态：2026-10-25 首版正式接入已实施，实际范围与数据缺口见ACCEPTANCE.md；下文保留原设计及扩展边界。统一采集管理已在独立任务实现，航运按现有注册/调度接口接入，不重建公共管理系统。沿用原研究计划。

## 页面入口

- 按用户截图指定位置，在企业经营趋势“历史数据”表格下方、口径说明文字之后、“说明”折叠项之前，仅601919显示普通文字链接“中远海控利润预测 →”。取消左侧栏入口和入口摘要卡，不新增一级导航。窄屏下链接单独成行，避免挤入横向滚动表格。
- 链接打开独立预测视图，建议深链 `/?code=601919&tab=shipping-forecast`，预测页提供返回经营趋势的链接。预测模块单独JS/CSS/API与计算代码，复用股票选择、布局和数据服务，不新开后台、不扩成全股票通用框架；不把预测金额写进实际财务图表或financial_reports。
- 正式页包括情景测算、数据覆盖、参数依据、历史验证、预测复盘、数据管理。保留当前完整实验页作研究快照。
- 目标季度可选，季度内提供截至当前数据的测算；季度结束而财报未出时继续预测；实际披露后保存预测与实际对照，不自动删除旧季度或用实际重写预测。

### 用户确认的周度来源（2026-10-24）

- CCFI：[SSE当期页面](https://www.sse.net.cn/index/singleIndex?indexType=ccfi)。SCFI：[SSE当期页面](https://www.sse.net.cn/index/singleIndex?indexType=scfi)。只使用免费可见的当期信息，不承诺免费历史查询或以查询日期参数取得旧期。
- 历史CCFI导入用户的《CCFI_2023-2026_图中数据.xlsx》，周度与月度分别保留；图中转录、日期推定、备注矛盾和待核对状态一并迁入。该文件没有SCFI历史，SCFI从正式接入后积累，不借用CCFI数值补齐。
- CCFI页面本次可见上期与本期的真实日期及数值；实现时可保存页面实际提供的两期值用于重叠核验、有限补漏，不能据此保证任意漏周均可补齐。已有同日值改变时保留来源修订，不直接覆盖旧证据。
- 本次已读取CCFI页面；SCFI页面读取超时，尚未核验响应字段。实现时须以实际响应样本确认解析规则；超时与拒绝分开记录，按公共恢复规则处理。
- 原始页面响应先归档；按用户追加要求，CCFI首版结构化保存综合指数及全部可见航线（当前12条）：日本、欧洲、美西、美东、韩国、东南亚、地中海、澳新、南非、南美、东西非、波红。一起读取上期、本期、日期及来源公布涨跌幅，不需要逐航线请求。校验涨跌幅时容许来源显示精度的舍入差异，保留公布值与本地计算值的区别。CCFI、SCFI数值定义不同，不直接拼接或互相替代；首版SCFI只作辅助观察，不在缺少历史回测时改变主预测参数。

### 交通运输部月度历史来源（2026-10-24追加）

- 入口为[出口集装箱运价指数目录](https://www.mot.gov.cn/shuju/yunjiazhishu/chukoujizhuangxiangyjzs/)，目录已看到2023—2026年逐月指数标题链接；先发现链接，再按目标月份核对实际覆盖，不仅靠标题相似就认定数据完整。首轮范围建议2022年12月至2026年最新已发布月份，前者补2023Q1提前一月窗口所需基数，逐月验收后才扩展更早历史。
- 标题识别目标年月与“中国出口集装箱运价指数”，排除同目录“市场分析报告”、上海出口及其他指数。数据所属月、页面显示发布时间、实际采集时间分别保存；URL目录年月不代替报告月或发布时间，例如2024年1月页面URL在202512路径下。
- 2024年1月样本是HTML表格，包含上一年均值、当年至今均值、当月值、环比及简单平均说明；2026年8月样本正文为图片。归档HTML及实际数据图片，图片提取后的行列、负号、小数及单位校验通过才发布；不确定值留待核验，不当作成功覆盖。图片识别不在页面读取时触发模型，需模型时仅明确生成操作使用额度。
- 月度综合、各航线及实际提供的年度/年初至今参考值、公布环比分别保存统计口径及区间，不把年初至今列当月值。历史“西非”与当前“东西非”不能仅凭名称相近合并为同一序列；保留原名称，核验定义后再决定映射。
- 2024年1月官方综合月值1191.91，原Excel月值1441，原周值简单均值1191.75。官方页提供了核对依据，仍保留Excel原件与差异记录；只有已校验官方月份才作为对应官方月度模型输入，生成新数据/模型版本并重跑回测，不能静默改变既有预测快照。
- 月度均值不能还原逐周历史，不据此补齐周值或SCFI历史；周度历史仍由Excel补充。官方月度与本地周聚合保持独立统计身份，不能强制相等。

## 可选扩展

- 港口集装箱吞吐量：用户新增的交通运输部月度市场分析报告可提供全国/沿海/内河当月TEU及同比，作为箱量假设的行业参照。已核实2026年9月报告（10月15日发布）引用的是8月吞吐量，不是9月。采集必须分别记录报告月、指标所属月、发布时间与取得时间；当季预测回测只能使用当时已发布数据。
- 该指标是港口装卸口径，不能等同海控承运箱量或用同比直接替代公司同比；海控全球业务、国内外及航线结构、市场份额、港口中转装卸次数均会影响映射。先将季度吞吐量同比与同口径公司单季箱量同比对照，检验固定基线及加入行业变量的滚动预测误差，再决定传导系数；不预设有效。月量求和后与上年同季总量比较，不直接平均月同比。CCFI运价领先窗口不自动套到吞吐量。
- 首版可展示行业箱量参考，不自动改变三情景箱量假设。报告中若还有租船租金变化，只作为另一个待验证成本代理，不直接视为海控当季成本涨幅。全国3012、沿海2668、内河343万TEU的样本存在1万TEU加总舍入差异，保留原值并按来源精度校验，不强行平账。
- 吞吐量不放进research_shipping_rate_points或公司财报指标表。实施前先检查既有行业统计存储能否复用；确无适用表时另设轻量research_shipping_industry_metrics（暂定，第4张候选表），保存指标、全国/沿海/内河范围、所属期、当月/累计口径、单位、数值、公布同比与来源引用；按新表规范登记维护说明。当前只增加候选设计，尚未建表或回填。

- 具体航线CCFI：欧线/地中海/美西/美东/亚洲区内等，须先核实真实来源可取得的历史覆盖和可比口径，再讨论用集团航线收入/箱量调整权重。官方非订购访问不能承诺任意历史或实时航线数据。
- 汇率：可使用外汇局/中国外汇交易中心公开人民币中间价形成参考均值，但中间价不等于公司结算汇率；当前模型以人民币收入拟合，不能再无条件重复叠加完整汇率影响。
- 船用燃料价格：必须是具体燃料等级、地区、频率的真实基准。只作成本情景参考，先验证数据可用性；Brent不直接当船用燃料成本，采购价格不直接当当季消耗成本。
- OOCL季度经营数据可作辅助交叉验证，不能直接替代海控集团收入/箱量；未核对范围前不纳入主模型。

## 自动事实和人工假设分开

- 更新运价，只更新适用窗口和已确认模型的计算结果。当前季度未结束时，清楚显示“已观察多少点/还缺多少未来点”，未发生的运价保留为情景假设，不用当前均值、旧期或零伪装成完整季度事实。
- 不同目标季度使用自己的运价截止。例如Q3提前2周窗口在9月16日结束，之后的新周价主要影响下季度，不应继续改变已经闭合的Q3运价窗口；来源修订例外需显式标注。
- 未来箱量增长、单位成本增幅、毛利以下净额、税前转归母比例仍是预测假设，不能“抓取”出尚未发生的真实数值。页面展示历史参考、公司最新已披露数值和本次假设的区别。
- 新实际季报通过口径及覆盖校验后追加样本、计算候选模型与回测；不自动因为一次短样本最优而在2周/3周/非线性间切换。模型版本和默认发布单独管理。
- 用户保存的三情景和手动覆盖不能被周度更新清空。采用新模型/新基准重新推算时生成新方案或版本，原方案可回看。
- 页面GET只读本地。参数调整本地即时计算；预测页提供“保存方案”“重新校准”及“前往采集管理”导航。全部批量采集的启动/停止/范围选择/定时配置统一放在后台维护→采集管理，预测页不设可执行“更新数据”按钮。确定性计算不依赖模型额度。

## 正式存储与现有工程衔接

- 事实仍复用financial_reports；公告元数据仍复用原流程。PDF和逐页解析用正式company_reports存储，研究samples中的原件按哈希导入/引用并登记，校验相同内容避免重下和重复。正式页面不直接依赖verification目录。
- 现有CompanyReportService.prepare/discover主要是最新annual/interim，不能当作已支持完整季度报告准备；正式接入时利用已有公告元数据定位Q1/Q3文档，补齐这部分，采集继续经RequestCollector。
- 运价、解析指标、预测版本是独立的新业务事实。新表统一research_shipping_前缀，分别为 `research_shipping_rate_points`、`research_shipping_report_metrics`、`research_shipping_forecast_versions`，具体字段与键在实施时定稿；引用公共source/batch和PDF/parse，不逐行复制原文、URL或大段来源JSON。
- 运价事实保留指数/频率、观察日、数值、真实发布/取得时间、质量、来源与修订；历史图转录和推定日期有独立质量身份，不冒充官方带日期原始序列。月均与周均独立，不无声互相替换。
- `research_shipping_rate_points`包含航线标识/原名称、统计类型及区间、单位和公布变动率等维度，综合指数使用独立标识；无需每条航线新建表。来源页面和图片仍通过公共source引用，避免每条航线重复存正文。月度事实的提供网站为交通运输部，原始数据生产方按页面记为上海航运交易所，来源链不能简化成直接从SSE抓取。
- 报告指标保留集团/子公司、航线范围、金额单位、币种、累计/单季、报告期、报告版本、提取版本和证据页；单箱收入及单季差分作为可追溯计算，不拿半年/年度均值冒充季度。
- 预测版本保存目标季度、预测生成时点、输入数据版本引用、模型系数/版本、训练截止、三情景参数及结果。避免复制完整源库；数值精度与修订证据不能精简丢失。
- 新表上线前按项目要求登记sqlite-storage、maintenance.DESCRIPTIONS/TIME_COLUMNS/PARENT_TIMES，验证维护页记录数、大小、分类和真实更新时间。用代表性数据实测行大小/总索引占用/常用查询/写入耗时，不先承诺未经测量的体积和性能。
- 新来源请求沿用公共归档、真实提供方锁、跨进程预算及拒绝冷却，不将航研所与航交所两个域名当成独立额度。现有其他个股和指数采集速度例外不自动扩给新运价任务。
- 统一采集管理已实现，先读其TASK_CATALOG.md及quarterly_dashboard/collection_management.py、collection_schedule.py的当前接口，将航运注册为真实任务。所有手动/历史回填/停止/定时操作在管理页；不新增独立调度线程，不复用其他任务开关。航运新增定时默认关闭，保留既有拥挤度/指数/国债配置和授权状态；8765停机时不伪记检查成功。

## 必须先处理的实际缺口

1. 当前周次日期只是日历辅助推定，需补带真实发布日期的历史，无法取得的保留推定质量与模型限制。
2. 2024年1月月值1441与周均1191.75不一致，部分周值与“未展示”备注矛盾；先保留双方与核验状态，不导入后默认全为已验证。
3. 官方可查最新综合指数不等于免费取得任意历史。后台若停机漏周，要记录缺口，使用有依据的历史渠道/导入补齐，不能悄悄补成上期值。
4. 本地预测回测采用现有财报版本，没有完整当时可得快照。固定系统从接入日起保存预测版本，之后才能形成真正可复盘的实时样本。

## 建议分两阶段实施

首版：正式迁入既有资料、数据质量/覆盖展示、601919专属入口、原模型和周度对照、SSE当期CCFI/SCFI手动增量更新、参数方案与预测版本保存、披露后误差复盘。周度采集频率按用户建议纳入设计；当前未创建定时任务，先验证增量闭环，再配置独立可见的定时开关。

扩展：授权范围内历史缺口恢复、SCFI积累足够样本后的预测增益检验、航线/汇率/船用燃料等经验证的新来源、更细成本模型；按新增信息的预测增益决定纳入，不按来源数量堆砌。
