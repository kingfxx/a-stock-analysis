# 设计决策

## 用户已确认的方向

- 港股进入三个现有个股页面，并可与 A 股在「我的股票」同组管理。
- 港股来源可以独立实现，采集入口共用现有「个股采集」卡片。`601919 01919` 是手动混合采集的验收输入。

## 存储决策

原则上共用证券主表、现有业务事实和公共采集表。按证券身份、来源和口径区分记录，按实际需要扩展约束或字段。港股来源适配独立于表布局，主要改造如下。

| 现有表 | 接入前需要的改造 |
| --- | --- |
| `instruments`、分组、最近查看 | `instruments` 的市场和代码检查目前仅支持沪深六位代码。迁移允许 `hk` 及五位数字文本，保留 `(exchange, code)` 唯一性、原 `id` 与 `search_*` 字段，分组和最近查看继续引用原证券 ID。复制迁移用新版本，检查所有引用、视图、触发器和索引，按现有启动备份流程预备回滚。 |
| `raw_daily_prices`、`adjusted_price_versions`、`adjusted_daily_prices` | 可共用现有证券、来源、交易日与复权版本约束。为读接口提供有明确定义的报价币种，港股 HKD 范围按证券／报价线路核实，遇到其他币种柜台不套用 HKD。港股接口和复权定义以真实接口、批次范围和版本标识追溯。 |
| `financial_reports` 及财务来源记录 | 键已经含证券、来源、报表类型和期间，可容纳东财港股三表。需复核衍生来源约束及修订保留机制，扩展契约以表达列报币种、单位、准则和期间类型。币种取财报或来源元数据，保留原字段码和证据。读层按各自来源映射到共用指标契约。 |
| `valuation_observations` | 键已含证券、来源、指标、日期，可共用。保留实际观测日、采样版本、币种、单位与总市值口径，现有 A 股行业快照的定义继续用于原有消费者。 |
| `dividend_events` | 可扩展同一张表。现有 `cash_per_ten` 表达单笔每十股值，无法完整表达港股宣派和支付的双币种、每股准确金额与派付日。新增适用的可空语义字段并保留十进制精度，保留 A 股原字段及读写兼容；复核来源、事件键和版本约束以支持港股修订。 |
| `business_segment_versions`、`business_segment_items` | 事实结构可共用。目前版本来源检查及触发器写死东财 `RPT_F10_FN_MAINOP` 及相应请求证据。验证港股来源后定向扩展允许的来源和身份校验，保证证券、报告期、run、batch、source 和定义相符。对意义不同的利润字段保留独立语义。 |
| 公告身份、元数据及披露日事实 | 现有 `stock_announcement_identities` 和相关触发器绑定巨潮及其请求。按港交所发行人和公告 ID 的实测契约扩充提供方、标识和证据检查。现有巨潮标识、候选和历史不动，已证明可保持相同语义的披露日事实继续共用。 |
| `sync_runs`、`sync_state`、公共 `collection_*` 表 | 复用既有控制和事实同步状态。业务范围以证券 ID 或显式市场与代码识别，来源身份使用真实提供方。公告和主营来源适配带来的约束扩展要保持原有一致性校验。 |
| `stock_fact_revisions` | 现有日线、三表、估值和分红表的自然键只保留当前事实。v59 在实际值修订时额外保存旧业务记录及其原 run 引用，避免覆盖后只能看到请求元数据。未变化事实不生成修订。 |

若实测某项数据无法无损落入共享结构，先在本文件记录具体字段冲突、查询职责、数据规模和迁移影响，再决定是否需要领域专表。新增表时同步 SQLite 文档、维护分类、真实时间路径与统计验收。源文件和正式 PDF 的备份仍按各自资料策略处理。

## 运行状态与兼容

- 同名 A/H 股是独立证券，财务数据按可追溯的来源口径保存。以 `601919` 自动填补 `01919` 的财务、股本、价格或派息会破坏事实身份，港股适配读取自身披露链。
- 已有六位 A 股链接和接口保持兼容，市场识别只接入本次改造的共享入口。现有数据服务和公开 API 的 A 股专用消费者先列清单，按调用点分流。避免把港股查询误导到 A 股行业快览、笔记数据快照或模型入口。
- 手动混合采集把未支持项显示为「不适用」，界面和结果从同一份后端适用性判断生成。未发请求的项目不生成来源记录，也不计为采集成功。已保存 A 股规则保留现有范围，混合规则由用户显式配置。
- 优先复用现有针对腾讯、东财、百度、同花顺的真实 provider 标识。披露易按其真实提供方登记并使用公共预算，保护范围覆盖同一提供方的各接口。A 股原有单股速度例外保持现有授权范围，港股新增适配走公共保守策略。
- AkShare 用于调研和对照。生产请求通过现有公共采集入口登记和调度，解析显式接收响应内容，避免库内隐藏请求和重试。跨模块共享的是证券身份、事实契约与公共采集机制。
- 主营来源改用 Stock Analysis 的公开港股 metrics 页。01919 的年度分部和地区收入已返回，2025 年集装箱航运、码头及抵销与年报精度一致。供应商带缩写的收入保留可追溯的展示精度，缺少完整构成的年度标示覆盖缺口。披露易元数据每次从公共证券检索确认标识，请求和识别结果与实际公告批次关联，现有巨潮专用身份表维持现用途。
