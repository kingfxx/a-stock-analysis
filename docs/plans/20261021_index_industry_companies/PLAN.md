# 指数页直达行业内公司

指数二级行业选择右侧、个股估值叠加股价按钮旁提供同样式「前往行业内公司」按钮（青色实底，无图标）。指数按一级／二级选择跳转；个股显式跳转所属三级行业，均定位公司标签。

行业页直接打开默认全市场（本地已导入沪深名单），不跟随当前个股。跳转或手动选择后，在本标签页会话中保存行业与排行层级，切页、换股及刷新继续保持；明确跳转覆盖记忆，清空一级回到全市场。

复用现有 SW2021 分类映射及财务、市值计算，不增加采集或数据库结构。读取接口支持 all（全市场）及 stock（明确按股票分类）范围。

验收：一级／二级跳转、分类选择、公司标签及定位正确；非行业隐藏；保留当前股票上下文；移动端不溢出。

性能反馈：全市场公司列表分页，每页最多 100 家；搜索及排序仍作用于全部公司。指标显隐只更新图表，切回已加载行业页不重建内容。验证切换耗时、DOM／JS 堆变化、翻页／搜索／排序及导航回归。

指数选择反馈：首次保持沪深300默认；本标签页会话中记住指数类别和代码，切换页面或刷新恢复；行业按目录还原一级／二级选择，失效或损坏的记忆回退默认。

个股估值显示反馈：移除卡片顶部重复指标提示，状态字号与指数页统一为 20px；DCF 与普通估值整块互相替换，切回普通指标恢复内容和图表尺寸。
