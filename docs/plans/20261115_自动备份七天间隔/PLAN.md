# 自动备份七天间隔

- `Database` 负责按现有自动快照文件判断是否满 7 个 UTC 日历日。检查云同步目录及历史归档，复用现有快照创建、校验、归档和保留逻辑。
- 应用初始化和个股更新前检查调用同一入口。初始化依赖现有运行时实例锁，并发更新沿用现有备份锁。保留已有文件名，专项及显式备份继续使用原入口。
- 在隔离库验证无历史首次创建、7 天边界、重启后使用既有备份、更新并发与失败约束。随后安全重启 8765，核对原库近期快照和服务状态。
- 云同步与本地归档合计保留最近 3 份自动快照。下次自动检查时即清理超额快照，也覆盖尚未满 7 天的情况。隔离测试验证既有归档轮转和创建新快照后的轮转。
