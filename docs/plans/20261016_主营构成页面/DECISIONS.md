# 决策

- 使用现有页面内 Tab，位于企业经营趋势之后，名称为主营构成；不增加第一 Tab 指标。
- 保持现有深色 CSS 变量、字体、卡片和 Plotly；五块图单列全宽，手机横向查看图表和表格。
- 分项事实只取东财 MAINOP 已存当前版本，不与新浪公司整体财务拼接；无采集、表结构或模型改动。
- 年报／中报／一季报／三季报按相同月日分开，默认年报，无年报时使用最新实际报告期类型。不做单季差分、TTM或半年度与全年比较。
- 跨期严格使用来源 item_key（代码＋名称），不自动合并更名。同比按相同项目及上年同日，本期缺失或基期非正时不可比。
- 毛利率和三种占比直接使用来源字段，小数转百分数；不自行补成本、毛利或毛利率，不归一化占比。保留负抵销，不使用100%归一化堆叠。
- 排除明确命名的整维度合计行及“其中:”／“其中：”下级明细，避免主项和子项重复堆叠，原始明细完整保留；非标准分组小计不猜测，提示需核对分类层级。
- 地区维度时避免重复图，保留地区最新明细。所有维度可查看完整七项指标明细及实际取得时间、修订号。
