# 投资笔记模块方案

状态：用户已批准执行，开发及验收完成，待用户使用反馈。日期：2026-10-23。实际结果见 PROGRESS.md。

## 1. 目标与已确认边界

记录用户在不同时间对某只股票的观察、买入理由、预期、仓位想法和后续复盘。日常以几句话的自由叙述为主，不要求填写结构化问卷或完整研报模板。

已确认：

- 一只股票一个 Markdown 文件，以日期二级标题分段，最新记录在上。
- 编辑与预览切换，不做即时所见即所得排版；正文支持直接手写 Markdown。
- 自动保存；以单项数据插入为主，保留数据表插入。
- 后台维护可配置笔记存储目录，可用其他笔记软件直接读写。
- 主入口位于左侧「财务分析」与「行业内对比」之间，以用户本轮截图为准，替代早期讨论的位置。
- 个股的三个页面指「企业经营趋势」「主营构成」「财务分析」。

用户在方案后明确授权“可以，执行吧”，按本计划开发及验收。未授权多 Agent 协作，按普通单 Agent 流程推进。

## 2. 页面与入口

### 2.1 主入口：投资笔记

共享侧栏顺序：企业经营趋势 → 主营构成 → 财务分析 → **投资笔记** → 行业内对比 → 指数分析 → 后台维护。

视图键 `notes`，支持 `/?code=300750&tab=notes`；指数页按用户后续授权扩展为当前指数自己的笔记，使用 `index:cn:代码`／`index:sw:代码` 独立身份，绝不按股票代码打开。

笔记页显示当前股票、编辑／预览切换、保存状态，以及「新增记录」「插入数据」「大纲」「导出」。正文区域优先分配空间；不设置买入原因、风险、仓位等必填表单。大纲默认收起，打开后在正文右侧独立目录栏展示一至六级标题；编辑与预览分别跳转，不切换当前模式。

新增记录在文档一级标题后插入 `## YYYY-MM-DD`，同日新建独立记录时附 `HH:mm:ss`，可自行补短标题；仅打开或切换到笔记页不创建空文件，也不自动增加日期段。清空正文可正常保存空文本，不自动删文件。

支持当前股票与全部笔记列表切换，按名称／代码定位；第一版不引入独立搜索数据库，正文关键词检索扫描笔记目录，规模明显增长再考虑可重建索引。取消关注不删除笔记；全部笔记列表仍能打开对应文件。

### 2.2 三个个股页面的快速入口

| 页面 | 页面级入口 | 数据级入口与携带内容 |
|---|---|---|
| 企业经营趋势 | 共用模块右边缘贴附「记一笔」 | 同组「插入笔记」，按可视面积识别经营趋势、估值、股东、融资模块，预选分组与适用区间／周期／子类 |
| 主营构成 | 共用右侧悬浮「记一笔」 | 同组悬浮「插入笔记」，预选主营数据与当前维度 |
| 财务分析 | 共用右侧悬浮「记一笔」 | 同组悬浮「插入笔记」，携带当前报表、报告期、累计／单季及比较期 |

按最新用户反馈，移除所有模块内重复入口，只在三个个股分析页显示一组按钮。桌面贴附可视面积最大的当前模块右边缘，预留侧边空间，滚动与窗口变化时更新位置和默认数据组；估值继承历史区间，股东／融资分别预选子分类。窄屏右下方横排；其他页面及快速编辑弹窗打开时隐藏。未明确点位时不猜测图表悬浮项，要求选择具体期间／项目。不改图表悬浮提示，不依赖悬浮菜单触发写入。

「记一笔」打开快速编辑面板，展示当前股票同一份文档，复用主页面编辑器、预览、保存与冲突逻辑。面板提供「新增记录」及「打开完整笔记」；来源页面的筛选与滚动位置保持。窄屏使用接近全屏面板。

「插入笔记」先选择并预览数据，再打开同一面板；有已记忆的有效编辑光标时插在那里，否则询问插入位置（新日期记录／现有正文光标），不静默覆盖原文。确认插入才变更正文并触发自动保存。同一浏览器页面只允许一个活动编辑实例，主视图与快速面板交接同一草稿状态。

切换股票时，未完成保存的旧股票内容仍绑定旧股票身份；不得把旧请求响应或草稿写到新股票。普通未授权页面读取不会启动采集或模型，笔记功能只读本地已有资料。

## 3. 编辑与数据插入

### 3.1 编辑器

使用可本地打包的成熟编辑组件，提供标题、加粗、列表、链接、撤销／重做、插入数据；开发时先核对现有依赖与许可，再选型。默认源码编辑，切换预览使用维护中的 Markdown 渲染库并净化输出；禁用原始 HTML 执行与危险链接协议。资源随项目提供，不依赖运行时 CDN。

预览与导出均读取同一 Markdown 内容。第一版不建设图片上传和附件管理系统，但保留笔记目录内的相对资源引用，迁移时随目录复制附件。禁止预览资源通过 `..`、符号链接或绝对文件路径越出配置目录。

### 3.2 单项数据为默认

操作：插入数据 → 选择指标 → 选择日期／报告期及适用口径 → 预览文字 → 插入光标处。快速入口预选当前页面上下文，用户仍可调整。

示例（占位符，不是真实数据）：

```markdown
## 2026-10-23

开始观察主要是估值偏低，PE（TTM）×× 倍，近十年历史分位 ××%；
PB ×× 倍，近十年历史分位 ××%；股息率 ××%。

按单季度看业绩依然增长，2026Q2 归母净利润同比 +××%（单季度）。
考虑买入 3% 仓位观察，等下一季度再验证。

```

按最新用户反馈，插入数据只生成普通文字或 Markdown 表格，不添加脚注标记、批注及插入时间说明，以兼容通用阅读器。选择器仍展示数据日期和必要口径，表格保留相应列。应用继续兼容旧脚注预览，不自动删除或重写用户已有内容。

### 3.3 指标与口径

| 分组 | 首批指标 | 必要上下文 |
|---|---|---|
| 估值 | 本地已有股价／PE／PB／股息率及可用历史分位 | 各自真实观测日、估值定义、分位区间与采样方式 |
| 经营趋势 | 营收、归母利润、扣非归母利润、同比、现金流及页面已实现指标 | 单季度／累计／年度／TTM、报告期、单位、实际来源和公式 |
| 筹码与融资 | 股东户数、户数变化、融资余额、融资买入额及确已存在的融券字段 | 户数截止日与披露日、交易日、户／元／股等明确单位 |
| 主营构成 | 项目收入、成本、毛利、占比、毛利率及已有同比 | 维度、项目、报告期、原始／统一名称、币种与来源修订 |
| 三表 | 页面已解析科目、本期／比较期、已实现变化率 | 报表类型、合并范围、周期、比较对象、来源字段和公式 |

不能假定所有股票或指标都有上述字段；开发时建立实际字段映射清单。融资余额、融资买入额、融资数量与融券余量分别命名，不混用。股息率沿用系统实际定义，不能套用样例中自行假定的近十二个月口径。

笔记读取接口只能复用本地读取／转换的纯计算路径，不直接调用可能触发到期检查或来源采集的通用个股加载流程。财务优先级、同比有效基数、缺值与单位遵守现有文档；有效零／负值保留，缺值不借旧期填补。历史修订数据不是严格历史可得数据，插入说明注明记录时读到的版本，不伪装成当时已知事实。

默认单项；多选可生成同一句或多行文字。用户显式切换「表格」后生成普通 Markdown 表格，保留数值、日期／报告期、单位和必要口径。未获取数据的选项显示不可用原因，允许显式插入“暂无数据”，不自动采集。

所有插入为固定快照；后续数据变更不回写旧笔记。插入期间源页面筛选或股票变化时须校验上下文版本，不能误插其他股票的数据。

## 4. 文件与存储位置

默认目录建议为项目相对路径 `data/investment_notes/`；配置在后台维护新增「投资笔记设置」分类，展示解析后的绝对路径、可用状态与最近检查结果。用户选定绝对目录时仅保存在本机配置，不把个人路径提交 Git。

股票文件名 `交易所代码_首次建档名称.md`，交易所代码为稳定身份。公司改名不自动重命名已有文件。为保持轻量，新建文件默认只有一级标题及日期段，不添加 YAML；兼容已有通用 YAML 股票身份。不要求模板字段，也不把来源 JSON 塞进正文。无代码身份的外部 Markdown 可通过显式关联股票纳入，保留原内容；已有其他元信息时提示在外部添加 stock_code，重复身份不自动合并或覆盖。

目录选择：必须选择后台所在宿主机的实际目录。开发时实现本地会话鉴权下的宿主机目录选择对话框，并提供绝对路径输入＋校验作为可用后备；网页文件上传／浏览器目录选择返回的文件集合不能充当后端可写路径。对话框取消不改变配置；不得阻塞后台全部请求。

配置操作包括「选择目录」「检查目录」「应用目录」「迁移现有笔记」「重新扫描」。目录存在且可读写才启用保存；不可用时保留草稿并报错，不静默退回其他目录。不覆盖同名非笔记文件，不将任意用户路径直接用于读写 API。

更换目录时明确选择：

1. **复制现有笔记及附件后切换**：展示数量、冲突与空间检查结果；复制后校验哈希，全部成功才更新配置，原目录保留。重名且内容不同则停止并列出冲突，不覆盖。目标不得与源互为子目录，避免递归复制。
2. **使用目标目录已有笔记**：预览识别到的股票及冲突，确认后切换；旧目录保持原样，不隐含合并。

切换前完成保存或明确保留未解决草稿；服务端暂停本应用的目录写入并使旧目录版本失效，旧请求不能写进新目录。复制前后检查源文件是否变化，外部软件仍在编辑导致不一致时终止切换，不宣称应用锁能锁住其他软件。

配置和 Markdown 为主存储，不新增业务数据库表。搜索索引先用可失效的内存缓存。未来确需新表时须另行落实 SQLite 用途、时间、存储成本及维护页规范。

## 5. 自动保存与恢复

- 停止修改 30 秒后自动提交，每次修改重置计时，无修改不写入；显示「未保存／保存中／已保存 HH:mm:ss／保存失败／存在外部修改」。切换、关闭快捷框及显式保存仍立即提交。
- 每文档串行保存、合并待发内容；保存中继续输入不被旧响应覆盖。成功回执对应当前内容版本后才显示已保存。
- 主视图、面板、股票切换与站内导航前立即尝试保存；失败保留草稿并提示，不静默丢失。关闭浏览器时不能依赖异步请求一定完成，有未保存草稿时使用离开提醒。
- 浏览器 IndexedDB 保存按目录身份、股票身份、基准版本隔离的恢复草稿；服务端保存确认后清理对应版本。关闭网页前尚未来得及持久化的最后输入仍存在极短窗口，不能承诺绝对零丢失。
- 磁盘写入先在同目录写临时文件，再刷新并原子替换；Windows 文件占用／权限错误返回明确失败，不截断原文件。
- 按用户后续要求，取消应用内历史版本管理、历史／恢复接口及所有 `.history/` 写入，由云同步软件管理历史；已有历史文件不自动删除或改写。保留当前未保存草稿、哈希冲突检测及手动导出，不额外生成冲突备份。

## 6. 外部编辑与并发保护

读文档返回内容哈希版本与目录版本；写入必须携带基准版本。服务端按文档加应用内锁，在写入前重新读取并比较实际内容哈希，不能只比较 mtime 或大小。多标签页／并发客户端使用同一版本规则。

| 情况 | 行为 |
|---|---|
| 外部变化，编辑器无未保存内容 | 自动刷新，尽量保留光标／滚动位置并短暂提示 |
| 外部变化，同时有本地草稿 | 暂停自动覆盖，保留本地草稿与磁盘内容，显示差异和处理入口 |
| 文件被外部删除或重命名 | 提示失联并保留草稿，不自动重建旧路径；重新扫描／关联或显式恢复 |
| 用户决定采用磁盘版本 | 提示将放弃本地草稿，可先手动导出，再载入磁盘内容 |
| 用户决定采用本地版本或合并 | 预览选择结果，基于最新磁盘版本重新提交；再次变化则再次提示 |

轻量检测：打开／聚焦时检查，活动编辑器约每 3 秒检查版本，页面隐藏时暂停轮询；每次保存始终再次检查。保存接口版本冲突返回 409，并携带可用于对比的最新版本；目录变化返回独立错误。

原子替换保障单个文件完整性，不等于对任意外部编辑器的跨进程事务。替换前再次检查外部变化，但不承诺任意同步软件并发写入绝无覆盖。产品建议避免两处同时编辑；保留当前草稿和导出入口，历史记录由云同步软件负责，不依赖自动猜测合并正文。

## 7. 实现落点与接口草案

现有入口：`quarterly_dashboard/server.py` 的 `research_sidebar` 及 HTTP 路由；`web/index.html` 的视图切换；`web/research-sidebar.html`／`research-layout.css`；三个页面模块；`web/maintenance.js`／`.css`。

建议新增 `quarterly_dashboard/investment_notes.py`（目录、文档、版本、恢复与迁移）、`note_snapshots.py`（本地指标适配），以及 `web/investment-notes.js`／`.css`。先检查已有公共配置、请求鉴权及渲染依赖，复用现有机制，避免平行造一套。

接口草案（开发时与现有 HTTP 约定对齐）：

- `GET /api/notes`：列出已识别笔记；读取文件不创建文档。
- `GET /api/notes/document?code=...`：正文、存在状态、哈希版本与目录版本。
- `PUT /api/notes/document`：股票身份、正文、基准版本与目录版本，原子保存。
- `POST /api/notes/snapshot`：显式选择指标及上下文，只读本地数据，返回普通 Markdown 片段及来源说明。
- 设置检查／宿主机选目录／迁移预览与执行／重新扫描／历史恢复采用独立本地管理接口。

所有变更操作沿用本地会话鉴权、同源校验和大小限制。按可信股票身份定位文件，限制路径范围。Markdown 原始 HTML、脚本 URL、预览资源越界与恶意文件名均需覆盖验证。

## 8. 开发步骤

1. 梳理现有配置与本地指标读取；确定编辑依赖、身份格式和指标映射，更新 DECISIONS。
2. 实现文件存储、条件保存、当前草稿恢复、外部冲突与存储目录设置，先验证文件完整性。
3. 接入侧栏主页面、日期段、编辑／预览、自动保存、导出及当前／全部股票列表。
4. 接入单项数据和可选表格，连接三个页面快速入口及上下文；按最新反馈不生成脚注。
5. 完成目录迁移、相对资源、边界测试和页面验收，同步用户文档。

第一版不做交易系统、收益统计、自动生成观点、模型调用、采集任务、即时预览、图片上传或自动按年拆分。现有样例为设计资料，不能自动导入正式笔记目录。

## 9. 验收与发布

自动测试全部用临时目录与隔离临时数据库，不写日常笔记或数据库。重点覆盖：

- 空文件、中文与 UTF-8、同股票同日多条、外部手写 Markdown、无元信息导入、同名／重复身份。
- 自动保存时继续输入、慢响应、网络失败、双标签并发、切股、面板／主页面交接、草稿恢复。
- 外部修改／删除／重命名、版本冲突、同 mtime 内容变更、Windows 文件被占用、权限不足、磁盘写入失败。
- 三个页面插入正确股票和筛选口径；2026Q2 单季同比不是上半年累计同比；百分位 0.8 即 0.8%，不额外乘 100；零、负值、缺值、旧期、修订与日期不齐。
- 读取和插入笔记不触发模型／采集；行情更新不改写已保存快照。
- 目录不可用不回退、迁移中源文件变化、哈希失败不切换、原目录保留、附件相对路径、符号链接与目标嵌套检查。
- Markdown 净化、目录越界、未授权写入；既有三页面与共享导航无回归。

交付用户文档 `docs/investment-notes.md`，链接到 README 与后台维护说明；如新增指标解释，更新企业经营趋势指标说明且只写实际实现行为。验收材料放 `data/verification/` 对应目录，清理临时产物。
