## 开发前需要通过代码核对的事项

这些是实施检查项，不是必须用户回答才能推进的产品问题。

- 现有本机配置的持久化位置、鉴权及适合复用的依赖。
- 每项估值、分位、财务与融资字段的真实本地读取路径，避免复用会触发采集的接口。
- Windows 宿主机目录选择对话框与原子文件替换在现有启动方式下的行为。
- 路径、配置和历史副本的 Git 忽略规则，防止个人笔记与路径意外进入版本库。
- 历史保留建议上限 50 版、普通版本至少间隔 5 分钟；未解决冲突副本不自动清理。
