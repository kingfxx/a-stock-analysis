# 指数估值收盘后更新当天

## 目标

指数“更新近期估值”在收盘后能够检查当日数据，避免来源已发布当天数据但默认增量截止日在前一交易日而跳过。

## 范围

- 北京时间15:00后，默认增量更新在当天为交易日且未指定更早截止日时，将当天纳入采集截止范围。
- 中证、乐咕、申万均使用该截止日；仅发布来源实际返回且通过校验的数据。
- 盘中增量、近期修订核对及其他历史任务保持原日期范围规则。
- 同步维护指数采集说明。

## 验收

- 收盘后交易日增量范围包含当天，盘中及非交易日不包含当天。
- 当天无来源数据时不伪造事实；中证、乐咕和申万可按各自水位请求。
- 通过相关检查并确认共享限速／冷却入口未绕过。
