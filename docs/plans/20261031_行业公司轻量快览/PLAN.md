# 行业公司轻量快览

状态：已实施并完成必要验收；宿主机8765运行最终版本。日期：2026-10-31。

## 目标与边界

行业内公司列表点击公司名称，在当前页面打开大浮层，快速查看该公司的本地财务及季末市值趋势。关闭后保留行业范围、搜索、排序、分页和滚动位置；需要深入研究时，由「完整个股展示」进入现有完整页。

本功能只读已有全市场财务与行情，不触发个股首次初始化、来源请求、采集任务、模型调用或股票库写入。当前任务独立于已完成的行业导航任务；本目录持续维护后续实施、调整和验收记录。本任务按单代理实施。

## 指标范围

第一版已实现以下14个财务／市值指标，并提供1个可选季末股价指标。具体核验与限制见 data/verification/reports/20261031_company_preview.md。

| 展示名称 | 本地来源／公式 | 周期及约束 |
|---|---|---|
| 营业总收入 | market_financial_industry.revenue，来自收入表 total_operate_income | 与行业列表一致；明确为营业总收入 |
| 归母净利润 | market_financial_industry.parent_profit | 流量 |
| 归母扣非净利润 | market_financial_income.deduct_parent_netprofit | 流量；不从归母利润估算 |
| 净资产（所有者权益合计） | market_financial_balance.total_equity；缺失时同一期 total_assets－total_liabilities | 时点；派生值记录公式，不替代归母净资产 |
| 营收同比增长率 | 同周期营业总收入同比 | 缺基期或基期非正不计算 |
| 归母净利润同比增长率 | 同周期归母利润同比 | 同上 |
| 累计加权ROE | market_financial_industry.weighted_roe，来自业绩指标 weightavg_roe | 保持所选报告期累计值，不差分、不相加、不年化；不能称为TTM估算ROE |
| 经营活动现金流净额 | market_financial_cashflow.netcash_operate | 流量 |
| 销售收现（主营现金流） | market_financial_cashflow.sales_services | 流量；是现金流入，不是经营净现金流 |
| 简化自由现金流 | netcash_operate－construct_long_asset | 两项按同周期转换，必要输入缺失留空；不是严格FCFF／FCFE |
| 毛利率 | 同周期营业收入及营业成本重算 | 复用现有行业规则：operate_income优先；仅明确的非金融公司允许按同口径 total_operate_income 回退；缺值不使用营业总成本 |
| 净利率 | 同周期（total_profit－income_tax）÷适用营业收入 | 合并净利润为派生值；收入规则同上。实施前以本地详细报表核验字段定义、范围和金额，不用归母利润替代；核验不通过则暂不开放并记录原因 |
| 资本开支CapEx | market_financial_cashflow.construct_long_asset | 流量；保留来源有效零／负值，不擅自取绝对值 |
| 季末总市值 | market_trade_snapshot.total_market_cap | 时点；沿用行业已发布版本及来源优先级，不调用完整个股页估算市值公式 |
| 季末未复权股价（可选） | market_trade_snapshot.close_price；缺失时复用同季匹配的 market_quarterly_prices.close | 时点；保留实际价格日及来源，不混用前复权，不插值；停牌沿用现有已核验快照规则 |

从轻量版选择器中移除：ROE（TTM估算）、ROIC（简化估算）、估算现金分红（已实施）、有息负债（简化）、净现金／净负债、披露日估算市值、披露日前复权股价。即使个别公司已有完整资料，也不在本版额外开放这些指标；完整个股页保持原功能。

金融企业隐藏销售收现、简化自由现金流、毛利率等不适用指标，沿用本地明确分类和现有适用性规则，不按字段缺失推断公司类型。经营现金流和资本支出原始项可展示；分类未知不套用仅限非金融的回退。

流量支持单季度、当年累计、年度、TTM；同年累计差分计算单季，TTM采用本期累计＋上年全年－上年同期，年度只展示年报。比例由所选周期金额重算；累计加权ROE例外。时点值不加总，年度取年末。计算和同比先于时间范围过滤完成，读取必要前置报告期。缺字段、缺期间均留空，不补旧期、不补零，保留有效零和负值。

## 交互

- 公司名称打开快览，保持原行业页和当前完整个股上下文；浮层显示公司名、代码、数据覆盖和最新报告期／市值日期。
- 默认A归母净利润柱形、B不选、C季末总市值折线；提供A／B／C指标、柱线切换及独立单位轴。金额统一亿元，比例为%，价格为元／股。不同单位不得共用错误刻度；各轴统一正负空间比例以对齐零线，范围包含全部可见有效值并留12%余量，保留亏损等负值；单轴也包含零。轴与布局沿用主图规则。
- 指标形状使用与主图一致的顶部「柱形／折线」分段按钮，下方独立指标选择；重复点击当前形状取消显示，两按钮均不选中，图表及历史表同步隐藏，保留指标下拉选择以便恢复；财务周期使用同样的分段按钮。
- 周期继承行业页当前选择，时间范围默认最近10年；可选最近5年、最近10年、全部。只读切换期间不重新加载完整个股页。
- 支持关闭按钮、Esc、点击浮层外空白关闭、焦点约束及关闭后焦点恢复；在浮层内部点击或由内部拖动到外部不误关闭；窄屏按全屏浮层适配。
- 上一家／下一家按当前搜索及排序后的全部匹配公司顺序切换，跨分页仍连贯，边界禁用；快速切换时取消请求或忽略过期响应，不能串股。
- 「完整个股展示」位于操作按钮区最左侧，与上一家／下一家同款按钮，青色强调；点击须先确认，取消保留快览，确认后导航。该入口为显式导航，沿用现有首次建档／本地展示规则；该按钮本身不另加全量刷新调用，已有股票仍由用户手动刷新。
- 覆盖期数、缺值规则及所选指标来源／公式收纳在下方默认折叠的「来源与口径说明」，保持动态更新。
- 图表下直接显示主图同款「历史数据」：所选指标按行、报告期从新到旧按列，固定左侧指标列并高亮最新一期；数值下方并排同比／环比，可横向滚动。单位在表头／指标行说明，不在每格重复。累计口径财务仅同比，市值／股价仍列同比与环比；年度两者均比较上一年。比较使用时间范围筛选前的同周期数据，基期非正或缺值显示—及原因。实际日期与收入依据另用可展开表保留。空数据、单点、部分覆盖、缺基期有明确提示，不把无数据画成零。
- 使用统一横轴悬浮；报告期只出现一次，各序列名称、数值、单位明确。季末交易日／停牌实际价格日保留在返回数据及来源说明中，必要时在共同的价格日期说明展示，避免伪装同日事实；标注报告期横轴不等于财报当时已披露。
- 财务截至2026Q2而行情截至2026Q3时分别注明；图表可保留已有行情独立季度，财务留空，不复制上期值。

## 职责与实现步骤

### 与2026-10-25／26架构优化的对齐（2026-10-31核对）

| 具体位置 | 本次职责 | 不得扩大的边界 |
|---|---|---|
| http/routes/industries.py | 接入快览GET路径，校验参数、调用领域读取函数、返回响应 | 不放SQL、指标计算、来源选择或HTML；沿用现有Handler分发与门禁，不向server.py新增业务分支 |
| domains/industries/company_preview.py（新增） | 单公司查询、分类适用性、财务与行情来源选择、返回数据组装 | 显式接收Database依赖；不导入application／HTTP，不调用完整个股加载、初始化或来源服务 |
| domains/financials/company_preview_metrics.py（新增） | 指标映射、周期转换、同比及派生公式 | 只接收内存输入；不导入SQLite、requests、行业服务或带来源／存储依赖的报表服务 |
| application.py／runtime.py | 沿用现有配置及后台生命周期 | 初版无状态领域函数，不新建常驻服务／缓存／锁／调度器，无需增加实例注册和恢复分支；若实际确需状态，再由application统一持有 |
| web/features/industries/company-preview.js／company-preview.css（新增） | 浮层与图表渲染、切股及前端交互 | industry.js只新增入口及传入列表顺序／周期，不把浮层全部塞入现有文件 |
| web/pages/index.html、web/asset-map.json、http/routes/shipping.py现有静态白名单 | 注册展示容器和新静态资源 | 沿用已存在的资源映射／白名单模式；不为此另建资源框架或顺带迁移旧路由 |

纯计算复用须检查传递依赖：现有 industry_service.value_for 虽是计算函数，但所属模块会导入来源／存储模块；statements.previous_quarter 所属模块也会导入 fundamental_service。新纯计算模块不得为复用几个函数反向引入这些模块。优先复用 financials/core.py 等真正纯模块的适用能力；如需共享新的周期函数，按实际调用者做最小提取，不复制完整行业服务或扩展通用注册框架。

Database连接句柄不等同常驻服务状态；路由可按现有配置创建轻量句柄并显式传入领域函数，领域只使用 connection() 默认只读事务，不调用 initialize()。不经 app.industry_service() 获取整个行业服务，以免快览引入其初始化、全市场缓存或运行状态。数据库启动／恢复仍沿用现有生命周期。

### 实施顺序

1. 数据契约与离线口径核验：复核本地来源版本、交易所和报告期，按非金融样本检查净资产派生、净利润派生及毛利率收入回退。保留核验结果和缺口。
2. 领域只读查询：在 domains/industries/ 新增具体的公司快览模块；财务公共周期计算放在领域纯计算模块，复用适用的现有计算，不直接扩充 server、StockDataService 或向行业主服务堆入独立流程。基础营收／归母利润／ROE读取 market_financial_industry，其余通过同股票、交易所、报告期、最新有效版本关联新四表；不回退旧 sw_financial_facts 或个股新浪。
3. 只读API：在 http/routes/industries.py 增加独立入口（拟为 GET /api/industry-company-preview?code=...），只做参数校验、调用和响应。每次仅查询一家公司必要历史，不加载全市场历史。响应提供可用指标、原始报告期、序列、实际观察日、来源引用、派生公式、缺失原因和覆盖。证券代码／交易所解析复用本地目录，不要求 instruments 已建档。
4. 应用组装：如需实例或缓存，由 application.py 显式注入现有数据库及配置；缓存有界且随财务发布、快照版本及分类版本失效，不另起调度器；无需缓存则不增加状态。优先复用已有模式，无必要不新增数据库表、业务数据副本或迁移。
5. 前端：在 web/features/industries/ 新增独立快览JS／CSS，industry.js 仅保留列表入口和上下文传递，模板由展示层挂载。复用现有图表样式与适用绘图函数，不加载完整个股数据链。
6. 回归、宿主机验收与文档：同步实际指标来源／周期／缺值规则到 docs/enterprise-trend-metrics.md，并更新架构导航及适用的行业说明；仅记录已实现行为。验收报告存 data/verification/reports/。

## 验证与完成标准

- 隔离库离线测试：未建档公司可读快览；最新版本、交易所隔离、缺字段、有效零／负值、Q1差分、Q4差分、TTM、年度、同比、时点指标和累计ROE；净利润及净资产派生可复算，金融分类适用性正确。
- API边界测试：拦截来源请求／个股初始化／任务提交，打开、切指标及换公司均无调用；业务表及股票库无变化。复用 tests/test_http_source_boundaries.py 的相关边界检查。
- 前端验证：指标剔除与命名正确；双单位／多单位轴正确；统一悬浮、实际日期说明、缺值断线、全部空值与单点、独立行情季度、快速换股竞争、Esc及焦点、上一家／下一家和跨分页正确。
- 行业导航回归：关闭后行业范围、搜索、排序、分页、滚动及完整个股上下文保持；完整个股页按钮行为与现有授权一致。
- 宿主机8765与原数据库验收：选择建设银行（无完整个股档案）、至少一家非金融公司、历史短或缺期公司；可复算财务＋市值，金融不适用项隐藏，不因查看发起来源请求或建档。记录首次／重复打开和换公司耗时、响应体积；温查询接口目标低于300ms、浮层温加载目标低于1秒，未达目标分析原因，不宣称未经测量的性能。
- 测试使用隔离数据库及业务目录；不另开持续后台。代码检查通过且需重启生效时，核对8765身份与活动任务后安全重启、核对日志及页面并保持运行；纯计划不重启。清理一次性测试资料，保留来源核验样本、验收报告和当前后台日志。

## 风险与实施门槛

- 有记录不代表字段齐全或历史连续；指标可见性和覆盖说明不能以任务成功替代。
- 全市场财务来源与原个股新浪来源不同，数值可能存在修订／口径差异；界面及文档明确来源，不为一致而混填。
- 净利率派生输入覆盖较好，但不能只凭字段名确认合并范围；本地样本核验通过才开放。
- 不新增来源采集、历史回填或自动刷新；缺口通过展示说明处理。未来扩大指标或来源另行讨论。
