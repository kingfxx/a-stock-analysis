# 行业公司轻量快览

状态：原快览及「主图与快览共用展示组件」阶段已实施并完成定向验收。日期：2026-10-31。

## 目标与边界

行业内公司列表点击公司名称，在当前页面打开大浮层，快速查看该公司的本地财务及季末市值趋势。关闭后保留行业范围、搜索、排序、分页和滚动位置；需要深入研究时，由「完整个股展示」进入现有完整页。

本功能只读已有全市场财务与行情，不触发个股首次初始化、来源请求、采集任务、模型调用或股票库写入。当前任务独立于已完成的行业导航任务；本目录持续维护后续实施、调整和验收记录。本任务按单代理实施。

## 指标范围

快览目前提供18项指标，包含原有14个财务／市值指标、季末股价、PE／PB和上年方案年度股息率估算。具体核验与限制见 data/verification/reports/20261031_company_preview.md。

|---|---|---|

| 季末总市值 | market_trade_snapshot.total_market_cap | 时点；沿用行业已发布版本及来源优先级，不调用完整个股页估算市值公式 |
| 季末未复权股价（可选） | market_trade_snapshot.close_price；缺失时复用同季匹配的 market_quarterly_prices.close | 时点；保留实际价格日及来源，不混用前复权，不插值；停牌沿用现有已核验快照规则 |
| PE（TTM，季末） | market_trade_snapshot.pe_ttm | 倍；时点快照原值，按现有来源优先级逐字段选择，缺值不重算，保留零／负值 |

| 年度股息率（上年方案，估算） | 上一年归属的已存方案每股税前派息合计÷本季末未复权股价 | %；事后归属估算，年度仅取年末，不差分、不滚动TTM；详见试版规则 |

从轻量版选择器中移除：ROE（TTM估算）、ROIC（简化估算）、估算现金分红（已实施）、有息负债（简化）、净现金／净负债、披露日估算市值、披露日前复权股价。即使个别公司已有完整资料，也不在本版额外开放这些指标；完整个股页保持原功能。

金融企业隐藏销售收现、简化自由现金流、毛利率等不适用指标，沿用本地明确分类和现有适用性规则，不按字段缺失推断公司类型。经营现金流和资本支出原始项可展示；分类未知不套用仅限非金融的回退。

流量支持单季度、当年累计、年度、TTM；同年累计差分计算单季，TTM采用本期累计＋上年全年－上年同期，年度只展示年报。比例由所选周期金额重算；累计加权ROE例外。时点值不加总，年度取年末。计算和同比先于时间范围过滤完成，读取必要前置报告期。缺字段、缺期间均留空，不补旧期、不补零，保留有效零和负值。

## 交互

- 公司名称打开快览，保持原行业页和当前完整个股上下文；浮层显示公司名、代码、数据覆盖和最新报告期／市值日期。
- 默认A归母净利润柱形、B不选、C季末总市值折线；提供A／B／C指标、柱线切换及独立单位轴。金额统一亿元，比例为%，价格为元／股，PE／PB为倍。不同单位不得共用错误刻度；各轴统一正负空间比例以对齐零线，范围包含全部可见有效值并留12%余量，保留亏损等负值；单轴也包含零。轴与布局沿用主图规则。
- 指标形状使用与主图一致的顶部「柱形／折线」分段按钮，下方独立指标选择；重复点击当前形状取消显示，两按钮均不选中，图表及历史表同步隐藏，保留指标下拉选择以便恢复；财务周期使用同样的分段按钮。
- 周期继承行业页当前选择，时间范围默认最近10年；可选最近5年、最近10年、全部。只读切换期间不重新加载完整个股页。
- 支持关闭按钮、Esc、点击浮层外空白关闭、焦点约束及关闭后焦点恢复；在浮层内部点击或由内部拖动到外部不误关闭；窄屏按全屏浮层适配。
- 上一家／下一家按当前搜索及排序后的全部匹配公司顺序切换，跨分页仍连贯，边界禁用；快速切换时取消请求或忽略过期响应，不能串股。
- 「完整个股展示」位于操作按钮区最左侧，与上一家／下一家同款按钮，青色强调；点击须先确认，取消保留快览，确认后导航。该入口为显式导航，沿用现有首次建档／本地展示规则；该按钮本身不另加全量刷新调用，已有股票仍由用户手动刷新。
- 覆盖期数、缺值规则及所选指标来源／公式收纳在下方默认折叠的「来源与口径说明」，保持动态更新。
- 图表下直接显示主图同款「历史数据」：所选指标按行、报告期从新到旧按列，固定左侧指标列并高亮最新一期；数值下方并排同比／环比，可横向滚动。单位在表头／指标行说明，不在每格重复。累计口径财务仅同比，市值／股价仍列同比与环比；年度两者均比较上一年。比较使用时间范围筛选前的同周期数据，基期非正或缺值显示—及原因。实际日期与收入依据另用可展开表保留。空数据、单点、部分覆盖、缺基期有明确提示，不把无数据画成零。
- 使用统一横轴悬浮；报告期只出现一次，各序列名称、数值、单位明确。季末交易日／停牌实际价格日保留在返回数据及来源说明中，必要时在共同的价格日期说明展示，避免伪装同日事实；标注报告期横轴不等于财报当时已披露。
- 财务截至2026Q2而行情截至2026Q3时分别注明；图表可保留已有行情独立季度，财务留空，不复制上期值。

### 实施顺序

1. 数据契约与离线口径核验：复核本地来源版本、交易所和报告期，按非金融样本检查净资产派生、净利润派生及毛利率收入回退。保留核验结果和缺口。
2. 领域只读查询：在 domains/industries/ 新增具体的公司快览模块；财务公共周期计算放在领域纯计算模块，复用适用的现有计算，不直接扩充 server、StockDataService 或向行业主服务堆入独立流程。基础营收／归母利润／ROE读取 market_financial_industry，其余通过同股票、交易所、报告期、最新有效版本关联新四表；不回退旧 sw_financial_facts 或个股新浪。
3. 只读API：在 http/routes/industries.py 增加独立入口（拟为 GET /api/industry-company-preview?code=...），只做参数校验、调用和响应。每次仅查询一家公司必要历史，不加载全市场历史。响应提供可用指标、原始报告期、序列、实际观察日、来源引用、派生公式、缺失原因和覆盖。证券代码／交易所解析复用本地目录，不要求 instruments 已建档。
4. 应用组装：如需实例或缓存，由 application.py 显式注入现有数据库及配置；缓存有界且随财务发布、快照版本及分类版本失效，不另起调度器；无需缓存则不增加状态。优先复用已有模式，无必要不新增数据库表、业务数据副本或迁移。
5. 前端：在 web/features/industries/ 新增独立快览JS／CSS，industry.js 仅保留列表入口和上下文传递，模板由展示层挂载。复用现有图表样式与适用绘图函数，不加载完整个股数据链。
6. 回归、宿主机验收与文档：同步实际指标来源／周期／缺值规则到 docs/enterprise-trend-metrics.md，并更新架构导航及适用的行业说明；仅记录已实现行为。验收报告存 data/verification/reports/。

## 主图与快览共用展示组件（已实施）

### 用户要求与验收基准

最初计划要求两处共用HTML结构、样式和绘图／表格展示，减少后续双份维护，并保持「企业经营趋势」主图当前格式。计划编写时仅修改文档；随后按用户指示单代理实施，沿用本目录三个文件。

以实施前主图实际显示为唯一视觉基准：字体字号、颜色、控件尺寸／布局、图例位置、图高、边距、季度标签／跨年间距、轴分组、刻度／零线、工具栏、历史表列宽与最新高亮，以及桌面／窄屏适配均保持。轻量图向主图对齐，不能将快览简化配置反向覆盖主图。提取存在回归风险，须用迁移前后同数据、同选择、同视口对照验证；不得未经对照声称绝对无影响。

两边允许差异仅来自真实数据、指标可用性和外层容器。快览保留弹窗标题／导航／确认／关闭、独立覆盖与来源／分红详情；主图保留标题、财报披露审核、个股说明和其他原有入口。将这些差异作为外围内容或明确的详情输入，不另建两套基础图表渲染分支。

### 当前代码依据（实施前须复核）

- 主图HTML、CSS、指标定义及render()在web/pages/index.html：A/B/C控件、历史表DOM、按单位合轴（市值单独成组）、线性横轴与跨年间距、柱宽／偏移、带同比环比和真实日期的悬浮提示、披露日长间隔参考点／虚线和零线对齐。
- 快览在web/features/industries/company-preview.js动态挂载：独立控件模板、draw()与renderTable()；虽借用metric-mode与trend-history类，仍有一套cp-controls／cp-history覆盖样式。当前按槽位单独建轴、category横轴、左侧图例、不同背景和边距、关闭工具栏，与主图并非同一实现。
- 主图读取state.views等已有个股载荷；快览读取GET /api/industry-company-preview的metrics、rows[].values、market、sources等。后端财务来源及算法不同，不能统一成同一取数链。
- 主图有savedSelections、saveSelections及既有控件ID依赖；周期年度主图为year、快览为annual，线形主图为line、快览为scatter。这些由适配器映射，不能改写后端参数或破坏旧保存设置。
- 静态资源经web/asset-map.json和http/routes/shipping.py现有_get_static_assets白名单提供；该路由当前持有通用静态资源入口，此阶段仅登记新资源，不借机迁移路由职责。

### 数据和实例契约

- 使用标准化的展示模型：报告期／显示标签、指标key／名称／单位／scale／轴分组、A/B/C槽位与形状、可见值、同比／环比及缺失原因、实际观察日／参考点／可选详情。示意字段以实现前核对为准，不强迫不同来源使用同名财务含义。
- 流量转换、TTM、利润率、ROE、估值及年度股息率继续由原后端／原适配路径提供，组件只做展示。不能把新浪／全市场新四表合并取数；季末市值与披露日估算市值、累计加权ROE与TTM估算ROE保持不同身份和说明。
- 比较期查找在时间范围裁剪前完成；有效零／负值、缺值断线、独立行情季度、单点和全部隐藏提示保持。若提取同一百分比格式／比较函数，需保留原基期非正和缺期原因，不顺带改口径。
- 时间范围算法本轮保留：主图目前相对当前日期，快览目前相对最新报告期；由各适配器准备范围结果，共享显示结构。统一外观不隐含改变历史可见期数。
- 主图参考点、虚线、特殊分红详情和真实日期通过可选数据／详情配置输入同一绘图器；快览未提供则不生成，不伪造披露日或参考价。
- 模板由组件单一生成，主图通过受控ID映射保留chart、bar-metric、bar-metric-2、line-metric、comparison-range和历史表等现有ID；核查实际引用再迁移。不能把两份HTML仅换成相同类名当作完成共用。
- 组件所有查询和事件限定实例根节点，不能document.querySelectorAll('[data-period]')批量影响另一张图；主图和快览各自保存选择／周期／范围，快览关闭销毁自身监听及Plotly实例，不清空主图设置、不串股、不改主图数据。
- 主图持久设置key及旧visible/display兼容由主图适配器保留；快览沿用本次会话选择，不写入主图存储。处理异步挂载／脚本顺序，避免其他页面代码在控件创建前访问空节点。

### 实施步骤与门槛

1. 阅读本目录三文件及架构、图表规范；检查当前Git改动，重新核对上述调用链与DOM引用，尤其saveSelections、renderCurrentStock更新、其他图表和投资笔记集成。只提取企业经营趋势区域，不移动估值／筹码／融资等图表。
2. 在原8765和已建档样本上保存小规模基线：桌面默认主图、三槽位／同单位合轴、多单位及含负值组合、窄屏；记录相应DOM尺寸／关键计算样式、Plotly traces/layout与历史表内容及必要截图。关闭动画并等字体／Plotly稳定，使用固定视口、同一数据与选项；不为基线联网采集。
3. 先原样提取主图样式、模板与展示算法到共用组件，接入主图适配器，保留原ID、脚本时序和状态兼容。此时先做主图等价对照，任何主图格式／行为回归先修复，不进入快览迁移。
4. 快览通过数据适配接入同一组件，保持浮层与只读边界。其基础图表改用主图的配色、轴分组、横轴标签／间距、图例、工具栏、历史表和控件；浮层尺寸不同允许可用宽度响应变化，但不得用cp CSS再复制一套展示规则。共享控件负责重复点击隐藏，两个适配器仅接收状态变化。
5. 删除两处已替代的模板、重复样式、绘图／表格函数，检查没有以兼容名保留双份实现；更新资源缓存版本／顺序和静态映射。更改静态白名单后如确需重启，按规则核对原8765身份／活动任务后安全重启，保持后台运行。
6. 仅完成下列定向检查，更新本目录进度及实际前端架构说明；若仅重构展示，不改指标定义文档中的财务口径。临时截图／浏览器缓存／隔离库清理，保留验收报告与常用工具。未经用户另行要求不自动commit／push。

### 克制测试与完成标准

- 优先复用现有趋势图／快览的浏览器检查和本地验收工具；执行前按当前文件选择实际覆盖此路径的用例，记录理由，不重复运行旧快览全部后端计算测试或全量套件。
- 共用组件新增少量离线用例覆盖真正风险：同单位合轴且市值独立、混合正负零线／全部值不截断、隐藏／恢复与全部隐藏、两实例状态及销毁隔离。不得为每个样式属性编写镜像测试。
- 一次集中宿主机8765浏览器验收：主图迁移前后同样本／选择／视口关键样式与图表布局一致；季度／累计／年度／TTM、范围、历史表与工具栏行为保持；保存设置刷新后恢复。截图差异需区分抗锯齿等渲染噪声与实际尺寸／布局回归，不使用任意放宽阈值掩盖变化。
- 快览只选一家金融公司和一家含亏损的非金融公司，覆盖2／3槽位、同单位／多单位、零线、标签、形状重复点击及历史表；原弹窗导航／外点关闭／确认取消仍可用。选择同时含PE／PB／股息率的一组已有数据验证单位与独立日期保留，不扩大为财务重算审计。
- 同页保持主图打开再开／切／关快览：主图数据、所选指标、周期、范围、保存设置和图表实例不变；行业上下文保持，无重复监听或JS异常。窄屏取一个固定视口验证内部滚动和控件布局，不开展大规模截图矩阵。
