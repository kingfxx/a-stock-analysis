# 决策

## 2026-10-31

- 用户要求先分析本地数据可行性，随后确认移除不支持的指标及「估算现金分红」，本轮授权编写计划，不实施代码。
- 采用行业列表内大浮层快览，保留列表上下文，显式按钮进入完整个股页。
- 保留14个财务／市值指标；原TTM估算ROE由独立命名的「累计加权ROE」替换，并提供可选「季末未复权股价」。具体名单以 PLAN.md 为准。
- 七项从快览彻底移除：TTM估算ROE、简化ROIC、估算现金分红、简化有息负债、净现金／净负债、披露日估算市值、披露日前复权股价。移除仅作用于新快览，不修改完整个股页。
- 本地已有个股资料也不作为本版回退，保证同一快览指标来源与口径一致，不因建档与否改变算法。
- 市值采用季度交易快照；不能沿用披露日估算市值名称。行情可比财务多一期，保持独立真实覆盖。
- 净利率可用利润总额减所得税派生，但上线前须用本地非金融详细报表核验，不以归母利润替代。净资产优先直接值，缺失时同一期资产减负债，保留派生来源。
- 周期差分／TTM与时点规则遵守既有财务规范；累计加权ROE固定累计口径。金融企业按适用性隐藏指标，缺失不得按零处理。
- 只读API与完整个股加载链分离，不采集、不建档、不关注、不调用模型。进入完整页沿用已有行为，不把导航扩大成新增全量刷新授权。
- 默认单代理，不开展协作开发。无数据库结构变更需求，不新增表或迁移。
- 用户已授权实施，并要求克制测试额度；仅运行新增能力及受影响边界的必要检查，不跑无关全量回归。
- 用户随后要求先核对上次架构优化；暂停业务编码，已对照后端导航及2026-10-26拆分决策。明确两个具体后端模块、独立前端模块、无状态只读函数及既有静态白名单接入位置，细节见PLAN.md。
- 不直接从industry_service或statements引入函数到新纯计算模块，以免传递导入来源／存储依赖；初版无新增常驻状态，不改application／runtime生命周期，不调用行业服务工厂或数据库初始化。

- 用户再次授权按复核计划实施；已完成无状态只读方案。未扩展完整页指标或采集权限。
- 手机三轴图采用内部横向滚动以保留可读刻度，指标选择器独立覆盖原页全局flex规则；不改变全局样式。
- 样本派生计算存在1000元尾差时保留真实来源，不混填新浪值；来源范围及利润率收入差异在文档、返回数据和页面说明中明确。
- 验证限定为新增9项、相关边界6项、行业前端检查、一次集中浏览器验收及手机显示定向复核；未运行全量套件。

- UI反馈：复用主图metric-choice／metric-mode-group／period展示样式，快览自身使用独立data属性处理事件，避免绑定完整主图逻辑。
- 点击浮层外空白关闭，要求按下和点击都发生在外部，避免从图表拖动到外部时误关闭。
- 「完整个股展示」置于上一家／下一家之前，统一按钮外形、青色强调；按用户要求使用浏览器原生确认框，取消留在快览，确认才导航。使用button防止中键／修饰键绕过确认。

- 历史表反馈：快览直接展示主图同款横向历史表，跟随当前A／B／C指标、周期和范围；原逐期实际日期／收入依据表保留为独立折叠详情。同比／环比展示复用主图规则，基期非正不计算百分比，不改变后端财务周期及来源。

- 形状按钮支持重复点击当前选中项取消显示；两种形状均不选即隐藏该槽位，保留指标选择，任意形状重新点击恢复；图表与历史表按同一可见槽位集合渲染。

- 覆盖期数、缺值规则及所选指标来源／公式合并放入下方「来源与口径说明」折叠区，不再直接占用图表与历史表之间的空间；原动态更新保持。

- 零线反馈：多纵轴按主图已有算法统一正负空间比例，并各自按数据量级缩放；轴范围保留全部可见值及12%余量，不将负利润截断或改值。单轴使用tozero，切范围／显隐后重新计算。
