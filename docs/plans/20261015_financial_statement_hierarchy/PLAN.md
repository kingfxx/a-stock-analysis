# 财务三表科目层级折叠

## 目标

财务分析页的资产负债表、利润表、现金流量表中，关键明细和完整原始报表均按父子科目分组；分组默认展开，用户可折叠。保留来源科目与原有数值、比较、说明逻辑，缺失仍显示待补。

## 范围

- 调整 `web/financial-statements.js` 的关键明细与完整报表渲染。
- 调整 `web/financial-statements.css` 的层级、缩进及折叠控件样式。
- 更新 `docs/financial-analysis.md` 说明。
- 不修改采集、数据库、财务取值及缺失处理。

## 验收标准

- 三张报表关键明细和完整科目均有可折叠父子分组，页面首次渲染为展开。
- 不删除来源科目，不改数值算法；缺失仍显示待补。
- 未归入已知子类的科目仍可见，避免静默丢行。
