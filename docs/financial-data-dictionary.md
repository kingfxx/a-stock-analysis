# 财务四表数据字典

生成日期／统计截止日：2026-10-02。依据本地 SQLite 已保存的新浪接口原始记录生成。

本次覆盖 15 只股票、4752 条报告期记录、548 个科目描述键。此字典列出本地已观察字段，不代表新浪接口全部股票的完整字段规范，也不代表所有字段已接入页面或 AI。

## 1. 快速使用

1. 新增财务指标优先检查 `gjzb`；对应股票、报告期无有效同口径值时，再从 `lrb`、`fzb`、`llb` 提取或计算。
2. 以 `report_type + item_source + item_field` 定位，结合标题、分组和报表范围核对。同名字段可能属于不同业务；相同字段码也可能跨表使用。
3. 保留原始值与来源；有效零值不丢弃，null、空字符串、--、非有限或不可解析值不默认转成零。
4. 利润和现金流金额通常是年内累计，余额科目是期末时点；ROE、ROIC、利润率等比例不能直接做季度差分或相加。
5. 金额单位、合并/归母范围和报告期长度必须确认。格式码仅描述显示格式，不能替代单位与计算定义。

## 2. SQLite 存储结构

数据库：`data/stock_analysis.sqlite3`；统一表：`financial_reports`；来源：`sina:CompanyFinanceService.getFinanceReport2022`。

|字段|含义|
|---|---|
|instrument_id|关联 instruments.id，再由 instruments.code 定位股票|
|source|来源标识；legacy/merged 记录不纳入此字典|
|report_type|gjzb 关键指标；lrb 利润表；fzb 资产负债表；llb 现金流量表|
|period|报告期末，YYYY-MM-DD|
|publish_date|入库来源披露日期；历史来源日期可能需要程序校正|
|update_time|来源更新时间，数据库为文本；不默认解释为 Unix 时间|
|raw_json|单个报告期完整来源记录，TEXT，读取后解析 JSON|
|content_hash|原始内容哈希|
|obtained_at|本次取得时间，不等于报告披露日|
|run_id|关联 sync_runs，追溯抓取与同步状态|

主键：`(instrument_id, source, report_type, period)`。同源同一期更新覆盖当前记录，不提供完整修订版本历史。

```sql
SELECT f.period, f.raw_json
FROM financial_reports AS f
JOIN instruments AS i ON i.id = f.instrument_id
WHERE i.code = :code AND f.source = :source AND f.report_type = :report_type
ORDER BY f.period;
```

## 4. 期间、单位和特殊字段

- 利润表及现金流量表的金额：第一季度为一季度累计，中报为半年累计，三季报为九个月累计，年报为全年；拆单季仅适用于同口径累计金额，TTM 需连续四季或同口径年报桥接。
- 资产负债表：余额对应期末，不能加总成年度或 TTM；回报率分母使用相应窗口平均余额。
- EPS、ROE、ROIC 等派生值：按具体定义解释。年内累计比率不能直接相减得到单季，来源 ROIC 的年化规则尚未核实。
- gjzb 的 PARENETP 是归母利润；NPCUT 是来源扣非利润。归母利润减扣非利润不等于税前合并非经营调整。
- gjzb 的 RIGHAGGR 是合并股东权益合计，不应直接当作归母净资产与归母利润配对。
- ROEWEIGHTED 为来源加权 ROE；ROEAVG、ROEDILUTED、ROEAVGCUT、ROEDILUTEDCUT 是其他定义，不能混用。当前 TTM ROE 仍为三表金额估算。
- ROIC 为来源回报率；EBITPS、EBITMARGIN 是每股值或比率；ROANOPATCONMS 是资产回报率，不是 NOPAT 金额。
- INCOTAXTOTP 的有效税率按百分数值理解，例如 13.957193 表示 13.957193%；计算税率小数需除以 100。其他比例逐项核对：OPNCFTONP 等 f4 比值不能统一除以 100。
- 单位：CNY 金额科目通常为元；每股金额通常元/股；百分数通常百分点值；周转率通常次、周转天数通常天。具体字段结合中文名称和来源说明核对，不能只看 f2 或 p2。
- 原始股本科目属于权益科目金额；现有程序将其用作股数，遇不同面值或特殊股份结构应另核对。
- 财务费用项下 INTEINCOOPCOST 与金融业务利息收入不同；利息费用的负号由现有源层专门归一，不对所有负值取绝对值。
- 减值损失旧/新字段码、合同负债/预收款等存在会计口径变化，不能仅按标题把全部历史序列合并。

## 7. 维护与再生成

抓取新增股票或来源新增科目后，用同一工具重新生成本文件和 CSV；请复核接口字段变化及已有指标映射，再提交文档。工具只读数据库，不访问来源接口，不初始化或迁移数据库。

```powershell
python data/verification/tools/generate_financial_dictionary.py --db data/stock_analysis.sqlite3 --docs docs --as-of 2026-10-02
```

参考：[SQLite 存储说明](sqlite-storage.md)、[架构说明](architecture-design.md)、[项目记忆](../AGENTS.md)。

CSV 提供额外的最新空值/未出现数、有效零数、来源分组和层级，适合程序筛选。其每列含义：前缀 all 表示历史全部记录，latest 表示逐股最新记录；present 为科目键出现，numeric 为可解析有限数值，absent 为科目键未出现，null/empty/invalid 分别为 null、空/--、无效数值。

## 公司报告资料索引（2026-10-02 新增）
