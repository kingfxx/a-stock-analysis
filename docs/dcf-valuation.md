# DCF 参考试算

入口为个股「企业经营趋势」下方「估值与分位」中，股息率旁的 **DCF 估值**。展开后读取一次本地数据，参数修改在浏览器中计算，不重新请求财报、采集来源或调用模型。

## 口径

本版使用已有的 **经营活动现金流量净额 − 购建固定资产、无形资产和其他长期资产支付的现金**。这是简化FCF，不是严格FCFF或FCFE。模块展示简化现金流总折现值、总折现值除以总股本的每股参考换算，以及相对股价的参考差额，不能直接当作归母合理市值、合理股价或投资安全边际。

严格FCFF需核实付息现金流归类、税盾、经营/非经营现金流和租赁处理，随后还需有息债务、真正超额现金、非经营资产、少数股东权益及其他优先索取权。现有资料不能可靠完成这些桥接，因此专业FCFF显示不可用及缺项，不自动把货币资金全额加回，不将缺少的负债默认为0，也不输出EV到股权的伪精确调整。

金融企业不适用此模型。周期企业、重大资本支出或现金流转负企业需要人工核对跨周期代表性；标准和三阶段模型在各期增长率大于-100%的条件下，均不能使负基准自动变为正现金流。

## 参数与公式

初始假设遵照需求：最近3完整年度FCF平均、显性增长3%、折现率9%、永续增长2%。1/3/5年窗口只接受连续年末报告，缺年或缺字段不跳过补齐，不能用半年累计或TTM代替。手动基准单位为亿元，计算内部使用元。

年末折现、显性期10年：

```
FCF(t) = 基准FCF × (1 + 显性增长率)^t
PV(t) = FCF(t) / (1 + 折现率)^t
TV(10) = FCF(10) × (1 + 永续增长率) / (折现率 − 永续增长率)
PV(TV) = TV(10) / (1 + 折现率)^10
总折现值 = Σ PV(t), t=1..10 + PV(TV)
每股参考折现值 = 总折现值 / 总股本
相对股价参考差额 = (1 − 未复权价格 / 每股参考折现值) × 100%
```

折现率必须大于永续增长率。缺失、非有限值及溢出拒绝计算，零/负FCF保留真实值并提示；非正参考值不展示价格差额。敏感性矩阵无效组合留空。三情景属于参数假设，不代表概率预测；终值占比高提示结果依赖远期假设。

## 三阶段成长模式

估值模式可切换「标准DCF」与「三阶段成长DCF」。默认仍为标准模式。成长模式使用相同的年度FCF基准、股本和未复权价，阶段年份固定：

| 阶段 | 预测年 | 示例年增长率 |
|---|---|---|
| 高增长期 | 1—3 | 15% |
| 增速放缓期 | 4—7 | 8% |
| 成熟过渡期 | 8—10 | 4% |
| 永续期 | 11年起 | 2% |

这些值是可覆盖的示例，不是特定公司的预测。三个显性期增长率各自可编辑，历史恒定增长推荐不自动替代三个阶段。切换模式保留已输入的增长假设；基准、折现率、永续增长率共用，参数变化仍完全在浏览器计算。

```
FCF(0) = 基准FCF
FCF(t) = FCF(t-1) × (1 + 当年所属阶段增长率)，t=1..10
FCF(1) = 基准FCF × (1 + 第一阶段增长率)
FCF(4) = FCF(3) × (1 + 第二阶段增长率)
FCF(8) = FCF(7) × (1 + 第三阶段增长率)
TV(10) = FCF(10) × (1 + 永续增长率) / (折现率 − 永续增长率)
```

标准预测仍按原幂次公式生成，成长预测按逐年复利生成。两者的10年金额数组进入同一个年末折现引擎；专业股权桥接的缺口和简化FCF标签不因选择成长模式而改变。表格列出每年阶段及实际增长率，预测图标识三个阶段；显性价值、终值、每股参考值、三情景和敏感性沿用现有组件。成长情景对三个增长率同时作±2个百分点变化，折现率及永续率的变化规则不变；敏感性仅改折现率和永续率，保持全部阶段增长假设不变。

增长率与永续增长率必须大于-100%。标准模式保留原有正折现率限制；成长模式允许大于-100%的零/负折现率假设，但仍须高于永续增长率，并提示这属于非常规假设。高于30%的增长、后阶段增速高于前阶段、永续增长高于第三阶段及终值现值占比超过75%会提示风险，不会静默裁剪用户输入。缺失年份、非正FCF、金额/股本单位及溢出规则与标准模式一致。

## 参数依据

增长建议参考最近最多10年营业收入、归母净利润、FCF的相邻可比年度增长中位数、负值和波动；不会直接使用异常端点CAGR。历史不足时明确降为默认假设。初始值与推荐值分开展示，用户可主动应用或覆盖。

成熟度与长期宏观边界无法单凭三表确定，永续增长0%—2%仅为初步假设区间，2%不是已核实的企业长期增长能力。

WACC面板在用户主动点击「自动估算」后读取参数；不会在普通页面读取时请求国债收益率或触发行情补采。Rf通过AkShare 1.18.30 的 `bond_gb_zh_sina(symbol="中国10年期国债")` 查询新浪财经10年期国债日度收益率，使用 `close`（百分比）中日期不晚于估值基准日的最近记录。成功结果仅在进程内按估值日缓存，不写入数据库；网络、响应结构或数据校验失败时留空，不回退固定利率。超过7天的最新可用值提示可能过期。

Beta复用本地个股前复权日线和本地沪深300指数日线（`index_price_observations`），按ISO自然周取每周最后一个实际交易日，再按共同周标签计算周收益率OLS协方差／方差。可选择2、3、5年；样本门槛分别为至少80、120、200组周收益率。界面展示共同样本数、日期区间和数据来源。缺少任一历史序列或样本不足时不可用，不自动补采，也不把负Beta改为1。

ERP默认6%，提供5%、6%、7%情景；这些都是模型假设，不是实时观测。Kd用最近完整年度合并利润表利息费用除以相邻两年末已披露有息债务分项合计的平均值；若分项缺失，显示基于已披露项目的部分估算和缺项提示，不把缺项当零，也不把财务费用当利息费用。债务权重使用估值日以前最新合并资产负债表已披露债务分项合计，以及相同交易日 `market_trade_snapshot.total_market_cap`；缺少债务分项时显示部分估算及警告，账面债务近似债务市值。估值基准日自动使用今天；税率使用最近完整年度合并利润表所得税费用／利润总额计算的历史有效税率，并自动填入WACC计算，可手动调整。利润总额非正、字段缺失或税率超出0%至100%时不自动填入。应用WACC时无需填写人工来源说明或日期；仍由用户点击“应用WACC到折现率”确认变更当前DCF折现率。当前没有可核验的A+H统一股数/币种资料，A+H总市值需人工核对。

每项参数显示状态、来源、日期及方法；状态包括实测、估算、假设、人工覆盖和不可用。从折现率参考卡片或WACC面板点击自动估算，都会将本次结果保留在六项输入框中；用户编辑自动值后显示人工覆盖，「恢复自动估算值」还原本次自动结果。计算结果实时展示Ke、税后Kd、两类权重及加权贡献，并显示Beta×ERP敏感性矩阵。应用时无需填写确认依据和日期；仍需单独点击「应用WACC到折现率」，不会自动覆盖既有折现率。

既有默认折现率9%仍是可编辑模型假设，不是自动WACC。CAPM及WACC公式：

```
Ke = 无风险利率 + Beta × 股权风险溢价
WACC = Ke × (1 − 债务权重) + 债务成本 × (1 − 税率) × 债务权重
```

DebtWeight=D/(D+E)，D为有息债务、E为股权总市值；无任何有效债务分项或该季度市值时参数留空。部分债务项目可用时，使用已披露分项合计但明确标记为部分估算，不把缺项填零、不算成完整债务。债务权重以与所用财报报告期同季度的最后交易日A股市值和债务账面值近似，A+H结构及租赁/一年内到期项需核对。自动或人工WACC都不改变简化现金流口径；经营现金流减资本开支不一定等于严格FCFF，不能因此将结果称为专业FCFF估值。

## 来源与追溯

年度数据复用 `FundamentalService.read` 与 `core.build_period_rows`/`view_rows('year')`，读取已有 `financial_reports` 新浪三表、遗留合并记录及人工覆盖。金额元，股数股，价格元/股；UI总额显示亿元。

总股本读取本地 `market_trade_snapshot.total_shares`。缺少已核实股数时不把财报「实收资本」面值金额直接当股数，每股参考值留空。价格比较 `PriceService.read(...,'raw',lease=False)` 未复权收盘价与已有交易快照的有效日期，使用较新值。两者分别展示实际日期及来源，过时或日期不一致提示局限，不能把历史价称作实时行情。财报币种与合并口径证据不足时，不自动使用遗留合并记录生成估值基准。

DCF事实读取接口为 `/api/dcf?code=股票代码`；WACC估算使用 `/api/dcf/wacc?code=股票代码&years=5`，仅由用户点击自动估算触发，读取本地行情/财报并按需查询AkShare国债收益率。Beta不补采历史行情。不新增数据表、不迁移旧资料，现有备份规则不变。开发方案及验收记录见 [自动WACC开发计划](../plan/2026-10-15_auto_wacc/plan.md) 和 [开发进度](../plan/2026-10-15_auto_wacc/progress.md)。
