# 财务分析页面

第一个 tab「企业经营趋势」的对照指标（含主营现金流、季末市值）、估值和筹码口径统一见[企业经营趋势指标说明](enterprise-trend-metrics.md)。本文说明第二个 tab「财务分析」。

页面一级标签为“企业经营趋势”和“财务分析”，当前标签在浏览器标签页内保留，换股票继续沿用。财务分析包含资产负债表、利润表、现金流量表，点击后读取本地已保存财报，不调用模型、不请求外部财务数据、不写业务事实。

桌面页面左侧为 180px 吸顶信息栏，始终显示当前股票名称、代码及现有“我的股票”分组入口，股票切换或名称补齐同步更新。窄屏（800px 及以下）改为顶部吸顶简条；侧栏独立占位，股票列表展开为浮层，过长列表内部滚动，保留搜索与分组管理功能。

## 展示与操作

- 利润表毛利率卡片右侧并排展示归母净利率＝归母净利润÷营业收入×100%，分子分母均使用所选同一累计／单季度期间，各期独立计算；营业收入非正或任一输入缺失时待补，保留归母净利润负值和有效零值。来源展开列出公式、实际字段及输入金额，不使用合并净利率代替。

- 利润瀑布下方新增“期间费用占毛利润”分组柱形图，对照销售、管理、研发、财务费用及期间费用合计。各期费用除以对应期间毛利润（营业收入减营业成本），比较期遵循流量报表的期间窗口；优先采用适用的 gjzb 字段，缺值回退利润表。财务费用保留负号，负值提示净收益，合计也保留正负号；缺少任一费用则合计待补。毛利润非正或缺失时不计算占比，本期不适用时改为金额图；金融企业不展示该图。原费用占收入图保留。

- 报告期选择及上一期／下一期使用本地三表报告期并集；某张表缺期时显示待补，不借用旧期。
- 余额按期末展示。利润与现金流可切换本年累计／单季度；一季度直接使用本期累计，其他季度必须有同年上季有效值。
- 金额单位为元、万元、亿元；每股科目保留元/股，不按金额缩放，非一季度不对累计 EPS 差分。
- 比较对象可选上年末、上年同期、上一报告期。上年末仅应用于资产负债表，利润与现金流改用上年同期；累计比较上一报告期时明确提示期间长度不同，不作为单季环比。
- 资产负债表包括资产与负债分项柱状图、金额／占本侧合计比例切换、资产与负债＋权益结构条；资产分项除以总资产，负债分项除以总负债，权益分项除以股东权益。资产总额卡片内并排展示净资产（复用合并股东权益合计，包含少数股东权益），显示本期、对应比较期和来源；资产负债率卡片内增加有息负债率，负债总额卡片内增加有息债务，两组指标在各自卡片内左右并排，所有概要卡片数值统一为 20px、标题统一为 13px；配对指标保持单行，第一列按内容宽度排布，列间距与分隔线右侧留白均为 6px，概要卡片金额单位省略末尾“元”（亿／万），窄屏配对卡片占整行并保持左右排列；均显示本期、比较期及可展开来源；银行、证券、保险等金融企业采用金融科目及总额结构。
- 图表悬浮提示只展示科目、金额和明确分母的占比，来源保留在可展开的卡片与明细中。利润瀑布图占比以营业总收入（金融企业以营业收入）为分母，现金流图以期初现金及等价物为分母；结构条的资金来源占比以负债与权益合计为分母。
- 利润表瀑布按营业总收入、营业总成本、其他营业损益净额、营业利润、营业外收支等净额、利润总额、所得税和合并净利润展开，另以图表比较成本费用占收入比例。归母与少数股东损益保留在明细。金融企业用营业收入到营业利润的净损益桥接及金融收入费用明细，不套工业企业毛利率。
- 现金流瀑布从期初现金及等价物经三类活动和汇率影响到期末余额，同时展示各类活动流入流出小计。单季期初取上季期末，期末不做差分。
- 每页保留关键明细、完整去重来源科目、比较期数值、变动额、来源字段码及公式；资产明细占比以总资产为分母，利润明细以营业收入为分母，现金流不统一计算占比。
- 关联观察对照上年同期的收入、应收账款、存货、合并净利润与经营现金流；仅展示事实，不生成投资结论，也不把经营占款余额变化作为精确现金流调节。

## 来源与缺失

所有概要卡片、关键明细和完整报表的“说明”统一按“指标意义 → 计算方法／来源 → 口径说明”展示。双指标卡片仅保留一个展开入口，内部按指标分别说明。意义使用易懂说明；未维护专门定义的原始科目使用资产／负债／权益分类说明或明确提示参阅附注，不推断未知明细。计算方法仅列公式或直接取数说明，不重复来源。口径先列本期、比较期报告期和实际值，再集中列一次本期实际来源（相同来源的字段合并），比较期仅显示结果；计算指标仅列本期分项、嵌套计算输入和可适用的代入公式。金额按所选单位显示，不附原始元值，单位切换同步显示；缺项保留待补并说明未计入情况。直接披露的比例保留原来源，并附参与核对的金额；单季度明细保留本期累计与上季累计的实际金额。

`GET /api/statements?code=600519&period=2026-06-30&mode=ytd&comparison=year_end` 读取 `financial_reports` 中的新浪 `gjzb/fzb/lrb/llb` 原始 JSON。接口使用 SQLite 只读事务，不启动迁移、同步或模型任务。三表子页切换、单位和资产占比切换复用同一份响应；报告期与期间口径切换重新读取本地资料。上方刷新完成后，已打开的财务分析重新读取。

新指标按股票、报告期逐项优先使用 `gjzb` 中同字段码、同底层来源且适用的数值；无有效值时回退三表。拆单季分别选择本期与上季来源，再做差分，保留两期来源。只接受当前已核对的人民币、合并期末范围；其他范围不擅自套用。零为有效值，null、空字符串、无效值不当零。

`gjzb.BIZTOTCOST` 虽在本地标题为“营业成本”，实际与利润表“营业总成本”对应，不能用来代替 `lrb.BIZCOST` 计算毛利率。来源毛利率、合并净利率、资产负债率仅在定义适用且与三表核算一致（误差小于 0.02 个百分点）时使用；单季度利润率自行计算。

有息债务按六项中的有效值求和：短期借款、应付短期债券、一年内到期非流动负债、长期借款、应付债券、租赁负债。各分项及比率分母资产总额优先取同口径 fzb，缺值回退 gjzb（此指标按用户指定优先资产负债表）；有息负债率＝有息债务÷资产总额×100%，分母非正或缺失时待补。余额按各期分别计算，上年末比较不混用上年同期。来源展开显示公式、分项金额、字段码和嵌套来源；缺项在来源列出，未计入合计且不代表为零；仅当全部分项缺失时合计待补。租赁负债使用非流动部分，一年内到期项目可能含无息项目，其他流动负债和长期应付款中的有息部分未纳入。此页面保留空白科目原值，按有效分项计算，不把缺项伪装成有效零值。货币资金不等于可用现金，也不等于现金及现金等价物。

现金流第三项名称为“Capex（资本支出）”，来源注明现金流量表 ACQUASSETCASH（购建固定资产、无形资产和其他长期资产支付的现金）；第四项名称为“自由现金流”，公式为 MANANETR（经营活动产生的现金流量净额）－ACQUASSETCASH，两项来源及金额均可展开查看。保持原算法，不等同于严格 FCFF/FCFE；金融企业不展示此工业企业指标。扣非归母利润保留来源口径，不根据投资收益等自行计算。利润图的“其他营业损益”是报告总额桥接，不代表非经常性损益；净利润与利润总额减所得税若还有差额，单列“其他净利润调整”。

资产与负债＋权益、现金期初加净变动与期末余额进行勾稽，超出舍入容差时显示差额。瀑布必要输入缺失时显示待补并保留明细，不以零补成完整瀑布。
