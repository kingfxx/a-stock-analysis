# 企业经营趋势：指标计算与来源

本页现有指标可通过「插入笔记」保存为固定 Markdown 文字或表格，仍使用本说明的计算与缺值口径，不新增指标或改写原财务数据。数据选择只读本地资料，不触发来源采集；选择器显示数据日期和必要口径，新插入不添加脚注或批注。具体操作、历史分位采样说明与限制见[投资笔记说明](investment-notes.md)。

笔记的估值数据选择器支持「数据日期」，默认最近一个有有效本地估值／日行情的日期；只取所选日的 PE、PB、股息率及未复权收盘价，缺项留空，不沿用其他日期。近 3／5／10 年分位以该日为截止点复用 `valuation_summary_observations`／`valuation_summary`，排除后续样本；股息率按对应日期前 365 天已实施分红及当日原始收盘价计算，有日行情时用日样本，无日行情时保留月度真实观察。计算基于当前保存版本，不是历史留存快照；估值图当前卡片及采集行为不受该笔记日期选择影响。

本文说明第一个 tab「企业经营趋势」的财务对照图、估值图和筹码图，按当前代码实现整理。第二个 tab 的三表分析另见[财务分析说明](financial-analysis.md)。原始科目码、标题别名和历史覆盖见[财务四表数据字典](financial-data-dictionary.md)，数据库结构见[SQLite 存储说明](sqlite-storage.md)。

## 1. 数据从哪里读取

正常业务读取本地 `data/stock_analysis.sqlite3`，公式结果在读取时生成，不分别保存单季度、当年累计、年度、TTM 四套结果。

| SQLite 表 | 来源与用途 | 主要字段 |
|---|---|---|
| `instruments` | 股票身份关联 | `code`、`id`；各事实表通过 `instrument_id` 关联 |
| `financial_reports` | 新浪 `CompanyFinanceService.getFinanceReport2022` 财务原始记录 | `source`、`report_type`、`period`、`publish_date`、`raw_json`；`lrb` 利润表、`fzb` 资产负债表、`llb` 现金流量表 |
| `report_overrides` | 按股票、报告期的手工或旧缓存覆盖 | `field_name`、`value_json`；读取财报后应用，显式零和 null 均保留 |
| `report_disclosure_dates` | 巨潮公告结构化元数据规则判断 | 当前结果及历史结果；首披露日、已知修订日、状态和候选依据，不保存公告正文或 PDF |
| `raw_daily_prices` | 腾讯未复权日线，用于市值和股息率 | `source='tencent'`、`trade_date`、`close` |
| `adjusted_daily_prices` | 腾讯前复权价格，按完整版本保存 | `version_id`、`trade_date`、`close`；版本与股票由 `price_versions` 关联 |
| `dividend_events` | 东方财富 `RPT_SHAREBONUS_DET` 分红事件 | `report_period`、`ex_dividend_date`、`status`、`cash_per_ten`、`raw_json` |
| `valuation_observations` | 百度股市通的 PE、PB、总市值真实观察 | `metric`、`observed_on`、`value`；来源 `baidu:opendata` |
| `industry_snapshots` | 东方财富当前同业估值快照 | `snapshot_at`、`raw_json` 中的 `PE_TTM`、`PB_MRQ`、`PS_TTM` |
| `shareholder_observations` | 东方财富股东户数 | 统计截止日、公告日、`holders`、来源及 `holder_scope` |
| `financing_daily` | 东方财富融资融券日度事实 | `trade_date`、`margin_balance`、`total_balance`、`net_buy` |

**首图当前取数路径与三表分析页有区别。** 首图用 `sources.py` 按科目标题及兼容别名解析新浪三表，`gjzb` 虽已存储，目前没有统一替代首图的原始金额或 ROE／ROIC 估算。数据字典中的科目码用于核对，并不表示首图所有字段都按科目码匹配。不要将第二个 tab 的 `gjzb` 优先规则理解为首图已经采用的逻辑。

财务读取先使用新浪三表，再由同表中 `source='legacy'、report_type='merged'` 的历史导入记录补充缺失项，最后应用 `report_overrides`。旧导入记录可能提供部分股本、金额或扩展字段；原 `data/fundamentals/` 等 JSON 不是正常业务的直接读取入口。

## 2. 周期、单位与缺值的通用规则

| 口径 | 当前实现 |
|---|---|
| 单季度流量 | Q1 直接取年内累计；Q2／Q3／Q4 用本期累计减同年上季累计，任一必要输入缺失则留空 |
| 当年累计流量 | 直接取本报告期财报原始年内累计：Q1、Q1+Q2、Q1+Q2+Q3、全年；不依赖前季数据，不对缺期补值 |
| 年度流量 | 只保留 12 月 31 日年报，取全年累计 |
| TTM 流量 | 连续四个单季度之和；缺季度或其中任一数值缺失则留空，不用单季乘四 |
| 时点指标 | 有息负债、净现金、市值、价格保留对应报告期时点值；年度取年末报告行，TTM 不加总 |
| 金额 | 内部按元计算，图表除以 `1e8` 显示亿元；股价为元／股，比例为百分数 |
| 日期 | 首图横轴是报告期；同时显示多个财报指标时，报告期和最终采用披露日及来源状态放在财务指标组末尾共同显示一次。披露日前复权股价和披露日估算市值的交易日期放在价格指标组末尾合并显示；两种价格日期相同时只显示一个日期，不同时分别标注不复权／前复权。季末市值列实际季末日期 |
| 缺值 | 普通金额保留有效零；null、空字符串、无效值不当零；特殊例外见分红和债务说明 |

ROE、ROIC、毛利率和净利率分别按自己的公式计算，不对原始比例做差分或相加。历史财报可能含后续修订，首图属于事后对照，不构成严格的历史实时回测。

## 3. A／B／C 可选的 20 个指标

> 本节20项为完整个股页指标；行业公司快览使用独立的全市场数据口径，见本文末「行业公司轻量快览」，不能混用来源及名称。

“流量转换”指上一节的单季差分、当年累计原值、年度累计、连续四季合计。以下公式中的比例均乘以 100%。

| 指标（接口键） | 含义与计算 | 实际来源 | 周期与限制 |
|---|---|---|---|
| 营业收入 `revenue` | 企业确认的营业收入 | `financial_reports/lrb`：“营业收入”，缺少适用值时取兼容标题“营业总收入”；常见码 `BIZINCO` | 流量转换；不是现金收入 |
| 归母净利润 `profit` | 归属于母公司股东的净利润 | `lrb`：“归属于母公司所有者的净利润”等兼容标题；`PARENETP` | 流量转换；保留亏损，区别于合并净利润 |
| 归母扣非净利润 `adjusted_profit` | 归属于母公司股东的扣除非经常性损益后净利润 | 优先 `financial_reports/gjzb` 的 `NPCUT`；缺少有效值时读取 `lrb` 中明确标为归母扣非净利润的兼容标题 | 流量转换；来源字段缺失时留空，不从归母净利润估算 |
| 净资产（所有者权益合计） `net_assets` | 合并所有者权益（股东权益）合计 | `fzb`：“所有者权益（或股东权益）合计”等兼容标题 | 报告期末时点金额；单季度、当年累计、年度和 TTM 均显示相应报告期末值，不加总；金额单位亿元 |
| 营收同比增长率 `revenue_growth` | （本期营收÷上年同期营收－1）×100% | 由 `revenue` 计算 | 比较相同单季／当年累计／年度／TTM；上年值非正或任一期缺失则留空 |
| 归母净利润同比增长率 `profit_growth` | （本期归母利润÷上年同期归母利润－1）×100% | 由 `profit` 计算 | 同上；负基数不计算百分比，与悬浮提示的盈亏文字规则不同 |
| ROE（TTM 估算） `roe` | TTM 归母利润÷本期与上年同期归母净资产均值×100% | `lrb` 归母利润；`fzb`“归属于母公司股东权益合计”等别名，`PARESHARRIGH` | 四种视图均使用 TTM 公式；年度展示年末 TTM。两端净资产必须都为正；不是官方加权平均 ROE |
| ROIC（简化估算） `roic` | 税后经营利润估算÷期初期末投入资本均值×100% | 新浪 `lrb/fzb` 分项，自行计算 | 年度用全年利润；单季、当年累计和 TTM 均用 TTM 利润；详细输入及限制见下节 |
| 经营活动现金流净额 `operating_cash_flow` | 经营现金流入扣除经营现金流出后的净额 | `llb`“经营活动产生的现金流量净额”，`MANANETR` | 流量转换；可为负 |
| 主营现金流 `main_business_cash_flow` | 销售商品、提供劳务收到的现金流入金额 | `llb` 同名科目，`LABORGETCASH` | 流量转换；名称沿用页面，它是现金流入，不是经营现金流净额 |
| 简化自由现金流 `free_cash_flow` | 经营活动现金流净额－CapEx | `llb` 两项现金流，自行计算 | 两项按同一周期转换；不是精确可分配现金，也不是完整 FCFF／FCFE |
| 估算现金分红（已实施） `cash_dividend` | 每笔税前每股派息×分红来源总股本，再汇总 | `dividend_events`；`PRETAX_BONUS_RMB/10` 与 `raw_json.TOTAL_SHARES` | 按归属报告期放置，非实际到账日；详细规则见下节 |
| 毛利率 `gross_margin` | （营业收入－营业成本）÷营业收入×100% | `lrb` 收入及“营业成本”，`BIZCOST` | 按所选周期金额重算；收入非正或必要字段缺失则留空。不用“营业总成本”替代营业成本 |
| 净利率 `net_margin` | 合并净利润÷营业收入×100% | `lrb`“净利润”，`NETPROFIT`，及收入 | 按所选周期重算；收入非正或输入缺失则留空；不是归母净利率 |
| 资本开支 CapEx `capex` | 购建固定资产、无形资产和其他长期资产支付的现金 | `llb` 同名及兼容标题，`ACQUASSETCASH` | 流量转换；不额外扣处置资产收回款，不含所有可能的资本投入 |
| 有息负债（简化） `interest_bearing_debt` | 六项债务余额之和 | `fzb` 六项科目，见下节 | 时点值，不加总；字段完整性和空值有特殊规则 |
| 净现金／净负债 `net_cash` | 报告期末货币资金－简化有息负债 | `fzb`“货币资金”及六项债务 | 时点值；正数为净现金，负数为净负债；不等同于精确可用现金／净债务 |
| 季末市值 `period_end_market_cap` | 季末当日或此前最近交易日不复权收盘价×同期末股本 | `raw_daily_prices.close`；`financial_reports/fzb`“实收资本（或股本）／股本”，常见码 `PAIDINCAPI` | 时点值；价格距季末超过 15 个自然日或股本缺失则留空；保留 `period_end_price_date` |
| 披露日估算市值 `market_cap` | 披露日当日或此前最近交易日不复权收盘价×该报告期末股本 | 同上，按 `publish_date` 匹配价格 | 价格距披露日超过 15 天则正式值留空；股本不是披露日实时股本；保留 `price_date` |
| 披露日前复权股价 `qfq_price` | 披露日当日或此前最近交易日的前复权收盘价 | `adjusted_daily_prices.close`，同一完整价格版本 | 距披露日最多 15 天；保留 `qfq_price_date`；历史负价保留，仅作走势，不用于市值 |

### 3.1 ROIC 的完整公式

```text
税率 = 所得税费用 / 利润总额
NOPAT = (利润总额 + 费用化利息 - 非经营性利息收入 - 非经营调整) × (1 - 税率)
投入资本 = 合并所有者权益 + 简化有息负债 - 现金扣除额
ROIC = NOPAT / ((期初投入资本 + 期末投入资本) / 2) × 100%
```

利润总额、所得税费用、费用化利息、财务费用项下利息收入来自 `lrb`；合并所有者权益（含少数股东权益）、货币资金和六项债务来自 `fzb`。利息收入优先识别 `INTEINCOOPCOST`，再识别财务费用分组内的“利息收入”；不使用金融业务经营利息收入，也不以财务费用净额或经营利息支出代替费用化利息。新浪负号展示的“利息费用”在来源层转为正费用金额，仅处理这一科目。

年度资本两端为上年末、本年末；TTM 资本两端为上年同期末、本期末。单季度与当年累计视图也使用 TTM 窗口，不计算单季 ROIC 或将单季年化。所用金额必须同币种、同单位、同合并范围。

默认现金扣除额为全部货币资金，非经营调整为零，尚未系统剔除投资收益、资产处置收益等。保留两项扩展：`excess_cash` 替换现金扣除额，需分别提供两端值；`non_operating_adjustments_ytd` 先拆季／合计成对应利润窗口，正数扣收益、负数加回损失，不重复计入已扣的利息收入。键缺省采用默认方法，显式零有效，显式 null 表示未知。

利润总额必须为正，所得税费用须在 0 与利润总额之间；费用化利息、非经营性利息收入、债务与现金扣除额不可为负，平均投入资本必须为正。必要输入缺失或非有限数值时留空，不套用默认 25% 税率。非金融企业的简化公式不能直接当作金融企业经营回报指标。

### 3.2 有息负债与净现金

六项为：短期借款、应付短期债券、一年内到期的非流动负债、长期借款、应付债券、租赁负债。首图当前要求六个字段都存在；**已有科目但解析值为空时按零相加，缺少科目时整项留空**。这是首图现有兼容行为，不代表来源明确披露了零，也不同于第二个 tab 按有效分项求和的规则。

净现金还需要有效货币资金。有息债务范围并不完整，部分一年内到期项目可能无息；货币资金可能含受限款项，因此结果为简化口径。

### 3.3 分红、分红率与同比

只取状态为已实施、除权日不晚于今天且有正现金派息的事件。`PRETAX_BONUS_RMB` 为每十股金额，存为 `cash_per_ten`，每股金额需除以 10；总股本从事件原始 JSON 读取，不用当前财报股本代替。

单季按 `report_period` 汇总，当年累计合计同年截至本报告期所属事件，年度合计该年所属事件，TTM 合计连续四个报告季度。2025 年年报派息即使在 2026 年实施，首图仍归入 2025 年，悬浮提示显示实际除权日。若当前已提供事件集但某期没有匹配事件，金额为零；事件集尚未就绪时留空；已匹配事件缺股本则对应金额留空。零仅表示当前缓存无该期已实施事件，不能判断最终分红。

回购股不参与分红、股本变动及 A/H 股不同实施方式等，会使估算额与公告实付额有差异。历史导入事件在新来源未覆盖的报告期可补充使用。

仅年度悬浮提示展示分红率：年度已实施估算现金分红÷全年归母净利润×100%。缺输入或利润非正时不可计算；有效零显示 0%，超过 100% 保留原比例。后续实施事件会改变历史归属年度金额，不代表最终派息率。

当年累计口径下，财务相关指标的悬浮提示和历史表仅显示同比，与去年相同报告期累计比较（Q1 对去年 Q1，Q2 对去年 Q1+Q2，依此类推），不显示环比；股价和市值仍按原有时点取值，保留同比与环比（环比比较前一季度）。其他口径的悬浮提示和历史表显示同比、环比，变化百分比保留一位小数。季度和 TTM 的同比比较去年同报告期，环比比较前一季度；年度的同比和环比均比较上一年度（年度数据没有季度环比）。净资产、债务、现金、价格和市值等时点指标比较相应报告期末／周期点位；流量和比率按所选周期口径比较。时间范围筛选前完成比较，因此允许使用范围外的同期记录。缺当前值、缺比较期或基期非正时显示不可比原因，不计算百分比。归母扣非净利润缺少来源科目时保留空值。历史表左上表头注明金额单位“亿元”，行内不重复展示单位（包括“元/股”），左侧指标名称下方按适用规则标注“同比”或“同比 / 环比”；有两个变化率时在同一行并排显示。

### 3.4 价格、市值与日期限制

季末市值与披露日估算市值分别匹配报告期末和披露日，但均使用**该报告期末**股本。不从百度总市值观察或行业市值表回填，不从前复权价格计算。

现有程序将“实收资本（或股本）”权益科目数值用作股数，通常隐含每股面值 1 元的假设；不同面值及 A/B/H 股等特殊股份结构需另核对。季末市值同样是公式估算，名称不表示已经获得数据源直接披露的精确历史市值。

披露日若位于有前后交易记录的长停牌间隔中，距前一交易日 16–180 天，披露日股价／市值可显示空心参考点并用虚线连接，悬浮提示给出日期与间隔。参考点不计作正式值；季末市值不使用这一长间隔参考回退。

新浪历史 `publish_date` 有错位情况，程序核对上一年同报告期记录的原披露日期并生成新浪校正候选，保留 `source_publish_date`。明确财务刷新时，公告日期同步独立读取巨潮定期报告元数据；普通缓存页面读取不发公告请求，首次建档仅由明确财务刷新或全量核对触发，成功检查在 24 小时内复用。唯一且完整核验的原始正式报告可作为首次披露日；修订公告日期单独记录为最近已知修订日。对于原版明确标记“已取消”而只有修订版的报告，只有在完整查询范围（或三项均来自此前已验证缓存）中，股票和报告期匹配的取消原版、有效正式修订版、非修订摘要三项发布时间唯一且一致、无来源时间冲突时，才用共同日期作为首次披露日；取消原版仅作发布时间证据，不作为当前有效财报。摘要、修订/更正说明、分页不完整或候选冲突不会被当作首次披露日。人工 `report_overrides.publish_date`（包括显式 null）优先于自动候选；无已核验公告结果时可沿用新浪校正候选并标记未核验。悬浮提示显示披露日来源、最近已知修订日及待核验/冲突状态。元数据采集不下载正文或 PDF，因此首次披露日期不证明当前财务值是当时披露版本；修订日期也仅覆盖已缓存候选。没有采用日期时披露日指标留空，季末市值仍可独立计算。前复权使用数据源当前调整的历史价格，不代表当年实际成交价；即使历史值为负，也保留源值。

| 行业均值 | 东方财富返回的当前同业 PE／PB／PS 算术平均 | `industry_snapshots`；只作当前横向比较，不对应历史月份 |

PS 不用首图季末市值或披露日估算市值作为分子。分红窗口为 `(观察日－365 天, 观察日]`，按实际除权日筛选；窗口没有已实施事件时股息率可为零，不用季末估算分红金额作分子。日频股息率只在本地实际未复权日行情日期计算，不补交易日、不插值；无日行情时保留月度观察的稀疏度。

图表可选日、周、月，周／月按每个指标分别取周期内最后一条有效观察；自动模式 3 年为日、5 年为周、10 年为月。周／月叠加前复权股价时，估值和股价的横轴共同对齐到该周期最后实际交易日，悬浮提示只显示一次该日期；估值值仍是周期内最后一条有效估值观察，可能早于展示日期。周期内无交易的叠加价格可连接前后已有点；周期末交易日缺前复权价格时留断点，不补造价格。

PE／PB／PS 的有效分位样本要求值为正，股息率允许零。负 PE 原始值保留，但走势断线并用浅色区域标注负值观察区间；缺失与零不标为负 PE。

### 4.1 分位、卡片与参考线

- 分位＝样本中严格小于最近有效值的数量÷样本数×100%，显示一位小数；相等样本不计入“小于”。最近值与日期按各指标自己的最近有效观察确定，不因另一指标更新而清空。
- 近 3／5／10 年的分位与参考线统一使用所选范围内全部有效日观察；不因年限或完整覆盖率降为周／月样本。缺失日不插值、不补值；股息率在本地日行情可用时以每日未复权收盘价计算日样本，图表按所选日／周／月频展示对应观察。
- 分位和参考线共用上述样本；切换图表日／周／月展示频率不改变样本。时间范围改变会重选样本。
- 分位模式的低／中／高参考线为 20%／50%／80% 分位值，排序后按位置 `(N－1)×分位比例` 线性插值。
- 标准差模式的下／中／上线为均值－1σ、均值、均值＋1σ；σ 是总体标准差，分母为 N。下限不截断，参考区间不表示投资结论或概率。
- 卡片分档：≤5% 极低；5%–20%（不含 5%，含 20%）低位；20%–40%（不含端点）偏低；40%–60%（含端点）中值；60%–80%（不含端点）偏高；80%–95%（含 80%，不含 95%）高位；≥95% 极高。股息率的低位／高位两档用低息／高息，最外侧同样使用极低／极高；无当前值或无有效分位时显示待判断。七档分别使用亮绿、青绿、灰蓝、琥珀、浅橙、珊瑚红、亮玫红，极低／极高底色更鲜明；股息率配色顺序反向，中值不变。分档仅表示自身历史位置，切换标准差参考线不改变卡片分档，不代表低估／高估或投资结论。
- 笔记插入的历史分位沿用上述七档边界及股息率反向配色语义，在数值后附文字判断和彩色 Unicode 圆点，支持普通 Markdown 文字／表格。圆点不保证与页面卡片的 CSS 色值一致；无有效分位时不附判断，不改变百分比数值或分位计算。

百度历史观察可能稀疏，不将缺日补成零或插值。财报可能后续修订，PS 的“当时已披露”筛选不等于完整的财报修订点时数据库。
