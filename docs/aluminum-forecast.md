# 中国铝业周期盈利分析

中国铝业（601600）的「企业经营趋势」提供「中国铝业周期盈利分析」入口。独立页读取本地已披露的归母利润、未复权 A 股收盘价和总股本，默认预测从当年起的三年。三个情景的价格、净利润敏感度、经营调整、分红比例及预计股本均可编辑，分红比例初始为 30%、35%、40%。基准年只以已披露全年财务为默认锚点，参考价和股本显示各自日期。

## 行情

打开页面只读本地数据。「刷新市场行情」使用上期所公开日行情文件，取已结算交易日的 AL、AO 实际交割月合约结算价。每品种先按持仓量排序，并列时按成交量和较近交割月确定。北京时间 15:45 前从上一天开始，最多探查五个周一至周五的候选日。未结算或文件不存在会检查更早日期。取得一条可用报价时发布可用品种并列出缺项。请求按真实来源 `shfe` 复用公共请求预算、同源锁、拒绝冷却和响应归档。

同一操作读取长江有色公开行情的华东 A00 铝锭现货中间价和区间，以及新浪财经沪铝连续 `AL0` 日线。图表展示最近 12 个自然月最后一个有效交易日的收盘价，当前月标明实际截止交易日，缺月断开。各来源分开记录成功或失败。两项市场参考都使用公共归档，页面可在重启后读取本地证据。现货和月线只用于市场参考。 [长江有色行情](https://www.worldmetalres.com/zh) · [新浪沪铝连续行情](https://finance.sina.com.cn/futures/quotes/AL0.shtml)

缓存每个品种最新一条，完整成功后 15 分钟内重复刷新复用已有报价，缓存释放或重启后可只读恢复公共归档。新建草稿自动取最新本地结算价为中性参考，没有归档时使用基准年报行情价。刷新成功后只重填尚未编辑的新草稿；已编辑参数可选择采用报价。合约期货日结算价、企业实际销售均价和年度预测均价分别有自己的口径。

## 计算、历史参考与快照

每年度归母净利润分别用共同基准利润加两项价格变动、产销量、成本和其他归母调整。敏感度以商品价格每变化 100 元／吨对应的合并归母净利润变化计。氧化铝按集团外部购销净敞口填写，产销量和成本调整按税后归母口径填写。现金分红以正归母利润乘分红比例计算，再除以预计总股本得每股股息，最后除以参考股价得税前股息率。缺值在对应结果留空，三年累计只汇总对应指标齐全的情景。

当年纳入已披露的最新累计归母净利润。剩余季度以基准年全年归母减同报告期累计归母作基准，年化期货价格影响按剩余季度数除以四折算。当年经营调整只作用于剩余部分。缺同报告期财务时，页面仍显示已经披露的实际数。无当年财报时全年度按情景试算，有当年年报时显示全年实绩。结果明细分别显示已披露归母与当年剩余预测。

自动草稿用 2025 年报的沪铝现货月均价与国内氧化铝现货均价为基准。沪铝敏感度用当年自产原铝外销量。氧化铝净敞口用冶金氧化铝产量减估算的自用量，按每吨原铝耗用两吨氧化铝计算，假设库存变化和其他流量可忽略。两项按同年归母净利润除以利润总额得到的转换系数折算，同时按含税报价 13% 折净和价格等额传导估算。敏感度可编辑，模型估算有别于财报披露的实际售价或采购量。保守和乐观按敏感度方向使用沪铝 4.0%、氧化铝 21.1% 的浮动幅度，这两个幅度参考年报市场价格同比变化绝对值。默认三年使用相同价格中心。

历史售价回归采用海控的传导方法，使用经核实的对外售价与同期沪铝均价，按实际披露日期滚动验证。当前财报未找到足量的同口径售价数据，页面将此缺口与自动估算依据一并展示。 [核查记录](plans/20261125_中国铝业周期盈利分析/PROGRESS.md)

审阅过的同频同口径样本可用 `python -m stock_analysis.domains.research.sectors.aluminum.sensitivity <样本.json>` 离线复算。输入为 JSON 数组，每项提供 ISO 日期 `start/end/published_on`、`frequency/basis`、`market_price`、`actual_price` 或 `revenue/volume`，以及 `financial_evidence/market_evidence`。首次建议从样本核对清单生成输入；命令只读取显式文件并输出诊断，结果由人工核对后发布。

保存生成新的不可改写版本。历史加载恢复原参数、报价、证据和结果，复制为草稿后可继续编辑。「用最新行情重新测算」先复制和刷新参考报价，用户再选择采用报价。所有计算结果均由服务端按采用的参数复算并保存。删除仅作用于选中版本，来源版本被删后已另存的方案仍可恢复。

SQLite 方案备份可以独立恢复原值和计算结果。完整证据档案恢复还需同期保存公共响应归档及正式财报文件。 [SQLite 存储说明](sqlite-storage.md)
