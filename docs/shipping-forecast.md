# 中远海控利润预测

仅601919在企业经营趋势历史数据表下、口径文字之后显示与「行业内对比」同样式的「海控净利润测算/运价趋势 →」，在新标签打开同一8765的 `/?code=601919&tab=shipping-forecast`。页面及GET API仅使用本地正式存储，不启动来源采集、模型或自动保存。返回链接进入经营趋势；采集管理链接进入后台维护。

研究页提供「利润预测」和「CCFI / SCFI 趋势」两个子 Tab。旧 `tab=shipping-forecast` 链接仍默认打开利润预测；以 `view=trend` 打开趋势并可通过浏览器前进/后退切换。未保存的预测参数留在原页面实例中，切换视图不会重载或保存。

趋势页只读 `research_shipping_rate_points`，月度严格使用 `monthly_mean`，周度严格使用 `release`；最新修订优先。默认仅官方，切换「官方优先＋补充资料」后，补充资料仅填补没有官方值的相同所属期，且在图例和明细中保留来源质量、通道、修订、来源ID及真实取得时间。不插值；月度缺月在曲线中断开。周度完整趋势按真实发布日期，跨年图按ISO周周年对齐，第53周独立保留，重复落入同一ISO周的点在对比线中采用该周最后一条有效发布，真实发布日期仍可从明细查看。航线只移除经核对的周度「航线（…）」后缀，西非与东西非不合并。

完整趋势支持CCFI/SCFI、月/周、可用航线、全部/十年/五年/三年/一年滚动范围、官方质量开关及实际利润（默认单季度，可切换不显示或年初累计）。多年对比的年份来自当前筛选可用数据，默认最近四个有效年份，可多选；年份标注在该年有效点中选择与其他年份曲线距离较大的留白位置。完整趋势与利润子图共用一个悬浮卡片和一条运价图日期标线，卡片同时显示运价及该季度实际利润；横轴缩放联动。多年运价与利润图不做悬浮联动。利润取601919 `financial_reports` 中 `gjzb.PARENETP` 优先、`lrb.PARENETP` 逐项回退；亿元为单位，年初累计直接读取报告原值，单季度以同年相邻累计值差分，缺上期累计留空，零和负数保留。利润仅画在真实财务季度，不扩展为月/周值；只展示与当前运价序列时间范围重叠的真实财务期。页面数值最多显示两位小数；可编辑参数仅格式化显示，不改变未编辑的原始参数值。

覆盖状态动态按本地事实查询。2026-10-25验收快照：CCFI官方综合月度153期（2014-01至2026-09）；CCFI官方综合周度2期（2026-10-16、2026-10-23）；SCFI官方周度综合2期、无月度数据。首末日期不等于每个航线/来源连续完整；SCFI月度显示明确空态，不从周值派生。

吞吐量保留指标月、报告月、披露日、当月万TEU与公布同比，全国/沿海/内河不强行平账。2026年9月报告于10月15日发布，引用8月数据；该变量仅展示行业参照，不用于模型或回测中的箱量替代。尚未建立足够同口径公司样本的增量验证，不给出传导系数。

## 模型与预测版本

财务读取financial_reports，gjzb优先、lrb逐项回退；营业成本固定lrb.BIZCOST，利润总额固定lrb.TOTPROFIT。业务收入和箱量分别累计差分再相除；当目标季度前一份可用业务底数不是紧邻季度时，页面显示实际锚点，不冒充相邻季度。模型训练只取目标季度之前的已存财务季度。历史报告仍为当前已存修订版，不宣称完整当时可得快照。

默认月度提前1月，三个自然月简单平均；同月已核验官方值优先，未核验月份仍使用标明质量的Excel值，不无声改成周均。缺任何月则窗口值为空，允许用户填写未来CCFI或收入覆盖作为情景。中性用历史单箱人民币收入对CCFI的水平线性斜率、锚定最新实际业务底数，悲观/乐观保留手动弹性；箱量、单位成本、汇率修正、毛利以下税前净额、税前转归母及额外损益均为可编辑假设。零收入覆盖有效。三情景不是置信区间。

周度整季窗口默认前移14天，用户可选提前2、3或4周；Q3提前2周为[6月17日,9月17日)，不只截取季末两周。选项同时控制展示的周度窗口及线性模型对应样本，月度提前1月仍作为独立对照。展示发布值均值与覆盖诊断，使用与月度共同季度样本滚动检验，不因一次最优切换默认窗口。日期质量仍含日历推定、节假日覆盖未独立核实。SCFI、航线权重、非线性与吞吐量未验证足够增益，不进入默认模型。

### 中性情景线性斜率的算法与样本

默认预测的「财报线性锚定」使用周度模型。先从 `research_shipping_rate_points` 取未被后续版本替代的 **CCFI 综合航线**事实；本次训练样本中的周值均为 `statistic=release`，不把月均、年均或年初累计作为周度观察。每个历史财务季度分别按所选提前周数平移整个季度区间，取区间内实际发布周值的简单平均，得到该季度运价特征 `xᵢ`。不对缺周插值；仅在窗口已结束、首末观察距边界均不超过10天、相邻观察间隔不超过14天时判为完整。相同日期有多条事实时优先官方值，来源修订按当前有效版本读取。

单箱收入 `yᵢ` 为该季度国际航线业务收入除以国际航线箱量，单位人民币/TEU。训练仅纳入目标季度之前、财务及业务底数齐备且周度窗口完整的季度。拟合带截距的普通最小二乘直线：

```text
yᵢ = a + b·xᵢ + εᵢ
b = Σ[(xᵢ−x̄)(yᵢ−ȳ)] / Σ[(xᵢ−x̄)²]
```

其中 `b` 是情景公式里的历史斜率，单位为“元/TEU/CCFI点”。预测时不直接用截距预测收入，而是锚定最近可用财报季度的实际单箱收入 `y_anchor`：实现对应 [航运模型代码](../stock_analysis/domains/research/sectors/shipping/shipping_forecast.py) 中的 `fit`、`rate_window` 与 `calculate`。

```text
预测单箱收入增幅 = [b·(目标窗口CCFI均值−锚点窗口CCFI均值) / y_anchor]
加入汇率修正后收入增幅 = (1 + 预测单箱收入增幅)·(1 + 汇率修正率) − 1
```

再将收入增幅应用于国际航线收入，国内等其他收入保持锚点值，后续另乘箱量假设；成本及归母利润按情景输入分别计算。改变提前2/3/4周会重取历史季度窗口并重新拟合周度斜率。

当前数据快照（2026-10-25，2026Q3预测、提前2周）：周度拟合 **12个季度样本**，期间为2023Q2至2026Q2（不含2023Q4），训练截止2026Q2；各季度均值分别使用11—13条发布值，共149条。该组训练观测当前均来自 `user_excel` 的 `calendar_inferred` 或 `calendar_inferred_flagged` 质量资料，**不是官方周度历史样本**；同日官方优先规则并未改变这组样本的实际来源质量。拟合斜率为4.6835（页面显示4.68），截距约2,725.60。并行月度模型使用提前1月的三个月均值；当前14个样本拟合斜率约4.7409，但本例公式使用周度4.6835。官方周度历史覆盖不足，系数应视为现有推定周度样本上的统计关系，不代表因果或已由官方长期样本验证。样本随数据库事实、修订、财务数据及提前周数变化而变化。

滚动验证以过去季度训练单箱收入线性映射，用前期实际单箱收入锚定下一季度；页面比较预测MAE和前期收入基线MAE，不将其当作三情景利润回测。保存版本固化目标、预测周数、输入事实ID、财务哈希、训练截止、模型系数、参数与结果，输入变化拒绝按旧hash保存。版本以可选清单展示，时间使用项目统一北京时间格式至秒；点击仅选择版本，需再按「载入所选版本」才载入参数并定位到情景测算；原参数不会自动展开。可删除选中的历史版本，服务端要求当前本地会话令牌并永久删除该版本。载入后当前试算使用最新本地数据，另存才生成新版本。重新校准是明确的确定性计算，保留参数并另存，不使用模型额度。旧版本不可UPDATE。行业箱量参考可按全国、沿海、内河多选，默认全选。

## 采集管理及API

管理页只展示一个「航运采集」模块，内部选择官方月度指数与吞吐量（含图片）、CCFI/SCFI周度、既有研究资料导入。切换类型保留各自未保存输入和已展开历史；刷新状态不重置类型。月度图片在同轮自动解析，人工核验补正及旧导入记录收在月度下的折叠项，不另列采集模块。

内部沿用 `shipping_weekly`、`shipping_monthly`、`shipping_research_import`、`shipping_image_review` 四个适配身份，以保留原运行、来源和配置。沿用统一operation互斥、取消、公共batch/source与唯一Scheduler；不新增调度线程。周月定时无配置时默认关闭，导入任务仅手动，不能开启定时。既有任务设置不改。

- `GET /api/shipping-forecast?target=2026Q3`：本地事实、质量、窗口、模型、默认参数、版本目录、来源依据。
- `GET /api/shipping-forecast?version=ID`：旧快照与当前实际误差。
- `GET /api/shipping-trend?index=CCFI&frequency=monthly&route=综合&range=all&quality=official&profit=none`：航运事实及覆盖，支持 `years=2023,2024` 多年筛选。仅本地读取，未写入预测版本。
- `POST /api/shipping-forecast/save`：target/name/kind/input_hash/scenarios，三情景由服务端复算；Origin和本地会话校验。
- `POST /api/shipping-forecast/prepare-report`：period，显式准备单份正式财报；同样校验Origin和本地会话。

SQLite备份不包括Excel归档、图片、PDF、解析文件；资料迁移同时携带公共collection_sources与company_reports，按哈希校验。实施范围及实际验收见[原计划](plans/20261024_ccfi海控利润预测/PLAN.md)、[主任务验收记录](plans/20261024_ccfi海控利润预测/ACCEPTANCE.md)和[趋势 Tab 与页面反馈验收](plans/20261024_ccfi海控利润预测/TREND_TABS_ACCEPTANCE.md)。

普通增量/回填复用已校验详情时，当前运行也登记对应分段、原batch/source引用和保留的来源取得时间，重新验证归档哈希，覆盖判定不升级。原失败运行保持历史状态；后续同范围恢复成功会产生新的成功运行，管理页最近执行成功随之更新，页面读取本身不启动恢复。


## 本地图片OCR与历史回填（2026-10-25）

月表为HTML或图片由同一采集任务分流，共用monthly_points字段、统计区间及校验规则。图片采用本地RapidOCR 1.4.4/ONNX Runtime，彩色3倍、灰度2/3/4倍识别；每个数字须至少两次高置信且有效的识别结果完全一致，数字形态、负号、小数及表头年月严格校验。航线由明确识别的原名确认；Windows自带中文OCR可辅助航线交叉核对，已识别的有效航线有冲突则不发布。不以固定13行套用所有历史表，西非与东西非不合并。当前自动图片模板支持带完整5列网格、指数两位小数的官方表格；未知布局、多图片及未通过整表校验的月份留下具体诊断，不猜值。

OCR仅在明确启动采集时运行，不在页面读取时触发，不上传图片或使用大模型额度。完整OCR行列、引擎版本及三个ONNX模型哈希集中归档为shipping.mot_ocr来源；事实仍引用原始shipping.mot_image来源。同轮HTML来源、图片及OCR证据均可追溯。两个2026-08/09真实样本各13航线、共104个数字与原核验值完全一致。

可选依赖见requirements-shipping-ocr.txt，按项目Python环境安装；当前机器附加运行包位于项目相对data/runtime/shipping-ocr，复用原已安装的numpy、OpenCV、Pillow和ONNX Runtime。Windows辅助识别需要系统中文OCR语言；不可用时仍只发布其余识别结果可明确通过校验的表格，否则留待核验。迁移机器应重新安装依赖，OCR原始证据随collection_sources迁移，不能只迁SQLite。

目录显示2013年仅6个月，2014—2025每年12个月，2026年截至9月。用户授权回填范围为2014-01至2026-09，共153个月指数与对应目录可见分析报告；目录完整不等于数值完整。历史分析报告正文确未披露吞吐量时，执行完成但coverage=empty，不造数；出现相关指标但无法解析仍保留失败诊断。分段进度在运行中持续写入，成功分段可原范围续跑。此次为手动回填，定时仍关闭。


## 航运请求提速（2026-10-25用户授权）

`mot`、`sse` 使用公共RequestCollector内的固定航运策略：同源单并发，完成后2—5秒，滚动60秒30次，每20次额外休息10秒。仅这两个真实来源采用此策略；默认及其他已授权例外不变。所有页面和图片共享对应来源预算，跨任务/进程/重启保留；原有预算等待不会因升级被清零。拒绝立即停止、至少一小时及Retry-After冷却、重复拒绝延长和普通错误60/120秒重试保持。运行结果provider_policies.shipping记录实际策略，policy字段仍是公共默认值。


## 历史市场分析解析修复（2026-10-25）

shipping-analysis-v2校验报告标题及真实披露日后，从统计段就近明确年月解析指标期，支持省略年时沿用正文已有明确年月上下文，不能用URL或发布时间推算。兼容规模以上/主要港口、全角百分号、大幅增长/微涨、共计等原文表达。scope原样区分全国/沿海/内河及规模以上/主要，不跨范围合并；原文混合统计范围时分别保留并标partial，不强行加总。basis=monthly为当月、ytd为年初累计（含明确第一季度）、annual为全年；period记录该统计区间终月，不能将累计量当成当月。预测页行业参考同时显示统计口径。

## 情景计算说明与趋势联动

每个情景卡片的「计算说明」按当前输入展示收入增幅、收入、成本、税前利润、单季度归母及年初累计的公式和计算值；缺少前序季度时明确标记未计算。趋势页启用实际季度利润时，月度模式使用等距月份横轴，利润柱左边对应季度首月、右边对应末月、中心对应中间月份（例如Q2为4月、5月、6月），相邻季度留出一个月间隔；真实统计期末日期保留在悬浮卡和明细中。周度模式仍使用真实日期横轴，季度柱覆盖自然季度，两端各内收3.5天，相邻季度保留7天间隔；周值保留真实发布日期，季初/季末最多半周可位于柱边留白内；纵轴以零为基准并按亿元整数刻度自适应。中性预测虚线框与实际柱宽度一致、置于目标季度中心，从利润零线向上（负值则向下）标出当前预测值，例如月度2026Q3从7月点延伸至9月点，8月点居中，不在图面放置预测文字；悬浮到目标季度时，统一提示卡显示中性预测利润说明。完整趋势与利润图悬浮时使用同一真实日期标线，并由一张提示卡同时展示运价和对应财务季度利润；月度联动按月份位置绘制标线，提示仍显示7月31日等真实统计期末日期。多年对比图不联动。

月度和周度均独立展示当前中性预测：启用利润且有运价点时，即使当前来源/范围没有重叠的已披露利润，也保留预测虚线框；横轴扩展到预测季度，预测值参与纵轴范围计算。鼠标移入预测框可直接查看统一预测说明，不依赖目标季度存在运价点。
