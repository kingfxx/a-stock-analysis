# 页面定时刷新与图表视野

2026-10-17因拥挤度图框选放大后自动还原，检查项目自有JS/HTML及Python生成页面的定时器；第三方Plotly库内部计时器不作为业务轮询。

## 已修复

| 页面区块 | 原行为 | 当前行为 |
|---|---|---|
| 大盘拥挤度 | 每10秒读取完整本地数据并重绘，空闲也执行 | 空闲不轮询；采集中每10秒仅读轻量status并更新进度/按钮；结束后完整读取一次 |
| 指数估值 | 采集中5秒、空闲30秒查询状态；版本变化时重读目录和图表 | 空闲不轮询；采集中5秒只更新进度/计数/按钮，版本变化也不重读历史；结束后按版本更新数据 |

这两块此前都没有稳定的Plotly `uirevision`。现在按各自指数、序列/指标（适用时）、时间范围、展示频率生成稳定键；数据更新保留框选/缩放/平移，主动改变相应筛选才重置。

指数估值图加载历史时保留旧图直至新数据就绪，不先绘制空曲线；日期轴类型固定为date，避免空数据中转导致日期轴变成数值轴而破坏缩放。

进度查询不等于刷新整个页面。运行中不重建筛选框、不重读曲线数据、不调用Plotly重绘；结束后才按需更新数据。两块使用显式页面事件同步任务启动/取消，避免为了发现同页新任务而持续空闲轮询。

首次打开及返回可见页面仍按需检查本地数据，指数区块保留聚焦时版本检查；运行中返回/聚焦也只更新进度。空闲页面不会实时发现另一窗口或后台刚启动的任务，需要返回页面或用户主动操作时检查。后台每日采集日程照常执行，不受前端是否轮询影响。

## 其他页面检查结果

| `web/features/research/assessment/ai-assessment.js` | 排队/生成/校验任务查询；登录连接期间2秒检查，最长10分钟 | 有任务或登录条件约束；更新研判摘要/抽屉，不重载主页面图表；报告抽屉重绘保留滚动位置 |
| `web/features/research/assessment/ai-checklist.js` | 与AI研判类似的任务和登录状态查询 | 同上，无无条件空闲定时刷新 |

| 财务报表、DCF等其余自有页面代码 | 未发现同类setInterval/setTimeout业务刷新 | 本次未修改 |

## 验证

宿主机隔离库浏览器使用真实鼠标框选，推进浏览器时钟验证：采集中即使写入新数据并提升版本，也没有历史/目录/点位数据请求及图表重绘；结束后读一次数据、三轴视野保留；继续空闲35秒，两区块没有新增定时请求；主动切换频率重置视野，从空闲点击采集可同时唤醒两处进度。
