# 未来三年股息率预测计算器

入口：个股研究页 → 估值 → 股息率 → 历史图下方「未来三年股息率预测计算器」。预测北京时间当前年及未来两年，不新增一级导航。

## 数据与口径

计算器通过只读`GET /api/dividend-forecast?code=601919`读取本地数据，不调用来源采集或模型，不写原始财务、分红或行情表。接口不支持历史时点回测；当前财务/分红记录会被来源修订覆盖，无法据此重建过去信息集。

- 财务来源为`financial_reports`中的新浪原始`gjzb/lrb/llb/fzb`，通过现有解码及`statements.metric`逐字段读取，适用的关键指标优先、三表回退。仅使用报告期和源披露日均不晚于当前日的记录，缺少可靠源披露日时不自动使用。验证CNY与合并口径，保留来源字段、哈希、取得时间及人工财务覆盖证据。
- 归母利润为`PARENETP`，经营现金流为`MANANETR`，资本开支为`ACQUASSETCASH`，FCF沿用经营现金流减资本开支。累计H1/Q3不再与已实现单季度重复相加。
- 股本取`market_trade_snapshot.total_shares`，使用已核实的股数；资产负债表实收资本金额不能当作股数。股价取最近本地腾讯未复权日收盘价，缺少或快照更新时取交易日快照未复权收盘价，展示各自实际日期和来源。
- 原始分红来自`dividend_events`。有同所属期的新源数据时不再叠加legacy。保留事件键、预案日、公告日和除权日；仅implemented且除权日已到的事件进入已实施合计。未来除权、待实施、取消独立展示。同所属期、同除权日出现多个身份时提示冲突，金额不自动累计。
- 现金金额默认为事件原始每股派息×事件来源总股数的**估算金额**，未扣回购等不参与股份，也不自动验证A/H股范围。允许逐事件填写现金金额与核对依据，不用当前股本倒算历史金额。原始DPS仍保留各事件原每股口径，不因金额覆盖或股本变动重复复权。
- 特别分红性质默认为未知，不能按金额或所属期推定。用户可标记普通/特别并填写依据，勾选排除特别分红后同步更新历史金额、分红率和覆盖倍数。没有依据的人工事件标记/金额暂不应用。

实际派息日、公告实付金额、完整特别分红分类与可靠结构化分红政策目前缺失。公开政策选项提供手填入口，不将文本上限视为确定分红承诺。

## 自动值与手动参数

历史参考显示最近五年及当前年已知情况。没有事件不代表零分红。年度完整性须由用户勾选并填写依据；明确零分红还须勾选不分红且没有已实施或待实施事件。排除特别分红时，该年度尚有未知性质事件也不能视为完整。

分红率自动值优先使用最近三年累计已实施现金分红/累计归母利润，三年缺少适用数据时回退最近一年，仍不具备则留空。**不要求用户逐年人工确认才能自动计算**；来源金额为估算、年度覆盖和特别性质未核实的限制单独提示。也可选择1/3/5年模式或逐年调整。累计利润非正时不提供自动比例；保留亏损年，不平均各年分红率，不跳过缺年。窗口中缺年、缺金额、事件身份冲突或仍有待实施事件时不能用于自动分红率。勾选排除特别分红只排除已标记且有依据的事件，未知性质不阻断参考比例，不能声称已排除所有特别分红。

只提供一套**中性主参数**：利润模式、上年基准、A/B金额及比例调整、三年增长率、年度利润覆盖、分红率、现金金额覆盖和股本。悲观与乐观全部按中性结果和情景系数自动生成，不再分别填三套年度参数。中性任一参数改变时，两个派生情景、累计回报、现金压力比较及目标价同时更新。

中性主参数顶部提供“未来三年统一分红率（%）”：填写一次应用到三个预测年度，悲观/乐观继续按各自系数联动。统一值生效时优先于原逐年分红率，下面三个年度的分红率暂时锁定；清空后恢复原逐年设置，未单独调整的年度回到所选历史默认值。原逐年设置保留，不被批量改写。0%为有效值，负值不用于生成分红。手动现金金额仍优先，结果显示实际隐含分红率。统一参数随当前股票/起始年保存，恢复默认或跨年时清除。

两个主要输入为悲观/乐观利润系数，默认优先从历史25%/75%线性插值分位相对中性自动基准的差异换算：`系数=1+(历史情景基准−历史中性基准)/abs(历史中性基准)`，中性选择均值时使用该均值作为中心。C模式系数优先参考A的历史波动，A缺少资料时参考B。历史不足、中心为零或分位没有方向差异时，使用0.8/1.2作为明确标注的可调模型假设，不构成公司预测。用户修改中性利润金额不会把历史波动系数重新拟合成独立预测。

正利润按`中性利润×利润系数`派生；为避免亏损方向倒置，一般形式为`派生利润=中性利润+abs(中性利润)×(利润系数−1)`，所以低于1会扩大亏损。三个年度各应用一次，不将情景系数逐年复利。中性为零时系数不能凭空产生利润。

折叠的“更多情景系数”支持分红率系数及股本系数，默认均为1，沿用中性口径：`派生分红率=中性有效分红率×分红率系数`、`派生股本=中性股本×股本系数`，随后按利润和分红率重新计算现金、DPS与股息率。分红率系数不得负，股本系数须正；不自动把悲观股本取倒数。中性若直接覆盖现金金额，派生现金沿用该金额假设，`中性现金×利润系数×分红率系数`，每个系数只应用一次；无有效非负金额则留空，不生成负现金。自定义系数组合可能使最终股息率次序变化，以实际计算为准。

| 模式 | 当前年利润基准 |
| --- | --- |
| A 当年累计＋剩余预测 | 最新已披露累计归母利润＋最近连续3/5完整年同剩余期间利润的中位数/均值；剩余利润=历史全年−历史同期累计，可为负值 |
| B 历史正常化 | 最近连续3/5完整年归母利润的中位数/均值 |
| C 三年增长率 | 上一完整财年利润或手填上年基准×当前年增长率，随后逐年复利 |

没有当年累计资料时A不自动切换B，提示用户选模式或填利润；没有完整历史窗口不跳年。A/B后两年默认0%持平。三个年度增长率均可手填：编辑A/B当年增长率会明确切换该情景为C；只编辑后两年继续以A/B当前年预测递推。年度最终利润覆盖优先，覆盖后的值作为下一年增长基准；结果显示最终有效同比，上一年利润非正时同比不适用。A/B调整比例不得小于−100%。

中性主参数直接显示自动值，每项附来源；绿色为自动值，金色为手动调整，清空并移开恢复自动。情景系数同样支持自动/手动状态，“恢复默认情景系数”只清除系数调整，保留中性输入。自动输入默认显示两位小数、股本及系数四位，鼠标提示保留未舍入值，计算始终使用完整精度。自动显示及派生结果不会变为持久手动覆盖。手动利润/现金金额与增长率/分红率同时设置时，显示优先生效的依据及有效同比/分红率。

## 公式与边界

内部金额元、股本股、比例小数；页面输入亿元、亿股、百分数时仅在边界换算一次。计算保留精度，显示时舍入。

```text
现金分红 = 预测归母利润 × 分红率
DPS = 现金分红 / 预测总股本
预期股息率 = DPS / 当前未复权价格
三财年累计DPS = 三个年度DPS之和
三财年累计股息回报 = 累计DPS / 当前未复权价格
目标买入参考价 = 所选情景/年度DPS / 目标股息率
```

归母利润非正、分红率不适用时乘法现金分红留空，允许用户直接覆盖非负现金金额；不会机械产生负股息。现金金额覆盖优先于分红率，利润为正时显示隐含实际分红率。超过100%分红率明确提示；零股价/股本、无效数值或溢出不输出误导性结果。任一年度DPS缺失时三年累计留空。

最近一年/三年FCF覆盖分别以相同归属财年的FCF和现金分红匹配，三年为合计之比，不是倍数平均；资料可用时自动显示覆盖参考，年度完整性未核实则明确为已实施估算口径，不要求先人工确认。缺项或存在待实施事件则留空，零分红覆盖倍数不适用。负FCF不抹平。预测分红与历史三年平均FCF比较只是假设压力提示，没有预测未来FCF或生成确定风险评级。

净现金为同一期末货币资金减简化有息债务。复用现有债务分项函数；缺少任何适用分项时仅显示已知部分及缺项，净现金留空。货币资金不等于可自由分配现金。金融企业继续支持利润/分红预测，标准FCF与简化净债务辅助区显示不适用。

## 历史图与未来收益的区别

历史图继续使用观察日过去365天已除权派息/当日未复权价；预测结果使用归属财年，不连接原历史曲线，不加入历史分位，不改变原PE/PB/PS/DCF结果。历史图叠加的前复权价不参与预测分母。

三财年累计可能包括当前年买入前已除权的股息，不能称为从今天持有三年能够收到的现金。结果不含股息税、再投资和股价变化，不是年化收益率。目标买入价是基于所选年度股息假设的参考，不能当作DCF内在价值。


## 机构预期模式（2026-10-21）

利润模式新增“D 机构预期”。仅用户选择该模式或点击“重新读取机构预期”时，通过`GET /api/institution-forecast?code=...`请求同花顺`https://basic.10jqka.com.cn/<code>/worth.html`，不额外安装或调用AKShare。使用与AKShare盈利预测相同的页面表格来源，严格匹配“预测年报净利润”及“单位：亿元”的caption和六个汇总字段，按北京时间当前年及未来两年精确匹配年度；均值由亿元转换为元，返回各年机构数、来源网址和取得时间。

机构预期逐年直接覆盖计算中的利润，不使用已有手动利润、A/B调整或增长率递推；保留原手动设置，切回A/B/C后恢复。D模式利润与增长率框只读，增长率由年度利润反推；分红率、现金金额、股本及情景系数继续按原优先级工作。零／负利润保留，机构数为零、缺年或缺均值留空，不以其他年度补齐。失败显示错误并留空，可显式重试；股票切换、跨年或新请求隔离旧响应。

预测值、网页正文和派生计算结果不保存到SQLite、文件、localStorage或sessionStorage，仅保留当前页面内存；HTTP及前端请求均no-store。刷新页面回到A模式，不自动重新采集；原手动参数仍保留。公共采集层仅登记`stock.institution_forecast`的请求元数据和执行状态，结果JSON不含预测值，来源文件／哈希／字节数为空。提供方`ths`共享跨进程预算，采用默认保守限速、拒绝停止及至少一小时冷却，不启用其他股票提供方的提速例外。冷却到期的恢复请求须通过完整预测表校验。

来源页面将指标命名为净利润；当前按其机构盈利预测口径用于计算器利润输入，不另外推断扣非利润，源表没有明确合并／归母标记时不能据此证明所有机构口径完全一致。机构净利润预测不等于公司分红承诺。

## 保存、刷新与测试

手动参数、事件标注和完整性证据保存于浏览器`dividend-forecast:v1:<股票>:<预测起始年>`，不跨设备同步，不保存计算结果或原始JSON副本，不增加数据库表。跨年重新生成年度参数和完整性确认，仅沿用仍匹配事件身份的人工标注及依据。存储不可用时提示仅保留内存。恢复默认清除当前股票当期人工覆盖及标注。

当前参数布局版本为2，计算口径为`dividend_forecast_v3`。升级时保留已有中性设置；旧版悲观/乐观独立覆盖停止生效并保留在`legacy_scenarios`证据中，页面提示已迁移，避免旧覆盖悄悄阻断中性联动。手动情景系数随股票和起始年保存，跨年重建。

初次选股息率即读取本地依据；财务/分红/价格更新后重读，保留手动参数并提示核对。异步请求按股票和请求序号隔离，股票切换不串参数。预测接口失败不影响历史图。

测试入口为`tests/test_dividend_forecast.py`、`tests/test_dividend_forecast_ui.py`及共享合成样例`tests/fixtures/dividend_forecast.json`，均使用隔离数据。实现与验收记录见[本任务计划](plans/20261021_股息率预测计算器/PROGRESS.md)。
