000001 的 1989/1990 年新浪利润表确实只有归母利润等少数字段，没有营业收入。首次同步保存原始稀疏报告并明确提示，缺失营收保持空值；近期 8 期仍执行必要字段校验，普通刷新不再因此重复全量。旧期已保存字段消失时仍拒绝覆盖。

旧月度估值与新逐日观察按同一自然月比较的完整差异清单见 [p4-valuation-differences.json](p4-valuation-differences.json)：601919 和 600887 各 95 个月有 PE/PB/PS 至少一项差异；000001 没有旧估值 JSON，故无可比较月份。差异既包括月末取样日变化，也包括同日观察数值或 PS 依赖变化，不能仅凭旧月度结果把每项断言为来源修订。公式沿用 `monthly_valuation` 与已披露收入 TTM 的现有计算规则；旧快照保留旧口径版本 `monthly_qfq_overlay_v1`，新事实标记 `baidu_dense_observations_v1`。

隔离副本与恢复副本均报告 `integrity=ok`、结构版本 3，财报、分红、估值、行业及旧月度快照记录数逐项一致。本机 Python 3.11.9 / SQLite 3.45.1 使用 DELETE journal。P5 已验证事务回滚、启动中断恢复、并发读取及本机备份恢复。

只读缓存 HTML 的独立进程首调用及同进程后续 3 次中位数：601919 为 444/492 ms（4.93 MB），600887 为 528/546 ms（5.23 MB），000001 为 330/319 ms（5.69 MB）。P4 前 601919 的运行库页面约 90.5/86.0 ms；新页面嵌入密集估值观察后响应体明显变大，性能差异需在正式切换时关注。该测量不含浏览器渲染、异步 API、外部来源或冷磁盘 I/O，也不是完整页面加载耗时。
