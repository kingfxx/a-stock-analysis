## 记录与复现

探针位于 `experiments/source_probe/`，对应 `results/*.json` 是本次运行摘要。`mootdx_probe.py` 记录空日线、财务快照和除权事件；`http_probe.py` 记录新浪、腾讯、百度及官方网页响应；`detail_probe.py` 记录财报历史和腾讯未复权日线；`tdx_package_probe.py` 只保留单日包内三只样本；`baostock_probe.py`、`eastmoney_fallback_probe.py` 保存失败/限流观察。`verify_samples.py` 对记录数据执行了 22 项字段核对并通过。

东财备源 JSON 被第二次失败实验覆盖；首次成功的行数及三股 2026-09-24 成交额来自当次终端输出，后者与保留的通达信包摘要一致。不能用这一次成功宣称东财稳定。部分 `HTTP 200` 数据不等于完整历史或持久可用；字段名称、单位、更新时点均按上表单独判定。

## 访问范围与权限核查

| 来源 | 本次请求量 | 已知限制/权限状态 |
|---|---|---|
| 腾讯行情/K 线 | 每只样本少量请求 | 接口未公开稳定服务承诺；单次最多 640 根的限制按[来源实现说明](https://github.com/simonlin1212/a-stock-data)记录，长期稳定性待观察；数据再使用条款未核对 |

| 通达信单日包 | 完整下载 1 个交易日，另做 4 字节范围请求 | [官方页面](https://www.tdx.com.cn/article/vipdata.html)将盘后数据描述为个人版 PC 软件用途；独立解析和长期本地留存的条款需核对 |
| mootdx | 三股各少量 TCP 请求 | [软件仓库](https://github.com/mootdx/mootdx)为 MIT 许可；这不代表上游行情数据有相同许可 |
| 东财备源 | 首次 3 次限速请求，后来 4 次失败 | 当前不稳定；未验证接口使用条款和可持续请求额度，不据此设计批量抓取 |

## 阶段 0 未通过的关口

1. 2001–2021 年的**历史成交额**尚没有稳定、可重复调用的来源；腾讯日线不含该字段，官方单日包 2021-01-04 已不可下载。
2. 历史股本事件的单位、精度和生效日未完成正式公告逐项核对；当前值的浮点近似不能直接用于精确市值。
3. 财报更正的历史版本与实际可见日期仍未验证；现有新浪接口返回当前版本，不能据此回填“当时已知”的更正前值。
4. mootdx 公司行动无完整公告/登记/派息日期，股息率历史计算尚缺实施日期的权威映射。
5. 公开接口与官方包的数据使用条款未完成逐项核对；当前只完成小样本个人研究测试。

上述关口未解决前，依照原始计划暂不锁定生产表结构或实现历史估值曲线。
