## 3. 可以直接演示的三个补充

### 3.1 具体同行对照，而不是仅看行业均值

选择宁德时代、亿纬锂能、国轩高科作为电池制造可比候选，仍需标注各家动力/储能/消费电池、地区和客户结构差异。

| 指标 | 宁德时代 | 亿纬锂能 | 国轩高科 |
|---|---:|---:|---:|
| 2026半年报毛利率（源披露） | 23.93% | 14.31% | 15.60% |
| 2026半年报累计加权ROE（源披露） | 12.08% | 7.24% | 4.68% |
| 扣非净利润 / 归母净利润（自行计算） | 90.13% | 74.26% | 7.71% |
| 2026-09-30腾讯PE(TTM) | 15.85 | 18.57 | 15.73 |

这只是来源样本对照，不构成公司质量排名或买卖结论。它已说明为什么相近 PE 仍需要检查利润结构。例如本次国轩样本扣非利润占比较低，应继续核实非经常性损益组成和持续性。

按项目优先级，宁德时代先读本地 `gjzb`，新同行从相同新浪接口取数。金额字段码 `PARENETP/BIZTOTINCO/NPCUT`、比例字段码 `SGPMARGIN/ROEWEIGHTED` 保存在验证报告；有效零值保留，缺值留空。累计加权 ROE 不能替换现有图中 ROE(TTM估算)。银行即使返回名为毛利率的值，也不因此适用于制造业横向对比，应另用净息差、不良率和资本充足率等。

同次东财查询的行业 PE(TTM) 平均为16.45、中值为25.38。两者相差较大，且只返回部分同行，建议同时展示来源中值、样本量、选择范围和方法核验状态；不能仅据一个均值判断便宜。

### 3.2 将产业链主题转为有证据的风险指标

伊利2025年报正式原件已在本地，无需重新下载；PDF第24页（报告印刷页20/255）披露：

- 前五名客户占年度销售总额8.15%。
- 前五名供应商占年度采购总额40.00%。
- 前五名供应商中的关联采购占年度采购总额25.96%。

三项分母不同，关联采购25.96%不是前五名内部占比。结合原奶周价、公司毛利率与现金流，可形成“原料价格—成本传导—利润变化”的研究面板。公司采购定价、传导时滞和产品售价还需报告证据，不能由相关性推断因果或直接模拟采购成本。

已有年报业务拆分与主题抽取可复用；优先加入历年可核对的结构化集中度，再逐步加入产能、利用率、销量、单位售价和订单。完整客户/供应商名称和真实商业联系未必披露，保留未知，不能让模型补出关系。

### 3.3 行业强弱与组合分析的数据基础

在共同观察区间2026-09-01收盘至09-30收盘：本地宁德时代前复权价格收益 -18.71%；腾讯电池ETF价格收益 -7.92%；沪深300价格指数收益 -5.50%。相对差值分别为 -10.79、-13.20 个百分点。这只是示范窗口，后续应展示20/60/120日趋势，不能由这个窗口推导择时有效性。

本地宁德时代、伊利、中远海控有21个共同价格日期。以起点各1/3、持有不再平衡作演示组合，区间价格收益 -6.43%、最大回撤 -6.98%。这证明现有价格可以支持组合计算；不代表用户持仓，不含费用、资金流和现金分红。正式收益核算需要实际数量和现金流水，历史相关性建议使用更长且共同有效的窗口，停牌和缺值不能当零收益。

组合集中度应按实际市值权重汇总；另保存不同业务带来的产业暴露，避免持有上游、制造、下游多家公司却共同依赖同一需求。股票分组允许多重归属，不能直接把每个分组相加当行业权重，否则会重复计数。

## 4. 建议建设顺序

1. **先补分类与具体同行组。** 独立保存分类体系、层级、代码、成分、生效区间和来源；允许用户确认经营可比组。先用2—3个行业试点，补中位数、同报告期增长、利润率、ROE/ROIC、现金流和扣非对照。
2. **再补重点行业经营面板。** 优先当前股票库中的电池、乳业、航运、有色；每行业先3—5个核心指标。电池用下游销量/渗透率、原料与产品价格、装车/储能需求；乳业用原奶、业务结构、销量和渠道；航运用SCFI/CCFI、运量和运力；有色用价格、产销量与单位成本。装车量及CCFI历史本次未做结构化接口验证。
3. **量化产业链证据。** 从已有正式报告增加客户/供应商集中度、关联采购、订单与产能历史；保留页码、哈希、统计期和提取版本，支持手工核验。
4. **增加板块强弱页。** 指数或ETF相对基准收益、上涨家数占比、成交活跃度、融资变化并列显示。机构预测及主力资金属于辅助来源，先验证方法和历史覆盖，再考虑回测；不先合成单一景气/择时分数。
5. **增加组合风险页。** 先数量、成本和现金，再权重、行业/产业链暴露、相关性、回撤和压力情景，最后才考虑仓位规则；不自动优化仓位。

复用现有 SQLite 事实、来源与同步框架，但行业公共数据不应为每只股票重复存一份。后续概念可分为行业定义/成分、行业指标观察、同行组及实际持仓。所有观察保留统计期、实际发布日期、行情日期、取得日期、单位、累计/单月/TTM、来源字段及计算版本；回测按当时可知信息，不能用当前成分和后来修订数据回填历史。

## 5. 接口和解释上的特别限制

- [上交所2024年沪港通披露调整通知](https://big5.sse.com.cn/site/cht/www.sse.com.cn/lawandrules/sselawsrules2025/global/hkexsc/c/c_20250613_10781806.shtml)规定自2024-08-19调整披露内容，沪股通公布每日成交总额及笔数、季度末单股持股等。旧北向分钟净流入接口即使返回数字，也不能因此当作当前官方真实净流入。本次未调用这类旧接口。
- [国证市盈率方法说明](https://www.cnindex.com.cn/files/syljssm.pdf)区分加权与中位数、静态与滚动口径；不能拿官方加权值与当前页面所称算术平均直接作差判断。
- 官方统计来源的大类行业、东财板块和公司主营业务分类不是一套分类，须有可核验映射。需求旺盛、盈利改善和股价上涨是不同信号。
- 本次完成当前小样本可达性、字段、日期、哈希和少量算术检查。跨交易日稳定性、全市场覆盖、历史修订、正式财报逐值交叉核验与回测有效性仍待验证。

复现方式：在有Python的环境中从仓库根目录执行 `python data/verification/tools/industry_extension_probe.py`；工具只依赖标准库，默认少量串行请求。可用 `--only sina_peer_300014 sina_peer_002074 tencent_battery_etf` 只跑选定来源。正式库使用 SQLite `mode=ro` 打开，输出仅在验证分类目录。此次仅新增研究资料与验证工具，8765日常后台无需重启。
