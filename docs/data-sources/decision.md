# 阶段 0 技术决策与下一步

日期：2026-09-27　状态：**原日线/历史估值范围部分验证；季度页面已单独放行**

用户随后将首版范围缩小为季度财务对照图，并接受不保存完整日线。该页面现在只需要季度财报和月末价格，按[新方案](../plans/2026-09-27-quarterly-dashboard.md)独立实施。本文件下述阻断仍适用于以后扩展完整历史日线、精确历史估值和股息率。

本机实验支持将**腾讯未复权日线**作为沪深个股 OHLCV 的候选主源、**新浪财报三表**作为财务字段及披露日期的候选主源。通达信官网单日盘后包可补足可下载日期的精确成交量和成交额；mootdx `xdxr` 可提供公司行动线索。mootdx 在线 K 线连续返回空，不能作为主源。实验细节见 [数据源矩阵](matrix.md)。

当前最大阻断是完整历史成交额和历史股本/修订时点。东财直连首次取得多年日线成交额，之后持续代理错误，不满足稳定性要求。官方单日包按日期下载整市场约 2–3 MB/日，即使最终只保留指定股票，长历史初次获取仍有流量成本；目前证实 2023-01-03 可访问、2021-01-04 不可访问。官网“完整包”链接在本机返回 989 字节脚本页，尚无法确认下载体积或以命令行解析。

后续阶段 0 工作顺序：

1. 复测东财备源的失败原因及服务条款，但保持它仅作补缺来源；并寻找独立的历史成交额来源。记录 3 个样本的首次、重复调用和跨日稳定性。不得为得到成功响应而高频重试或轮换网络。
2. 从正式公告核对每只样本至少一例股本变化和分红实施日期，确定 `xdxr` 的万股/每 10 股单位以及事件生效日；精确股本优先采用公告股数，浮点快照仅作交叉校验。
3. 用已更正财报的真实样本测试新浪是否保留旧版本。如果只返回最新值，历史曲线必须有“版本未知”状态，或补充公告版本源后才上线历史 PE/PB。
4. 明确首版对历史成交额的处理：找到可靠来源后按原需求完整保存；若只保证 2022 年后成交额，需修改需求及验收范围并在界面显示早期缺口。

阶段 0 放行条件仍是：每个首版必需字段有稳定来源和核对样本；披露日与公司行动时点足以避免未来信息；缺失或失败可被识别。满足后再按 [实施计划](../plans/2026-09-27-a-share-local-analysis.md)进入阶段 1。
