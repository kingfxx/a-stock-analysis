# 图表悬浮提示规范

本规范适用于项目内的趋势图和其他带坐标轴的图表。目标是让用户快速读出时间点、曲线名称和数值，避免在同一个提示框中重复日期。

## 默认样式

- 使用统一横轴悬浮提示（Plotly `hovermode: 'x unified'`），同一横轴位置的多条序列放在一个提示框内。
- 日期轴的提示框标题显示一次完整日期，格式为 `YYYY-MM-DD`。轴刻度可以按页面密度显示年月，但悬浮日期使用完整格式。
- 每条序列只显示“名称：数值 单位”。不要在序列行再次输出横轴日期、展示日期或实际日期；隐藏额外的 trace 名称区，避免名称重复。
- 数字精度和单位沿用指标定义；不同序列使用自己的名称和单位。

```js
{
  hovermode: 'x unified',
  xaxis: { type: 'date', tickformat: '%Y-%m', hoverformat: '%Y-%m-%d' }
}

{
  name: '融资余额',
  hovertemplate: '融资余额：%{y:.2f} 亿元<extra></extra>'
}
```

日期型以外的横轴，在标题中显示一次对应的类别或周期；各序列行仍只显示名称、数值和单位。

## 多序列日期对齐

- 同一提示框中的序列应共用相同的横轴日期。周／月频展示时，若同时叠加交易价格，优先用该周期最后一个实际交易日作为共同展示日期。
- 共同展示日期是图表对齐锚点，不得据此改写来源事实日期或声称所有指标都在该日重新观察。
- 如果某序列的实际观察日早于共同展示日期，应明确记录其取值规则，并在图表附近的说明中注明该值来自周期内最后一条有效观察。不要为追求提示简洁而隐去会影响理解的日期差异。
- 如果序列不能合理对齐到同一日期，保留各自真实日期并说明原因；不能把不同日期的值伪装成同日事实。

## 检查清单

- 同一悬浮框内日期只出现一次。
- 每条序列行都有可辨认的名称、数值和单位，且名称没有重复显示。
- 周／月频的日期锚点和跨序列取值规则在页面说明中准确表达。
- 缺失值、负值和零值继续按各自指标规则呈现，不由 tooltip 格式化逻辑改变。
