# 投资笔记

入口位于侧栏「财务分析」与「行业内对比」之间。直接打开 `/?code=300750&tab=notes` 可读取该股票的笔记，不启动行情／财务到期采集或模型生成。切回原有分析页面后沿用原页面的数据更新规则。

## 日常记录

每只股票一个 UTF-8 Markdown 文件，默认目录为数据库同级的 `investment_notes/`；日常数据库对应项目 `data/investment_notes/`。文件名如 `sz300750_宁德时代.md`，以股票代码定位，公司名称变化不会自动改名。

点击「新增记录」在一级标题之后插入北京时间日期，最新记录在前；同日再次新建会加时分秒。默认正文只含股票标题与日期，不要求填写模板，也不添加可见的 YAML 元信息。兼容已有 YAML 的 `stock_code` 股票身份；没有代码身份的外部 Markdown 可以在后台维护中关联股票，关联会在原文前添加最少的通用元信息，保留原正文。有其他元信息的文件应在外部软件中添加 `stock_code` 后重新扫描。

直接写文字或 Markdown，可用加粗、列表、撤销与重做。点击「预览」查看排版，点击「编辑」继续写。支持普通 Markdown 表格和来源脚注；不执行原始 HTML。原始 `.md` 可以在其他笔记软件中直接打开。「导出」下载当前编辑内容，包含尚未成功写入磁盘的草稿；「全部笔记」支持名称、代码、文件名和正文搜索，取消关注不会删除笔记。

编辑与预览工具栏都有「大纲」按钮，点击展开／收起正文右侧的独立目录栏；目录与正文左右并排，可独立滚动，不放在正文上方。按 Markdown 一级至六级标题显示层次，也识别下划线式标题，排除代码块中的伪标题。选择标题时，编辑模式跳到对应行，预览模式跳到对应标题，保持当前模式。空文档会提示暂无标题；日期标题不足三条也可使用。

## 自动保存与外部修改

快捷笔记窗口支持点击窗口外的空白处关闭，关闭前立即保存当前修改，不等待 30 秒；点击窗口内部不会关闭。保存失败或存在冲突时保持窗口打开，显示提示并保留内容，可处理后重试关闭。

停止修改 30 秒后自动保存，每次继续输入或修改都会重新计时；没有修改时不写文件。保存期间的新修改仍保留，并按最后一次修改重新安排保存。工具栏显示未保存、保存中、已保存、失败或冲突；失败时保留内容并提供重试。站内切换视图、股票切换、快速面板关闭或页面转入后台时尝试立即保存，Ctrl/Cmd+S 可立即保存；仍有未保存内容时关闭浏览器会提示。浏览器 IndexedDB 只保留当前未保存草稿以便恢复，不管理历史版本；浏览器禁用存储或清理站点数据会影响草稿恢复，不影响已经保存的 Markdown。

文件写入使用同目录临时文件、刷新及原子替换，写入失败不截断旧文件。保存携带完整内容哈希版本，不仅依赖修改时间和文件大小；两个标签页不能直接用旧版本覆盖新版本。

活动笔记约每 3 秒及页面重新获得焦点时检查外部修改，页面隐藏时暂停检查。没有未保存内容时加载外部更新；两边同时编辑时暂停自动保存，展示本地与磁盘内容，可在正文合并后采用当前编辑内容，或采用磁盘内容。采用磁盘内容前提示将放弃本地未保存内容，可先导出草稿；不自动创建冲突副本。文件被删除或改名时不自动重建，先检查目录，再显式决定是否恢复。

应用不再提供「历史版本」入口、历史读取／恢复接口或版本文件写入，历史管理交给用户的云同步软件。已有 `.history/` 文件不自动删除或改写，可由用户另行整理。正文保存仍用内容哈希校验外部变化，这只是防覆盖检查，不是历史版本管理。

这些保护不能把不遵守应用锁的外部软件变成同一个事务。其他软件恰在最后一次检查与替换之间写入仍存在极短竞态；同步软件也可能自行制造冲突文件。建议避免两处同时编辑，出现异常可检查云同步软件的历史记录和当前浏览器草稿。浏览器被强制结束前尚未来得及持久化的最后输入也不能保证恢复。

## 在估值图追踪笔记

估值图自动从当前股票已保存的 Markdown 二至六级标题中提取有效的 `YYYY-MM-DD` 日期，例如 `## 2026-10-21 买入记录`。正文、表格、代码块、YAML 中的日期不作为笔记事件；无效日期忽略。标记使用标题真实日期，不挪到交易日，也不使用笔记里的数据日期替代；仅在图表已有数据起止日期之间显示，不补造对应估值。

图上沿的笔形标记及竖向参考线指示记录日期，悬浮显示标题，点击以预览打开笔记并定位标题。同一天多条记录合并显示数量，点击选择具体条目。相邻日期错层显示，过密时优先保持标记可点击，图下「图内笔记」列表保留区间内所有条目，也支持键盘访问。「叠加前复权股价」右侧提供「显示笔记」按钮，高亮为显示；点击可隐藏／恢复图中标记、参考线及图下笔记列表。切换 PE、PB、PS、股息率与展示频率不改变笔记日期。

保存后同步更新标记；趋势页打开期间每 3 秒只读检查文件变化，外部软件修改后也可更新。该功能不写入笔记，不发起行情采集或模型调用。

## 插入数据与快捷入口

编辑器「插入数据」默认生成单项文字，可多选后以分号连接，也可切换生成 Markdown 表格。选择器显示真实数据日／报告期与周期；缺值显示「暂无数据」，可显式插入缺失说明，不用旧期或零值代替。

数据分组：

- 估值与分位：PE（TTM）、PB、股息率、相应可用历史分位、未复权收盘价；历史范围为 3／5／10 年。

- 经营趋势：营收、归母与扣非利润、同比、现金流、利润率及页面已有简化指标，支持单季度、累计、年度、TTM。
- 股东与融资：实际截止日的股东户数与较上期变化；日末融资余额、当日融资净买入额、融资融券余额。现有本地页面不提供融资买入总额与融券余量时显示缺失，不与净买入或余额混用。
- 主营构成：按产品、行业、地区选择报告期及原始项目的收入、成本、毛利、收入占比、毛利率；使用来源原始名称，不将统一名称归并结果冒充原始值。
- 财务三表：所选报告期和单季／累计口径下的关键卡片、已有同比／环比、完整来源科目及比较期值。余额仍为期末时点值，比较期按原页面规则。

估值与分位的「历史区间」旁提供原生日历式「数据日期」选择。默认选今天或最近一个有有效本地估值／日行情的日期；没有任何资料时显示今天并提示无数据。手动选择日期后，每项仅读取该日有效数值，缺失显示「暂无数据」，不自动沿用前日数值；更改日期会清空已选项目及旧预览，避免插入上一次结果。日期不得晚于北京时间今天，切换历史区间保留所选日期；其他数据分组继续使用自己的报告期。

历史分位使用所选日及此前 3／5／10 年的有效样本计算，后续日期不计入分位。PE／PB 复用原始观察及页面公式，股息率使用该日前 365 天已实施现金分红与该日未复权收盘价，有日行情时按日样本；无日行情时保留已有月度观察及真实观察日。有效零股息率保留，PE／PB 非正值不作为有效估值或分位。计算使用当前本地保存的资料版本，历史日期不代表应用在当日留存过快照，不调用来源补齐缺失。

插入历史分位时自动附上页面同口径的七档位置判断，单项文字和数据表均适用，例如 `PE（TTM）近10年历史分位 0.10%（🟢 极低）`。分档为极低、低位（股息率为低息）、偏低、中值、偏高、高位（股息率为高息）、极高；缺失或无效分位不生成判断。使用彩色 Unicode 圆点表达配色方向，PE／PB 低位为绿、高位为红，股息率相反，中间档用蓝／黄／橙色；各阅读器字体外观可能不同，不依赖 HTML 样式，也不自动改写旧笔记。
单项文字示例：`2026Q2 归母净利润同比 ××%（单季度）`。按用户最新反馈，新插入只生成选中数据的普通文字或表格，不附脚注标记、批注或时间说明，方便通用 Markdown 阅读器查看。选择器仍显示数据日期和必要口径，表格保留日期／报告期，默认不含口径列；选择数据表后可在「插入位置」旁勾选「插入口径」，预览及插入结果才增加口径列，每次打开选择器默认不勾选；历史分位 0.8 表示 0.8%，不乘 100。插入内容是固定文本，后续数据刷新不会改变旧笔记。已有笔记中的旧脚注继续兼容预览，不自动删除或改写。

企业经营趋势、主营构成、财务分析共用一组「记一笔／插入笔记」按钮，不在各模块重复摆放。桌面贴附当前模块的右边缘，预留侧边空间避免遮挡数据，滚动及窗口变化时跟随；窄屏保留右下方横排。笔记、行业对比、后台维护页面，以及公告列表或任意对话框打开时隐藏；关闭弹层后恢复。

点击插入时，根据可视面积最大的模块自动预选分组：经营趋势区→经营趋势及当前周期；估值与分位区→估值与分位及当前历史区间；股东区→股东与融资／股东户数；融资区→股东与融资／融资。主营页保留所选维度，三表保留报表类型、报告期、周期与比较对象。用户仍可在选择器切换分组及细项；没有明确点位时不猜测图表悬浮项，需自行选择具体日期和项目。选择插到当前光标或新日期段，确认后才更改文档。

主页面与快速面板复用同一个编辑器和草稿。查看笔记、选择及插入数据只读本地保存资料，不调用模型、不发起来源采集，不改写财务事实。报告期、披露日、取得时间分别保留，读取的财务可能包含后续修订，不是严格历史实时回测。

## 存储目录与备份

后台维护新增「投资笔记设置」，显示宿主机完整目录。可调用宿主机文件夹选择窗口，窗口不可用时直接输入绝对路径。「检查目录」会创建不存在的目标目录并测试写权限；只检查不切换当前目录。

更换目录需先预览，再选择确认：

1. 复制现有笔记及附件后切换：已有附属文件原样复制，逐文件校验哈希，复制过程中源／目标变化则不切换；原文件保留。
2. 使用目标目录已有笔记：只切换读取位置，旧目录仍保留，不自动合并两边内容。

同名不同内容、重复股票身份、互相嵌套的目录、符号链接越界会阻止迁移。失败后目标可能保留已复制的文件；重新预览会识别相同内容，仍不会覆盖不同内容。迁移期间本应用写入串行，其他软件应停止编辑以免目录反复变化。

「重新扫描」识别外部新增、修改及尚未关联的根目录 `.md` 文件。目录不可写或不可读时明确报错，不静默保存到其他位置。笔记最大 2 MiB；预览目录内的 PNG/JPEG/GIF/WebP、PDF、文本资源最大 20 MiB，禁止越界与隐藏文件访问；不自动加载远程图片。不包含附件上传管理功能。

配置存于数据库同级 `notes-settings.json`；默认 `data/` 已被 Git 忽略。自选目录的隐私和同步由该目录所属软件管理。没有新增 SQLite 表，SQLite 备份不包含 Markdown、附件、历史副本或此配置；完整迁移电脑需单独复制这些文件并重新核对本机目录配置。

## 本地依赖

CodeMirror 5 提供编辑，markdown-it 与脚注插件提供预览，DOMPurify 负责净化；静态文件、许可证、固定版本与 SHA256 清单在 `web/vendor/notes/`。页面运行不访问 CDN。具体版本见该目录的 `manifest.json`。
