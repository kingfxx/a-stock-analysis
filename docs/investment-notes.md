# 投资笔记

入口位于侧栏「财务分析」与「行业内对比」之间。直接打开 `/?code=300750&tab=notes` 可读取该股票的笔记，不启动行情／财务到期采集或模型生成。切回原有分析页面后沿用原页面的数据更新规则。

## 日常记录

每只股票一个 UTF-8 Markdown 文件，默认目录为数据库同级的 `investment_notes/`；日常数据库对应项目 `data/investment_notes/`。文件名如 `sz300750_宁德时代.md`，以股票代码定位，公司名称变化不会自动改名。

点击「新增记录」在一级标题之后插入北京时间日期，最新记录在前；同日再次新建会加时分秒。默认正文只含股票标题与日期，不要求填写模板，也不添加可见的 YAML 元信息。兼容已有 YAML 的 `stock_code` 股票身份；没有代码身份的外部 Markdown 可以在后台维护中关联股票，关联会在原文前添加最少的通用元信息，保留原正文。有其他元信息的文件应在外部软件中添加 `stock_code` 后重新扫描。

直接写文字或 Markdown，可用加粗、列表、撤销与重做。点击「预览」查看排版，点击「编辑」继续写。支持普通 Markdown 表格和来源脚注；不执行原始 HTML。原始 `.md` 可以在其他笔记软件中直接打开。「导出」下载当前编辑内容，包含尚未成功写入磁盘的草稿；「全部笔记」支持名称、代码、文件名和正文搜索，取消关注不会删除笔记。

编辑与预览工具栏都有「大纲」按钮，点击展开／收起当前文档目录。按 Markdown 一级至六级标题显示层次，也识别下划线式标题，排除代码块中的伪标题。选择标题时，编辑模式跳到对应行，预览模式跳到对应标题，保持当前模式。空文档会提示暂无标题；日期标题不足三条也可使用。

## 自动保存与外部修改

输入停止约 800ms 后自动保存，工具栏显示未保存、保存中、已保存、失败或冲突。失败时保留编辑内容并提供重试。站内切换视图、快速面板关闭时尝试立即保存；仍有未保存内容时关闭浏览器会提示。浏览器 IndexedDB 保留按目录和股票区分的恢复草稿，下次打开同一股票时恢复；浏览器禁用存储或清理站点数据会影响草稿恢复，不影响已经保存的 Markdown。

文件写入使用同目录临时文件、刷新及原子替换，写入失败不截断旧文件。保存携带完整内容哈希版本，不仅依赖修改时间和文件大小；两个标签页不能直接用旧版本覆盖新版本。

活动笔记约每 3 秒及页面重新获得焦点时检查外部修改，页面隐藏时暂停检查。没有未保存内容时加载外部更新；两边同时编辑时暂停自动保存，展示本地与磁盘版本，可在正文合并后采用当前编辑内容，或采用磁盘版本。采用磁盘前先将本地草稿保存为冲突副本。文件被删除或改名时不自动重建，先检查目录，再显式决定是否恢复。

`.history/<交易所代码>/latest.md` 保留上一次被替换的内容；普通历史版本最多 50 份、通常至少间隔 5 分钟。`conflict-*.md` 是冲突保护副本，不自动清理。「历史版本」可预览并将所选内容加载回编辑器，随后按相同自动保存和版本校验规则写入。恢复前当前文件也会保留。

这些保护不能把不遵守应用锁的外部软件变成同一个事务。其他软件恰在最后一次检查与替换之间写入仍存在极短竞态；同步软件也可能自行制造冲突文件。建议避免两处同时编辑，出现异常先查看历史版本、冲突副本和浏览器草稿。浏览器被强制结束前尚未来得及持久化的最后输入也不能保证恢复。

## 插入数据与快捷入口

编辑器「插入数据」默认生成单项文字，可多选后以分号连接，也可切换生成 Markdown 表格。选择器显示真实数据日／报告期与周期；缺值显示「暂无数据」，可显式插入缺失说明，不用旧期或零值代替。

数据分组：

- 估值与分位：PE（TTM）、PB、股息率、相应可用历史分位、未复权收盘价；历史范围为 3／5／10 年。
- 经营趋势：营收、归母与扣非利润、同比、现金流、利润率及页面已有简化指标，支持单季度、累计、年度、TTM。
- 股东与融资：实际截止日的股东户数与较上期变化；日末融资余额、当日融资净买入额、融资融券余额。现有本地页面不提供融资买入总额与融券余量时显示缺失，不与净买入或余额混用。
- 主营构成：按产品、行业、地区选择报告期及原始项目的收入、成本、毛利、收入占比、毛利率；使用来源原始名称，不将统一名称归并结果冒充原始值。
- 财务三表：所选报告期和单季／累计口径下的关键卡片、已有同比／环比、完整来源科目及比较期值。余额仍为期末时点值，比较期按原页面规则。

单项文字示例：`2026Q2 归母净利润同比 ××%（单季度）`。按用户最新反馈，新插入只生成选中数据的普通文字或表格，不附脚注标记、批注或时间说明，方便通用 Markdown 阅读器查看。选择器仍显示数据日期和必要口径，表格保留日期／报告期及口径列；历史分位 0.8 表示 0.8%，不乘 100。插入内容是固定文本，后续数据刷新不会改变旧笔记。已有笔记中的旧脚注继续兼容预览，不自动删除或改写。

企业经营趋势、主营构成、财务分析共用一组「记一笔／插入笔记」按钮，不在各模块重复摆放。桌面贴附当前模块的右边缘，预留侧边空间避免遮挡数据，滚动及窗口变化时跟随；窄屏保留右下方横排。笔记、行业对比、后台维护页面及快速编辑弹窗打开时隐藏。

点击插入时，根据可视面积最大的模块自动预选分组：经营趋势区→经营趋势及当前周期；估值与分位区→估值与分位及当前历史区间；股东区→股东与融资／股东户数；融资区→股东与融资／融资。主营页保留所选维度，三表保留报表类型、报告期、周期与比较对象。用户仍可在选择器切换分组及细项；没有明确点位时不猜测图表悬浮项，需自行选择具体日期和项目。选择插到当前光标或新日期段，确认后才更改文档。

主页面与快速面板复用同一个编辑器和草稿。查看笔记、选择及插入数据只读本地保存资料，不调用模型、不发起来源采集，不改写财务事实。报告期、披露日、取得时间分别保留，读取的财务可能包含后续修订，不是严格历史实时回测。

## 存储目录与备份

后台维护新增「投资笔记设置」，显示宿主机完整目录。可调用宿主机文件夹选择窗口，窗口不可用时直接输入绝对路径。「检查目录」会创建不存在的目标目录并测试写权限；只检查不切换当前目录。

更换目录需先预览，再选择确认：

1. 复制现有笔记及附件后切换：包含历史副本，逐文件校验哈希，复制过程中源／目标变化则不切换；原文件保留。
2. 使用目标目录已有笔记：只切换读取位置，旧目录仍保留，不自动合并两边内容。

同名不同内容、重复股票身份、互相嵌套的目录、符号链接越界会阻止迁移。失败后目标可能保留已复制的文件；重新预览会识别相同内容，仍不会覆盖不同内容。迁移期间本应用写入串行，其他软件应停止编辑以免目录反复变化。

「重新扫描」识别外部新增、修改及尚未关联的根目录 `.md` 文件。目录不可写或不可读时明确报错，不静默保存到其他位置。笔记最大 2 MiB；预览目录内的 PNG/JPEG/GIF/WebP、PDF、文本资源最大 20 MiB，禁止越界与隐藏文件访问；不自动加载远程图片。不包含附件上传管理功能。

配置存于数据库同级 `notes-settings.json`；默认 `data/` 已被 Git 忽略。自选目录的隐私和同步由该目录所属软件管理。没有新增 SQLite 表，SQLite 备份不包含 Markdown、附件、历史副本或此配置；完整迁移电脑需单独复制这些文件并重新核对本机目录配置。

## 本地依赖

CodeMirror 5 提供编辑，markdown-it 与脚注插件提供预览，DOMPurify 负责净化；静态文件、许可证、固定版本与 SHA256 清单在 `web/vendor/notes/`。页面运行不访问 CDN。具体版本见该目录的 `manifest.json`。
