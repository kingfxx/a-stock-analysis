# AI 股票综合研判

首版采用价值投资、中长期 1–3 年视角。顶部股票信息行的“AI 研判”用于生成或打开最近成功报告；重新分析才重新使用额度。经营、估值为主要依据，筹码只作补充；“买入候选”表示值得进一步核实。

## 连接和使用

1. 安装 `requirements.txt` 中依赖，启动日常 8765 后台。
2. 打开“AI 设置”，选择 `Continue with ChatGPT`，在 OpenAI 页面独立登录并授权计划使用权限。
3. 返回设置面板，从当前账号官方模型列表中选择并保存模型。登录及选择模型不自动生成研判。
4. 数据更新完成后，点击“生成研判”或“重新分析”。可先展开“本次分析的数据范围”。
5. 成功报告显示五个维度、支持与反面证据、判断改变条件；点击“依据”查看生成时的事实。报告及历史均可离线重开。

数据不够时拒绝调用；部分缺项允许受限分析。相关事实变更后标明数据变化。失败、取消和后台中断不会覆盖旧报告，不自动重试模型请求，也不使用 API Key 兜底。

历史记录支持复选、多选、“全选已加载”和批量删除，最多一次删除 200 条。确认删除后实际移除 SQLite 中的任务、报告、用量和诊断记录，并清理不再被其他任务引用的输入与来源快照。正在分析或等待的任务需先取消；批量请求中有无效或活动记录时整批不删除。删除最新报告后摘要回退到上一份成功报告；全部删除后显示暂无报告，不自动调用模型。删除不另行触发备份，既有正式备份按原规则保留。

首版仅发送本地当前股票摘要，不发送分组、最近查看、个人笔记或整个 SQLite。报告不执行交易、不提供仓位或目标价。模型文字的事实忠实度仍需人工核实，程序校验不能证明全部语义。

## 认证与凭据

采用官方 SIWC 文档中的 public-client 动态注册、PKCE、state、nonce、JWKS 身份签名验证；Python 通过 Requests 调用公开 Responses API，身份签名使用 PyJWT。无需 Node 辅助进程。每个请求发送 `store:false`、`stream:true`，只接受成功终态后的严格 JSON，不暴露模型工具。

Windows DPAPI 将凭据绑定到当前操作系统用户，文件位于忽略的 `data/ai-private/credentials.dpapi`，无明文降级路径。稳定主机标识和客户端注册映射保存在同目录的 `registration.json`。凭据不进入数据库、前端存储、日志和 Git，也不从 Codex 认证文件读取。断开连接清理本应用凭据并尝试撤销可续期会话；远程撤销未确认时会提示去 ChatGPT 设置处理。

SQLite 备份包含报告及快照，**不包含账号凭据**。换机器或 Windows 用户、恢复数据库后须重新连接。已有报告可继续查看。

## 存储与故障恢复

迁移 007 将结构升级为版本 7。升级前在线一致备份，新表为 `ai_analysis_snapshots`、`ai_analysis_runs`、`ai_analysis_preferences`。快照不可修改；任务关联同股票快照，成功报告追加保存。数据库约束与短事务实现股票去重、全局单运行任务及最多一个等待任务。

每次生成在一个只读事务中复制事实、覆盖与已完成价格版本；模型调用在事务外。快照保存模型实际输入、证据和有限来源记录，纯抓取时间或同步 ID 不影响输入哈希。AI 分析不单独触发备份，沿用现有启动及跨日业务更新前日备份规则，不覆盖当天已有备份。启动恢复活动任务为中断，重新生成须手动触发。

新增写接口校验 Host、Origin、JSON 大小与启动时随机本地会话令牌。模型输出以文本节点渲染。查看报告和历史不会请求供应商；只有打开设置获取模型列表或明确生成才访问供应商。

推理诊断保存在任务的 `diagnostic_json`（失败）或 `validation_json`（成功）中：北京时间、模型、HTTP 状态、仅 `x-request-id`/`Retry-After` 两个响应头、终止事件类型和完整错误对象。非成功 HTTP 响应体最多保留 256 KiB，超限明确标记截断；认证字段及回显凭证脱敏，不保存请求头或正常模型正文。客户端注册身份匹配与工作区独立核验分别记录，未核实工作区不视为一致。诊断不会触发自动重试。

## 验证边界

自动回归使用临时库和模拟供应商，测试不消耗真实额度。浏览器验收使用已有 Edge 无头模式。真实账号登录、计划资格、模型格式能力、实际额度/延迟、刷新与撤销、真实分析质量，需要在本应用完成独立授权后人工验收；模拟成功不代表这些已验证。

官方协议核对日期：2026-10-01。参考：[注册与登录](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)、[模型与调用](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)、[限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。


### 依据展示与债务口径修正

依据以可收起条目展示指标、单季/TTM/年度、历史窗口和实际观察日期，重复点击同一条目不会新增内容。财务快照计算版本为 `stock_assessment_calc_v2`：有息负债和净现金复用主页面的计算，债务组成科目齐全且报表列示空值时按零处理；缺少科目时留空。净现金为负表示净负债；已实施分红率仅年度计算，单季/TTM 留空。旧版报告保留生成时快照并提示重新分析，修正后的财务事实需重新提交分析才能反映到结论。
